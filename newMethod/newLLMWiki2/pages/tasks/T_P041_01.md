# Task: fine-tuning pretrained universal machine-learning interatomic potentials

- Task ID: `T_P041_01`
- Canonical name: `fine_tuning_pretrained_mlips`
- Paper: `P041`

## Objective

improve accuracy of a pretrained MLIP for a specific target system while preserving its generalizability and preventing catastrophic forgetting

## Material scope

- Li6PS5Cl (LPSC)
- argyrodite-type Li solid-state electrolytes
- other sulfide, oxide, nitride, and halide electrolytes

## Target properties

- potential energy surface (PES) accuracy
- Li diffusivity
- structural stability
- quasi-melting behavior

## Constraints

- prevent catastrophic forgetting
- maintain computational efficiency
- preserve generalizability across diverse chemistries

## Input requirements

- pretrained universal MLIP (SevenNet-0)
- target-specific fine-tuning dataset (LPSC AIMD trajectories)
- pretrained dataset (MPtrj) for Replay/EWC computation

## Output goal

- fine-tuned MLIP model with improved PES accuracy for LPSC and transferable knowledge to chemically distinct systems

## Research stages

1. constructing the fine-tuning dataset from AIMD trajectories of LPSC (`data_acquisition`)
2. constructing the Replay set by sampling from the pretrained MPtrj dataset (`data_acquisition`)
3. preprocessing datasets for fine-tuning (`data_preparation`)
4. fine-tuning SevenNet-0 using reEWC loss function (`model_training`)
5. evaluating forgetting prevention and generalizability on sMPtrj test set (`model_evaluation`)
6. evaluating PES accuracy on argyrodite and non-argyrodite Li SSE test sets (`model_evaluation`)
7. validating dynamical properties via MD simulations and comparison to DFT benchmarks (`experimental_validation`)
