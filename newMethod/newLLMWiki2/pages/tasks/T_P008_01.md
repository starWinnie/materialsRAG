# Task: identifying semiconductors with ultralow lattice thermal conductivity

- Task ID: `T_P008_01`
- Canonical name: `identify_semiconductors_with_ultralow_lattice_thermal_conductivity`
- Paper: `P008`

## Objective

efficiently discover semiconductors exhibiting ultralow lattice thermal conductivity (κL) for thermoelectric applications

## Material scope

- semiconductors

## Target properties

- lattice thermal conductivity (κL)

## Constraints

- ultralow κL (≤2 W/mK)
- thermodynamic stability (Ehull ≤0.05 eV/atom)
- band gap 0.1–2 eV
- Natoms < 20
- Nelements < 4
- exclude H, lanthanides, actinides

## Input requirements

- chemical composition
- crystal structure
- descriptors derived from Magpie and Voronoi tessellations

## Output goal

- list of candidate semiconductors with ultralow κL
- interpretable descriptors governing κL modulation
- new factor influencing structural anharmonicity

## Research stages

1. obtaining material dataset from Materials Project database (`data_acquisition`)
2. preliminary high-throughput screening and data cleaning (`data_preparation`)
3. unsupervised learning to identify problem-specific clusters with similar κL (`candidate_generation`)
4. high-throughput calculation (HTC) of κPET on problem-specific clusters (`computational_validation`)
5. labeling materials as ultralow or non-ultralow κL based on κPET threshold (`label_generation`)
6. training CatBoost classifier on labeled local database (`model_training`)
7. evaluating CatBoost model performance (`model_evaluation`)
8. screening candidate materials with ultralow κL for in-depth mechanism analysis (`candidate_screening`)
9. first-principles computational validation via phonon BTE solving (`experimental_validation`)
10. interpretable analysis using SHAP to link descriptors to κL mechanisms (`computational_validation`)
