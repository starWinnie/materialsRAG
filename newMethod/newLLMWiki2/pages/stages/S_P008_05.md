# Stage: labeling materials as ultralow or non-ultralow κL based on κPET threshold

- Stage ID: `S_P008_05`
- Stage type: `label_generation`
- Stage order: 5
- Task: `T_P008_01` — identifying semiconductors with ultralow lattice thermal conductivity

## Goal

generate binary classification labels for supervised learning using κPET ≤2 W/mK as cutoff

## Input

- κPET values from HTC
- threshold of 2 W/mK

## Output

- binary labels: 1 (ultralow κL) or 0 (non-ultralow κL)

## Datasets used

- local database — label_source: generate binary classification labels for supervised learning using κPET ≤2 W/mK as cutoff
