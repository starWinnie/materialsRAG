## Purposes

- Source of experimental bandgap measurements for constructing the primary perovskite database
- Training dataset after cleaning (204 samples) for initial BPM development / Test dataset (23 samples) for evaluating initial BPM performance
- Base pool from which four specialized subsets (ABX3, all-inorganic, hybrid, tin-free) were derived for candidate model generation

- Source of bandgap labels for SHAP-based interpretation of feature contributions
