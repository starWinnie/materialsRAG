# Stage: comparison of OOD performance against MatBench i.i.d. baselines

- Stage ID: `S_P029_05`
- Stage type: `ablation_study`
- Stage order: 5
- Task: `T_P029_01` — structure-based out-of-distribution (OOD) materials property prediction

## Goal

To quantify the generalization gap by comparing each model's OOD MAE to its published i.i.d. MatBench baseline MAE.

## Input

- OOD MAE results
- MatBench leaderboard i.i.d. MAEs

## Output

- percentage performance degradation/improvement for each model and OOD method

## Datasets used

- matbench_dielectric — benchmark: To compare OOD MAE results against MatBench i.i.d. baselines.
- matbench_log_gvrh — benchmark: To compare OOD MAE results against MatBench i.i.d. baselines.
- matbench_perovskites — benchmark: To compare OOD MAE results against MatBench i.i.d. baselines.
