# Stage: training of CrystalFramer architecture

- Stage ID: `S_P010_02`
- Stage type: `model_training`
- Stage order: 2
- Task: `T_P010_01` — crystal structure modeling for SE(3)-invariant property prediction

## Goal

To train the CrystalFramer model using Adam optimizer and mean absolute error loss on crystal property prediction tasks.

## Input

- crystal structures from JARVIS, MP, and OQMD datasets
- DFT-simulated property labels

## Output

- trained CrystalFramer model with dynamic frames

## Datasets used

- JARVIS-DFT 3D — training: training the CrystalFramer model from scratch using mean absolute loss function with Adam optimizer for 2000 epochs
- Materials Project — training: training the CrystalFramer model using mean absolute loss function with Adam optimizer
- Open Quantum Materials Database (OQMD) — training: training the CrystalFramer model using mean absolute loss function with Adam optimizer for 200 epochs with larger batch size
