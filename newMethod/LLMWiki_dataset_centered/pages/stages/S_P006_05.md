# Stage: clustering and interpretability analysis of ct-UAEs

- Stage ID: `S_P006_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P006_01` — universal atomic embeddings (UAEs)

## Goal

to project ct-UAEs into lower-dimensional space and cluster atoms to reveal connections between atomic features and targeted crystal properties

## Input

- ct-UAE tensors
- UMAP clustering method
- K-means clustering method

## Output

- two-dimensional projection of ct-UAEs
- three-class atom categorization (Class A/B/C)
- violin plots of properties per class

## Datasets used

- oxide compounds subset from Materials Project — computational_validation: to statistically validate the clustering results of ct-UAEs by analyzing oxide compounds

Here, the UMAP clustering method42 is employed to project these ct-UAEs into a two-dimensional space, thereby offering a means to intuitively understand atomic characteristics in a reduced dimensional setting."
