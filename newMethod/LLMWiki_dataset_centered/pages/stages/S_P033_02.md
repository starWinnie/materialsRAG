# Stage: database establishment and cleaning

- Stage ID: `S_P033_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P033_01` — bandgap prediction of ABX3-type perovskites

## Goal

Construct and clean a database of perovskite compositions and corresponding experimental bandgaps

## Input

- raw experimental bandgap data

## Output

- cleaned training dataset (204 samples) and test dataset (23 samples)

## Datasets used

- Experimental ABX3-type perovskite bandgap dataset (227 samples) — training: Training dataset after cleaning (204 samples) for initial BPM development / Test dataset (23 samples) for evaluating initial BPM performance

## Evidence

- P033, PDF page 2, Build model: "The second step is the establishment and cleaning of the database. First, data with the same chemical composition and bandgap are removed, but due to the different conditions and environments of the experiments, there will be data with the same chemical composition (input data) but different bandgap values (output data). In order to ensure the authenticity of the data and avoid the non-uniform distribution of the data, we choose to keep them in the training dataset."
- P033, PDF page 3, Results and analysis: "We set up a training dataset and a test dataset of ABX3-type perovskites containing 204 and 23 data to train and evaluate the pros and cons of the algorithm."
