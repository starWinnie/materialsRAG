# Stage: Validating predictions via first-principles DFT calculations

- Stage ID: `S_P005_08`

- Task: `T_P005_01` — Predicting thermodynamic stability of inorganic compounds

## Goal

Confirm predicted stability of top-ranked candidates using density functional theory (DFT) to compute formation energies and construct convex hulls

## Input

- crystal structures of candidate compounds
- VASP computational framework

## Output

- DFT-calculated ΔHd values
- convex hull stability verification
- validation accuracy (e.g., 25/35 stable perovskites confirmed)

## Datasets used

- Materials Project — computational_validation: Construct convex hull for DFT validation of candidate compounds
