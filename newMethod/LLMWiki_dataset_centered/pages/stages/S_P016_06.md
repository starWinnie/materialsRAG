# Stage: analysis of scaling effects (training time and size) on OOD performance

- Stage ID: `S_P016_06`
- Stage type: `ablation_study`
- Stage order: 6
- Task: `T_P016_01` — probing out-of-distribution generalization in machine learning for materials

## Goal

To test whether neural scaling laws hold for OOD generalization by varying training time and training set size and measuring resulting MAE on ID and OOD test sets.

## Input

- trained models
- OOD tasks
- varied training durations and dataset sizes

## Output

- learning curves (MAE vs. training time/size) for ID and OOD performance

## Datasets used

- None stated
