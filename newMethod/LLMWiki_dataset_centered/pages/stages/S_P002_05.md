# Stage: pretraining the G-invariant positional encoding module

- Stage ID: `S_P002_05`
- Stage type: `model_training`
- Stage order: 5
- Task: `T_P002_01` — developing a single machine learning architecture that is capable of adapting its weights automatically to enforce invariance to any input space group

## Goal

To train the symmetry-adapted encoding module to produce embeddings where the Euclidean distance corresponds to the true orbit distance.

## Input

- synthetic dataset of atomic position pairs
- ground-truth orbit distances

## Output

- pretrained G-invariant positional encoding model

## Datasets used

- synthetic orbit distance dataset — training: To train the symmetry-adapted encoding module to produce embeddings where the Euclidean distance corresponds to the true orbit distance.
