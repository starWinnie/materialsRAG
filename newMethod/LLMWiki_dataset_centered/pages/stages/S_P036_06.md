# Stage: GBRT-P model training

- Stage ID: `S_P036_06`
- Stage type: `model_training`
- Stage order: 6
- Task: `T_P036_01` — predicting the experimental band gap values of HOIPs

## Goal

To train a high-accuracy, interpretable predictive model using the 7 selected physical features as input and experimental band gaps as labels.

## Input

- training set
- 7 selected physical features

## Output

- GBRT-P model with RMSE < 0.060 eV

## Datasets used

- 610-data-point HOIP dataset — training: training set (85% of 610 data points) used to train the GBRT-P model

## Evidence

- P036, PDF page 5, METHODS: "Figure 3b shows the variation of GBRT-P accuracy with the number of subfeatures; the model accuracy is not significantly improved when the number of subfeatures is greater than 7, so we chose the top 7 features in ranked feature importance as input variables to reduce the complexity of the model without sacrificing the accuracy too much and the final GBRT-P model with an RMSE of 0.059 eV for the test set."
