# Stage: Training classical ML models in delta-learning framework

- Stage ID: `S_P035_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P035_01` — Correcting DFT formation energies towards experimental accuracy

## Goal

Train classical ML models (KRR, RF, GPR) to predict the residual (delta) between calculated formation energies (PBEsol or zero-shot MLIP) and experimental values, using latent features from PET-OMATPES as input.

## Input

- latent features from PET-OMATPES
- target deltas: δ∆HPBEsol_f or δ∆HMLIP_f
- experimental formation enthalpies

## Output

- trained KRR-LAP-LF model
- trained RF model
- trained GPR model

## Datasets used

- Alexandria database — computational_validation: Serve as computational reference to validate PET-OMATPES r2SCAN formation energies and energies above hull as the baseline for stability flip rate analysis.
- experimental references used by Kirklin et al. — label_source: Provide target deltas (δ∆HPBEsol_f and δ∆HMLIP_f) for training classical ML models in the delta-learning framework.
- expt formation enthalpy kingsbury dataset — label_source: Provide target deltas (δ∆HPBEsol_f and δ∆HMLIP_f) for training classical ML models in the delta-learning framework.
- Materials Cloud three-dimensional crystals database (MC3D) PBEsol-v1 — source: Provide source formation energies (PBEsol) for computing target deltas (δ∆HPBEsol_f) in the delta-learning framework.
