# Stage: selection of best-performing models per perovskite subclass

- Stage ID: `S_P033_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P033_01` — bandgap prediction of ABX3-type perovskites

## Goal

Select top-performing models for each perovskite subclass (ABX3, all-inorganic, hybrid, tin-free)

## Input

- evaluation results across subclasses

## Output

- final selected models: Xgboost for ABX3/all-inorganic; MLP for hybrid/tin-free

## Datasets used

- All-inorganic perovskites subset — training: Training dataset for all-inorganic perovskite-specific BPM
- Inorganic-organic hybrid perovskites subset — test: Test dataset for hybrid perovskite-specific BPM evaluation
- Tin-free perovskites subset — training: Training dataset for tin-free perovskite-specific BPM
