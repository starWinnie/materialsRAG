- Stage ID: `S_P019_04`

## Goal

Evaluate DTNet's performance on dielectric tensor prediction using MAE metrics and compare it with PaiNN, M3GNet, and MatTen.

## Input

- trained DTNet models
- test subset of MP dataset
- models PaiNN, M3GNet, MatTen

## Output

- MAEten, MAEmean-diag, MAEdiag, MAEoff-diag scores
- superior performance claims

## Datasets used

- Matbench dielectric task dataset — benchmark: Benchmarking DTNet on the official Matbench dielectric task
- Materials Project cleaned dielectric subset — benchmark: Benchmarking DTNet against state-of-the-art models
