# Stage: Consistent formatting and validation of extracted data

- Stage ID: `S_P042_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P042_01` — Creation of an open-access, FAIR-compliant database and analysis tool for perovskite solar cell device data

## Goal

To standardize all extracted data according to a defined protocol and perform error checking and validation.

## Input

- manually extracted raw device data
- original data extraction protocol (95 attributes)

## Output

- consistently formatted dataset ready for database ingestion

## Datasets used

- Perovskite Database — source: Consistent formatting and validation of extracted data

## Evidence

- P042, PDF page 3, Data: "Once extracted, the data have been consistently formatted according to the instruction in the supporting documentation and is now freely available in the Perovskite Database."
- P042, PDF page 7, Methods: "We have therefore set up a system for reporting dubious data points, and we thereby expect some self-correction over time... To reduce the errors, we went through the extracted data to check for errors, misunderstandings, confusing entries and inconsistent formatting."
