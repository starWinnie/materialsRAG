# Stage: pre-training via crystal structure reconstruction

- Stage ID: `S_P023_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P023_01` — crystal property prediction

## Goal

Train the diffusion model to reconstruct crystal structures (L and F) from atom composition A, learning the latent marginal distribution p(F, L | A)

## Input

- 800K untagged crystal graph data (A, F, L)

## Output

- pre-trained diffusion model ϕθ
