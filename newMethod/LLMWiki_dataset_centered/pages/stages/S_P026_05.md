# Stage: validate OOD generalization improvement

- Stage ID: `S_P026_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P026_01` — dataset redundancy control for material property prediction

## Goal

Demonstrate that models trained on non-redundant data achieve better out-of-distribution prediction performance than those trained on redundant data.

## Input

- EmbeddingOOD test set
- Roostnr and Roostred models

## Output

- MAE and R² improvements on OOD test set (10.03% MAE, 31.6% R² gain)

## Datasets used

- EmbeddingOOD — experimental_validation: Out-of-distribution test set to validate OOD generalization improvement

## Evidence

- P026, PDF page 8: "We found that the Roostnr significantly outperforms Roostred model, with 10.03% improvement in MAE and a 31.6% improvement in R2 for the OOD test set. This result demonstrates that removing redundant data can steer an ML model away from focusing on crowded samples, ensuring equitable attention to all other samples, and consequently improving OOD prediction performance."
