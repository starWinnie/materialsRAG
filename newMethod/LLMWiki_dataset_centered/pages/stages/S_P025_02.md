# Stage: constructing atom-probe graphs

- Stage ID: `S_P025_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P025_01` — charge density prediction

## Goal

Build efficient equivariant graph representations linking atoms and probe points for message passing

## Input

- atomic species
- atomic positions
- probe point locations
- periodic boundary cell

## Output

- graph with atoms and probe points as vertices
- edges formed via proximity with cutoff of 4 Å

## Datasets used

- None stated

- P025, PDF page 2, Results: "As illustrated in Fig. 1b, c, a graph is first constructed with atoms and probe points as vertices, with edges formed via proximity with a cutoff of 4 Å. Edges connecting atoms are unidirectional and edges connecting atoms and probe points are directed pointing from atoms to probe points."
- P025, PDF page 7, Methods: "We develop an algorithm to achieve more efficient atom-probe graph construction, enabling faster training and inference times."
