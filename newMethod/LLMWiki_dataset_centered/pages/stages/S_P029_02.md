# Stage: generation of five OOD test set splits per dataset

- Stage ID: `S_P029_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P029_01` — structure-based out-of-distribution (OOD) materials property prediction

## Goal

To construct realistic OOD test sets by systematically selecting samples from sparser regions of structure or property space, ensuring distributional deviation from training data.

## Input

- raw MatBench datasets
- orbital-field matrix (OFM) features
- t-SNE dimensionality reduction

## Output

- LOCO test sets
- SparseXsingle test sets
- SparseYsingle test sets
- SparseXcluster test sets
- SparseYcluster test sets

## Datasets used

- matbench_dielectric — candidate_pool: To generate five OOD test set splits (LOCO, SparseXsingle, SparseYsingle, SparseXcluster, SparseYcluster) by clustering in OFM feature space or property space.
- matbench_log_gvrh — candidate_pool: To generate five OOD test set splits (LOCO, SparseXsingle, SparseYsingle, SparseXcluster, SparseYcluster) by clustering in OFM feature space or property space.
- matbench_perovskites — candidate_pool: To generate five OOD test set splits (LOCO, SparseXsingle, SparseYsingle, SparseXcluster, SparseYcluster) by clustering in OFM feature space or property space.
