# Stage: end-to-end training of equivariant prediction model

- Stage ID: `S_P030_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P030_01` — charge density prediction

## Goal

Train the eSCN-based model to jointly predict orbital basis coefficients ci,j,m and learnable scaling factors si,j for exponents, minimizing mean-absolute error between predicted and DFT charge densities.

## Input

- atomic numbers A'
- coordinates R'
- ground-truth charge density ρ(r)

## Output

- trained SCDP model F(A', R') → {ci,j,m, si,j}

## Datasets used

- None stated

## Evidence

- P030, PDF page 6, 3.2 Prediction Model: "We train the model end-to-end with a mean-absolute error loss L over the charge density: L = Er∈Data [|ρ(r) −ˆρ(r)|] ."
- P030, PDF page 7, 3.2 Prediction Model: "Fine-tuning for scaling factor prediction. The scaling factors at the exponents lead to significant training instability when the network is trained from scratch. Therefore, we use a fine-tuning approach, where we first pre-train the model with fixed basis set exponents [...] and then fine-tune the prediction model with a small learning rate with the learning for scaling factors enabled."
