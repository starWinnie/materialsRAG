# Stage: Deriving stability labels from decomposition energy (ΔHd) via convex hull analysis

- Stage ID: `S_P005_03`
- Stage type: `label_generation`
- Stage order: 3
- Task: `T_P005_01` — Predicting thermodynamic stability of inorganic compounds

## Goal

Compute binary stability labels by determining whether each compound lies on the convex hull of its elemental phase diagram

## Input

- formation energies of compounds
- phase diagram data

## Output

- binary labels: stable (ΔHd < 0 meV/atom) or unstable

## Datasets used

- Materials Project — label_source: Derive binary stability labels via convex hull analysis using formation energies

## Evidence

- P005, PDF page 2: "The thermodynamic stability of materials is typically represented by the decomposition energy (ΔHd)6, which is defined as the total energy difference between a given compound and competing compounds in a specific chemical space. For detailed definitions of ΔHd, see Supplementary Note 1. This metric is ascertained by constructing a convex hull utilizing the formation energies of compounds and all pertinent materials within the same phase diagram7."
- P005, PDF page 11, Methods: "Compounds with a ΔHd below 0 meV/atom were considered stable and are labeled accordingly."
