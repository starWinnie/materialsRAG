# Stage: comparison of dynamic frame variants

- Stage ID: `S_P010_04`
- Stage type: `ablation_study`
- Stage order: 4
- Task: `T_P010_01` — crystal structure modeling for SE(3)-invariant property prediction

## Goal

To validate the effectiveness of dynamic frames by comparing different frame construction methods (max frames, weighted PCA frames, static local frames) against conventional static frames.

## Input

- CrystalFramer models with different frame types

## Output

- performance comparison showing superiority of max frames

## Datasets used

- None stated

## Evidence

- P010, PDF page 8, 5.1 CRYSTAL PROPERTY PREDICTION: "Our method with max frames outperforms others in most tasks, significantly enhancing the performance of the baseline Crystalformer model."
- P010, PDF page 8, 5.1 CRYSTAL PROPERTY PREDICTION: "Additionally, we evaluated a variant using static local frames. These frames are similar to max frames but constructed with static weights, wij(n) = exp −r2 ij(n) . As a result, these static local frames rely only on the distances to neighbors and do not account for dynamic self-attention weights. The max frame method outperforms this static counterpart in most tasks."
