# Stage: evaluation of extrapolative prediction performance

- Stage ID: `S_P015_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To assess model generalization on unseen material classes or chemical compositions excluded from training.

## Input

- trained MNNs
- test sets from excluded polymer classes (e.g., p13–p14–p18)
- HOIP-GeF and HOIP-PbI test sets

## Output

- RMSE and R² scores for Cp, refractive index, and bandgap prediction

## Datasets used

- HOIP dataset — test: Evaluation of extrapolative prediction performance on unseen perovskite compositions (HOIP-GeF and HOIP-PbI).
- RadonPy polymer dataset — test: Evaluation of extrapolative prediction performance on unseen polymer classes.

## Evidence

- P015, PDF page 3, Experimental results: "To evaluate the prediction performance for an unseen polymer class, the following process was implemented: (1) a model was trained using randomly selected samples from 19 of the 20 polymer classes and (2) its generalizability was assessed using data from the remaining polymer class."
- P015, PDF page 5, unknown: "We performed numerical experiments using the same setting as that employed by Na et al.42,43. The HOIP dataset was divided into 12 groups... For creating a training episode, we excluded all samples with Ge and F or with Pb and I and randomly selected 50 instances of (x, y) from one group while drawing S of size 50 from the 10 remaining groups."
