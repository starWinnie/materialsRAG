# Stage: training interpretable supervised classification model

- Stage ID: `S_P008_07`
- Stage type: `model_training`
- Stage order: 7
- Task: `T_P008_01` — identifying semiconductors with ultralow lattice thermal conductivity

## Goal

Train a robust, interpretable CatBoost classifier on the labeled local database to predict ultralow κL (κPET ≤ 2 W/mK) and refine coarse unsupervised clustering results.

## Input

- labeled local database (661 materials)
- 273 descriptors (Magpie + Voronoi)
- top 9 selected features

## Output

- trained CatBoost classification model
- ROC AUC = 0.94, accuracy = 0.90

## Datasets used

- labeled local database — training: Train interpretable CatBoost classifier to predict ultralow κL (κPET ≤ 2 W/mK).
