# Stage: validation on alloy systems and complex materials

- Stage ID: `S_P027_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P027_01` — phonon spectra and bandstructure prediction

## Goal

Validate model generalizability on unseen alloy systems and large-unit-cell materials

## Input

- trained k-MVN model
- SiGe alloy data
- NiCo/NiFe/NiFeCo alloy data
- MoTaNbWV/VWNbTaTi high-entropy alloy data

## Output

- predicted phonon bands for alloys
- agreement with VCA/DFPT ground truth
- demonstration of scalability to >40 atoms/unit cell

## Datasets used

- Togo phonon database — computational_validation: Validation on alloy systems and high-entropy alloys using phonon data derived from Togo database or analogous DFPT/VCA methods
