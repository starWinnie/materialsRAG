# Stage: generating benchmark datasets with defined data splits

- Stage ID: `S_P028_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P028_01` — benchmarking of materials design methods

## Goal

to prepare benchmark datasets with well-defined train/validation/test splits for AI methods and reference test sets for other methods

## Input

- reference datasets
- well-defined data splits
- AI-specific training/validation/test identifiers

## Output

- json.zip files with training/validation/test identifiers and target data for AI
- reference test sets for ES, FF, QC, EXP

## Datasets used

- JARVIS-DFT 2D — test: test set for 2D exfoliation energy predictions
- JARVIS-DFT 3D — training: training set for AI models / validation set for AI models / test set for AI models

## Evidence

- P028, PDF page 4, Results and discussion: "AI benchmarks have pre-defined training/validation/test identifiers and target data in a corresponding json.zip file, while other methods have only reference test set for evaluation because they do not require model training like an AI method does."
