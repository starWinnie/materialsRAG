# Stage: Training PDDFormer (WPDDFormer/UPDDFormer)

- Stage ID: `S_P012_02`
- Stage type: `model_training`
- Stage order: 2
- Task: `T_P012_01` — Crystal material property prediction

## Goal

Train transformer-based models using crystal graphs with WPDD or UPDD as input

## Input

- multi-edge crystal graphs G = (X, XI, E, PDD)
- property labels (e.g., formation energy, band gap)

## Output

- trained WPDDFormer and UPDDFormer models

## Datasets used

- JARVIS-DFT — training: Training WPDDFormer and UPDDFormer models on property prediction tasks
- Materials Project — training: Training WPDDFormer and UPDDFormer models on property prediction tasks
