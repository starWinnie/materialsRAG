# Stage: generation of 24 candidate bandgap prediction models

- Stage ID: `S_P033_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P033_01` — bandgap prediction of ABX3-type perovskites

## Goal

Generate multiple candidate ML models by combining 4 databases and 6 algorithms

## Input

- cleaned database
- six ML algorithms: LR, KNN, SVR, RF, MLP, Xgboost

## Output

- 24 candidate bandgap prediction models

## Datasets used

- CBM and VBM database for ABX3 perovskites — training: Training dataset for CBM and VBM prediction models
- Experimental ABX3-type perovskite bandgap dataset (227 samples) — candidate_pool: Base pool from which four specialized subsets (ABX3, all-inorganic, hybrid, tin-free) were derived for candidate model generation
