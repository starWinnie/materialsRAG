- pre-trained ALIGNN source model
- target datasets

## Output

- fine-tuned ALIGNN target model

## Datasets used

## Evidence

- P024, PDF page 2, INTRODUCTION: "The transfer of information can be performed by either ﬁne-tuning or feature extraction methods. Fine-tuning uses the weights from the pre-trained model as the preliminary weight initialization for the network, which are further reﬁned using the target dataset. In the feature extraction method, we treat the pre-trained model as a feature extractor to extract robust features for the target dataset and use them to build the target model using representation learning."
