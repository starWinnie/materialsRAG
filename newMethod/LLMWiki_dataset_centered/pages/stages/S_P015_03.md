# Stage: training MNNs via extrapolative episodic training (E2T)

- Stage ID: `S_P015_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To train attention-based meta-learners (MNNs) on episodes where (x,y) lie outside the support set S’s domain, thereby learning y = f(x, S) for extrapolative prediction.

## Input

- episodes (xi, yi, Si) with extrapolative relationships
- descriptors/embeddings
- kernel ridge regressor parameters

## Output

- trained MNNs with extrapolative capability

## Datasets used

- HOIP dataset — training: Training MNNs via extrapolative episodic training (E2T) using episodes with extrapolative relationships.
- RadonPy polymer dataset — training: Training MNNs via extrapolative episodic training (E2T) using episodes with extrapolative relationships.
