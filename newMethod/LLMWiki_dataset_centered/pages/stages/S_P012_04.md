# Stage: Ablation study on (W/U)PDD contribution

- Stage ID: `S_P012_04`
- Stage type: `ablation_study`
- Stage order: 4
- Task: `T_P012_01` — Crystal material property prediction

## Goal

Validate the importance of WPDD/UPDD integration by removing PDD message passing blocks or (W/U)PDD inputs

## Input

- models with/without PDD message passing blocks
- models with/without (W/U)PDD information

## Output

- comparative MAE improvements (e.g., 17.4% in Bulk Moduli)

## Datasets used

- JARVIS-DFT — validation: Ablation study on (W/U)PDD contribution using testing MAE as evaluation metric
- Materials Project — validation: Ablation study on (W/U)PDD contribution using testing MAE as evaluation metric
