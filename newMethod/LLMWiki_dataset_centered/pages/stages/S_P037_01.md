# Stage: creating and validating unique experimental databases

- Stage ID: `S_P037_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P037_01` — accelerating the discovery of new transparent conducting materials (TCMs)

## Goal

create and validate experimental databases comprising several examples of existing TCMs to mitigate shortage of available data

## Input

- Materials Platform for Data Science (MPDS)
- UCSB dataset
- primary literature
- Pearson's Crystallographic Database
- ICSD

## Output

- electrical conductivity dataset (8231 material entries)
- band gap dataset (4767 material entries)

## Datasets used

- Materials Project DFT-computed band gap dataset — pretraining: pretraining dataset for CrabNet model
- MPDS electrical conductivity dataset — source: source for raw electrical conductivity data
- UCSB thermoelectric dataset (electrical conductivity subset) — source: source for raw electrical conductivity data
- Zhuo et al. experimental band gap dataset — source: source for raw band gap data

## Evidence

- P037, PDF page 1, Introduction: "To mitigate the shortage of available data, we create and validate unique experimental databases, comprising several examples of existing TCMs."
- P037, PDF page 3, Introduction: "To address the limitation of optical property data, we adopt the band gap (Eg) as a proxy for optical transparency... To enable a ML approach, we have created and validated two experimental datasets of room-temperature conductivity and band gap measurements, to be used as foundation for training SOTA ML models for the discovery of new TCMs."
