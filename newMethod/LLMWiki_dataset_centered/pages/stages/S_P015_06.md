# Stage: fine-tuning for downstream extrapolative domains

- Stage ID: `S_P015_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To adapt pretrained E2T models to target domains using limited data, evaluating transferability and sample efficiency.

## Input

- pretrained MNNs
- small target-domain datasets (e.g., 20–500 polymer samples, 10–40 perovskite samples)

## Output

- fine-tuned models
- scaling curves of RMSE vs. target sample size (Figs. 5–7)

## Datasets used

- HOIP dataset — candidate_pool: Fine-tuning pretrained E2T models on target-domain perovskite subsets (HOIP-GeF and HOIP-PbI) with limited samples.
- RadonPy polymer dataset — candidate_pool: Fine-tuning pretrained E2T models on target-domain polymer classes with limited samples.

## Evidence

- P015, PDF page 6, Fine-tuning to extrapolative domains: "Fine-tuning was performed on the RadonPy dataset. In this experiment, a pretrained E2T model with a source data size of 38,000 was fine-tuned on data from the target domain corresponding to a particular polymer class."
- P015, PDF page 11, Fine-tuning experiments: "An MNN pretrained by E2T with a source data size of 1248 (HOIP-GeF) or 1228 (HOIP-PbI) was fine-tuned on data, including data from the target domain. Half of the target dataset was reserved for performance evaluation, whereas 10–40 samples from the remaining data were used for fine-tuning."
