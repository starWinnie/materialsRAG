Assess relative contribution of atom/bond/angle features and quantify performance gain as function of target dataset size.

- Table 1 (feature ablation)
- Supplementary Figures 2 and 3 (dataset size vs. % error improvement)

- atom-bond-angle features(last) identified as best

## Evidence

- P024, PDF page 4, Poison: "Table 1 shows that, in general, feature representations containing structure-aware atom-based features tend to perform better as compared to only bond or angle-based features. Moreover, the combination containing the last set of the atom, bond, and angle-based features, called atom-bond-angle features(last), performs the best among the 38 sets of features used for the analysis."
- P024, PDF page 6, Mepsx: "We plot the percent error improvement of the TL model against the SC model as a function of dataset size with a histogram in Supplementary Figures 2 and 3 and observe larger improvement in the model accuracy for smaller datasets as compared to larger datasets."
