# Stage: comparing atomic embeddings from different front-end models

- Stage ID: `S_P006_02`
- Stage type: `candidate_screening`
- Stage order: 2
- Task: `T_P006_01` — universal atomic embeddings (UAEs)

## Goal

to evaluate and compare the performance of atomic embeddings generated by CrystalTransformer (Method I), GNN models (Method II), and artificially constructed features (Method III)

## Input

- atomic embeddings from Method I (CrystalTransformer)
- atomic embeddings from Method II (GNN models)
- atomic embeddings from Method III (artificially constructed)

## Output

- comparative MAE analysis
- identification of best-performing embeddings (ct-UAEs)

## Datasets used

- Materials Project dataset — benchmark: to evaluate and compare the performance of atomic embeddings generated by CrystalTransformer (Method I), GNN models (Method II), and artificially constructed features (Method III)

Other pretrained atomic embeddings used GNN models (Method II shown in Fig. 1b).
