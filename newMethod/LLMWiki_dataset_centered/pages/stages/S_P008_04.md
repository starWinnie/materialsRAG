# Stage: high-throughput calculation of κPET values for second-level dataset

- Stage ID: `S_P008_04`
- Stage type: `label_generation`
- Stage order: 4
- Task: `T_P008_01` — identifying semiconductors with ultralow lattice thermal conductivity

## Goal

Assign property labels (κPET values at 300 K) to materials in the second-level dataset using the low-cost phonon-elasticity-thermal (PET) empirical model.

## Input

- 704 materials (C1 and C2)
- PET empirical equation

## Output

- labeled local database of 661 materials with κPET values
- list of candidates with κPET ≤ 2 W/mK

## Datasets used

- second-level dataset — source: Provide input structures for PET model-based high-throughput calculation of κPET at 300 K.
