# Stage: Preprocessing compositional and electronic-structure representations

- Stage ID: `S_P005_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P005_01` — Predicting thermodynamic stability of inorganic compounds

## Goal

Transform raw chemical formulas into structured inputs suitable for ML models—including element-fraction vectors, statistical atomic features, graph representations, and electron configuration matrices

## Input

- chemical formulas
- periodic table data
- electron configuration data

## Output

- Magpie feature vectors (132 features)
- Roost crystal graphs
- ECCNN input tensor (118 × 168 × 8)

## Datasets used

- None stated
