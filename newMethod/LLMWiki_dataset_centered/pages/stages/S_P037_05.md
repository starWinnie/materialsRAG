# Stage: assessing model performance with bespoke evaluation schemes

- Stage ID: `S_P037_05`
- Stage type: `model_evaluation`
- Stage order: 5
- Task: `T_P037_01` — accelerating the discovery of new transparent conducting materials (TCMs)

## Goal

evaluate trained models using K-fold, LOCO-CV, and leave-one-TCM-family-out to determine ability to identify previously unseen TCMs

## Input

- trained RF model
- trained CrabNet model
- list of 55 compositions

## Output

- family-discovery-rate (FDR) metric
- MAE and R2 metrics
- confusion matrices

## Datasets used

- None stated
