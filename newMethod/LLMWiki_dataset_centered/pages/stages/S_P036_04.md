# Stage: feature engineering and physical feature pool construction

- Stage ID: `S_P036_04`
- Stage type: `candidate_generation`
- Stage order: 4
- Task: `T_P036_01` — predicting the experimental band gap values of HOIPs

## Goal

To construct a physically meaningful feature pool by selecting and crossing elemental descriptors (e.g., electronegativity, ionic radius) based on domain knowledge.

## Input

- nine element characteristics (Pauling’s electronegativity, μ, τ, IR, EA, DP, AR, d/f electrons)

## Output

- 27 new features including sums, differences, and ratios (e.g., χB−X, IRA−X, μ)

## Datasets used

- 610-data-point HOIP dataset — candidate_pool: source of elemental descriptors for feature engineering and physical feature pool construction

## Evidence

- P036, PDF page 3, METHODS: "In this work, we chose nine element characteristics as descriptors in the initial feature pool based on a priori knowledge, including Pauling’s electronegativity (χ), μ, τ, IR, electron affinity (EA), dipole polarizability (DP), atomic radius (AR), and the number of electrons on d and f orbitals. ... In addition to the individual descriptors, we considered their sums, differences, and ratios to create new features, named feature crosses; details are given in the Supporting Information, and Pauling’s electronegativity used for the elements of B-site and X-site is given in Table S5."
