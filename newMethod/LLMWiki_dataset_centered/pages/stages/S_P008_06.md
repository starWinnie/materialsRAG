# Stage: first-principles validation of selected candidates

- Stage ID: `S_P008_06`
- Stage type: `computational_validation`
- Stage order: 6
- Task: `T_P008_01` — identifying semiconductors with ultralow lattice thermal conductivity

## Goal

Perform high-accuracy ab initio calculations (phonon BTE) on selected candidates to computationally validate ultralow κL and reveal underlying phonon transport mechanisms.

## Input

- Cs2SnSe3 and Cs2GeSe3 crystal structures
- first-principles DFT calculations
- phonon BTE solver (ShengBTE)

## Output

- precise κL values vs. temperature
- phonon dispersion, PDOS, spectral κL(ω), group velocity, phonon lifetime
- mechanistic insights (e.g., rattling, anharmonicity)

## Datasets used

- labeled local database — computational_validation: Provide candidate list (Cs2SnSe3, Cs2GeSe3) selected from κPET-ranked materials for first-principles validation.
