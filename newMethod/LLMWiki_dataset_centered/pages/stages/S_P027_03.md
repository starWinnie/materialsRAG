# Stage: training of VGNN models (VVN, MVN, k-MVN)

- Stage ID: `S_P027_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P027_01` — phonon spectra and bandstructure prediction

## Goal

Optimize neural network parameters to minimize MSE loss between predicted and ground-truth phonon frequencies

## Input

- atomic coordinates
- atomic numbers
- atomic masses
- training set phonon data

## Output

- trained VVN model
- trained MVN model
- trained k-MVN model

## Datasets used

- DFPT phonon database for semiconducting inorganic materials — training: Training data for optimizing neural network parameters via MSE loss minimization
