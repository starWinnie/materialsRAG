# Stage: populating reference benchmark datasets

- Stage ID: `S_P028_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P028_01` — benchmarking of materials design methods

## Goal

to generate well-defined benchmark datasets with reference data from experimental, density functional theory, or numerical solutions published in peer-reviewed articles

## Input

- experimental data
- density functional theory data
- numerical solutions
- peer-reviewed articles with DOIs

## Output

- json.zip files containing reference datasets
- well-characterized samples/tasks with DOI links

## Datasets used

- AFLOW — source: reference benchmark dataset for ES methods
- arXiv — source: reference benchmark dataset for AI text-based methods
- JARVIS-DFT 2D — source: reference benchmark dataset for 2D exfoliation energy predictions
- JARVIS-DFT 3D — source: reference benchmark dataset for AI, ES, FF, and QC methods
- Materials Project — source: reference benchmark dataset for AI methods
- Open Quantum Materials Database (OQMD) — source: reference benchmark dataset for ES methods
- QM9 — source: reference benchmark dataset for AI methods
- STEM 2D image dataset — source: reference benchmark dataset for AI image-based methods
- ThreeBodyTB.jl fitting dataset — source: reference benchmark dataset for ES methods
- Tight binding three-body dataset — source: reference benchmark dataset for AI methods
- ZSM-5 CO2 adsorption isotherms — experimental_validation: experimental benchmark for CO2 adsorption in zeolites

## Evidence

- P028, PDF page 4, Results and discussion: "There are several categories for the benchmarks, including AI, ES, QC, FF, and EXP and their combinations."
- P028, PDF page 5: "A benchmark should be considered the “ground truth” for a particular task. Therefore, it is mandatory to have a digital object identifier (DOI) for each benchmark from a peer-reviewed article."
