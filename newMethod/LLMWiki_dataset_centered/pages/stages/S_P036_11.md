# Stage: virtual composition space generation

- Stage ID: `S_P036_11`
- Stage type: `candidate_generation`
- Stage order: 11
- Task: `T_P036_01` — predicting the experimental band gap values of HOIPs

## Goal

To construct a large-scale virtual search space of HOIP compositions constrained to target band gap ranges and exclude Cl-containing systems.

## Input

- chemical constraints (MAaFAbCs1−a−bPbxSn1−xBrmI1−m)
- target band gap ranges (1.3−1.4 eV, 1.7−2.1 eV)

## Output

- ~5.2 × 10⁷ compound search space
- 100,000-sample subset for prediction

## Datasets used

- MAaFAbCs1−a−bPbxSn1−xBrmI1−m virtual composition space — candidate_pool: large-scale virtual composition space constructed for targeted band gap screening
