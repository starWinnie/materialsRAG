# Stage: estimating prediction error using leave-one-out cross-validation

- Stage ID: `S_P014_08`
- Stage type: `model_evaluation`
- Stage order: 8
- Task: `T_P014_01` — predicting plastic flow strength from small-scale indicator properties

## Goal

Quantify regression prediction uncertainty by applying leave-one-out cross-validation on the 153 IP pool.

## Input

- 153 regression models (each trained on 152 IPs)
- leave-one-out validation set

## Output

- average relative prediction error = 15%
- ±2 × RMSE error bounds

## Datasets used

- OpenKIM IP Repository — validation: Enabling leave-one-out cross-validation to estimate prediction error by fitting 153 regression models, each trained on 152 IPs and validated on the left-out IP.

## Evidence

- P014, PDF page 5: "Here, we ﬁt 153 regression models on the same three predictors, leaving out one of the 153 IP samples from each model for validation. As an estimate of the prediction error by regression on DFT predictors, the average relative prediction error among 153 leave-one-out models is 15%."
