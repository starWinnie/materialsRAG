# Stage: SHAP-based interpretation of feature contributions to bandgap

- Stage ID: `S_P033_09`
- Stage type: `label_generation`
- Stage order: 9
- Task: `T_P033_01` — bandgap prediction of ABX3-type perovskites

## Goal

Quantify and explain how each chemical composition (A/B/X site) contributes to bandgap prediction using SHAP values

## Input

- trained Xgboost and RF models
- feature descriptors

## Output

- SHAP importance ranking showing B-site metal and X-site halogen dominate

## Datasets used

- Experimental ABX3-type perovskite bandgap dataset (227 samples) — label_source: Source of bandgap labels for SHAP-based interpretation of feature contributions

## Evidence

- P033, PDF page 1, ABSTRACT: "our ML models give the effect of each chemical composition constituting the ABX3-type perovskites on the bandgaps by using the SHAP value, and they can be well explained in physics."
- P033, PDF page 4, four: "Through the further analysis of the SHAP plot, we can see that the bandgaps of ABX3-type perovskites can be effectively reduced with the increase of I and Sn, while the bandgaps of ABX3-type perovskites can be effectively increased with the increase of Br and Pb."
