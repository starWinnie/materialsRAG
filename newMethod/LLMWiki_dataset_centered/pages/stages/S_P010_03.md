# Stage: evaluation on crystal property prediction tasks

- Stage ID: `S_P010_03`
- Stage type: `model_evaluation`
- Stage order: 3
- Task: `T_P010_01` — crystal structure modeling for SE(3)-invariant property prediction

## Goal

To benchmark the performance of CrystalFramer against conventional frame methods and state-of-the-art crystal encoders on multiple property prediction tasks.

## Input

- trained CrystalFramer model
- test splits of JARVIS, MP, and OQMD datasets

## Output

- mean absolute errors for formation energy, bandgap, E hull, bulk modulus, shear modulus

## Datasets used

- JARVIS-DFT 3D — test: evaluation of CrystalFramer performance on crystal property prediction tasks
- Materials Project — test: evaluation of CrystalFramer performance on crystal property prediction tasks
- Open Quantum Materials Database (OQMD) — test: evaluation of CrystalFramer performance on crystal property prediction tasks
