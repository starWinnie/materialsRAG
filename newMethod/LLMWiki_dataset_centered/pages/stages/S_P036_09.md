# Stage: GASR model training

- Stage ID: `S_P036_09`
- Stage type: `model_training`
- Stage order: 9
- Task: `T_P036_01` — predicting the experimental band gap values of HOIPs

## Goal

To train a symbolic regression model to discover interpretable mathematical formulas mapping physical features to band gap.

## Input

- 7 physical features
- band gap labels
- GASR hyperparameters

## Output

- mathematical formulas (e.g., Eg = χB−X² + 0.881χB−X)

## Datasets used

- 610-data-point HOIP dataset — training: training set used to train the GASR model to discover mathematical formulas mapping physical features to band gap

## Evidence

- P036, PDF page 5, METHODS: "To explicitly obtain the mapping between physical features and the band gap, we used the GASR algorithm to develop mathematical formulas between 7 features and band gaps. GASR is a ML method based on a GA to find the hidden mathematical relationships between features and labels in data."
