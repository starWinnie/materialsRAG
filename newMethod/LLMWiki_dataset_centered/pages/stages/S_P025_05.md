# Stage: using predicted charge densities to accelerate DFT calculations

- Stage ID: `S_P025_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P025_01` — charge density prediction

## Goal

Validate utility of predictions by initializing DFT calculations and measuring reduction in self-consistent field (SCF) iterations

## Input

- ChargE3Net-predicted charge densities
- DFT code (VASP)

## Output

- reduced SCF step counts
- non-self-consistent property predictions (energy, forces, band gaps)

## Datasets used

- None stated

## Evidence

- P025, PDF page 2, Results: "We demonstrate the application of MP-trained ChargE3Net to initialize DFT calculations, resulting in a median of 26.7% reduction in SCF steps on unseen MP data and 28.6% on novel GNoME materials."
- P025, PDF page 4, experimental: "To evaluate how well ChargE3Net’s predicted charge densities reproduce physical properties, we compute the energy, forces, band energies, and bandgaps of the test set non-self-consistently."
