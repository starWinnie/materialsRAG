# Stage: band gap labeling

- Stage ID: `S_P036_03`
- Stage type: `label_generation`
- Stage order: 3
- Task: `T_P036_01` — predicting the experimental band gap values of HOIPs

## Goal

To assign experimental band gap values as labels for supervised learning, resolved from literature reports using domain-informed rules.

## Input

- literature-reported band gap values for same compositions

## Output

- single band gap label per composition

## Datasets used

- 610-data-point HOIP dataset — label_source: source of experimental band gap labels resolved from literature reports

## Evidence

- P036, PDF page 3, METHODS: "Second, for data with the same composition but different band gaps, we chose the average value when the difference between the maximum value and the minimum value is less than 0.2 eV. When it is greater than 0.2 eV, we chose the model because the experimental error is about 0.1−0.2 eV when using different instruments."
