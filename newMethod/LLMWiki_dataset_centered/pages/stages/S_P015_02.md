# Stage: descriptor generation and dataset partitioning

- Stage ID: `S_P015_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To encode material structures into numerical descriptors and partition data into training, support, and test sets appropriate for episodic training.

## Input

- polymer repeating units
- perovskite crystal structures

## Output

- 2048-dimensional Morgan fingerprints
- 32-dimensional MPNN embeddings
- episodic partitions (S, Q) with extrapolative relationships

## Datasets used

- HOIP dataset — training: Descriptor generation (MPNN embedding) and episodic partitioning for extrapolative training.
- RadonPy polymer dataset — training: Descriptor generation (Morgan fingerprint) and episodic partitioning for extrapolative training.

## Evidence

- P015, PDF page 9, Methods: "The count-based Morgan fingerprint38, a type of extended connectivity fingerprint (ECFP)39, was utilized as a descriptor for the repeating unit of a homopolymer. The descriptor was calculated using RDKit55, with a radius of 3 and bit length of 2048."
- P015, PDF page 10, Methods: "The MPNN44 was employed as the encoder for the crystal structures in all models. The MPNN architecture was designed in a manner similar to that proposed by Na and Park42, with an embedding size of 32."
- P015, PDF page 9, Methods: "Data of 19 of 20 polymer classes were used for training, whereas the remaining class was used for testing... In each step of E2T, a training instance on (x, y) was sampled from a randomly selected polymer class, whereas the support set S of size m=30 was sampled entirely from the 19 polymer classes, including interpolative and extrapolative episodes."
