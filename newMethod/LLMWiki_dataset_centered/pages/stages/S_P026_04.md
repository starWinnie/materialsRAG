# Stage: evaluate ML model performance on redundancy-controlled splits

- Stage ID: `S_P026_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P026_01` — dataset redundancy control for material property prediction

## Goal

Assess how redundancy control affects prediction accuracy (MAE, R²) of ML models on both in-distribution and out-of-distribution test sets.

## Input

- non-redundant datasets
- ML models (Roost, CrabNet, ALIGNN, DeeperGATGNN)

## Output

- R² and MAE scores for formation energy and band gap prediction
- parity plots
- OOD performance comparisons

## Datasets used

- Matscholar-nr — training: Training set for composition-based ML models (Roost, CrabNet) under redundancy control
- Mendeleev-nr — training: Training set for composition-based ML models (Roost, CrabNet) under redundancy control
- OFM-nr — training: Training set for structure-based ML models (ALIGNN, DeeperGATGNN) under redundancy control
- XRD-nr — training: Training set for structure-based ML models (ALIGNN, DeeperGATGNN) under redundancy control
