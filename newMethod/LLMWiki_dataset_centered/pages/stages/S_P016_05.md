# Stage: UMAP-based representational domain identification

- Stage ID: `S_P016_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P016_01` — probing out-of-distribution generalization in machine learning for materials

## Goal

To distinguish statistically OOD from representationally OOD test data by projecting learned embeddings or descriptors into low-dimensional space and estimating kernel density.

## Input

- learned embeddings (ALIGNN, GMP)
- handcrafted descriptors (XGB, RF)
- training set embeddings/descriptors

## Output

- representationally ID/OOD classification for each test sample

## Datasets used

- None stated

## Evidence

- P016, PDF page 5, Inspecting materials representations: "We propose to deﬁne and distinguish two types of OOD. A test set is considered statistically OOD if the statistical distribution of one or more attributes differs from the training set, whereas a test set is considered representationally OOD if the test data are outside the region of the training set when viewed from the high-dimensional representation space."
- P016, PDF page 5, Inspecting materials representations: "Uniform Manifold Approximation and Projection (UMAP) is used to project the high-dimensional materials representations to a two-dimensional plane... For each OOD task, we apply a Gaussian kernel to the training data and evaluate the kernel density estimate of the training data for every test data point in the UMAP embedding space. Test data points with high/low density estimates are considered as representationally ID/OOD data."
