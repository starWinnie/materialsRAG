# Stage: feature selection via correlation filtering and importance ranking

- Stage ID: `S_P036_05`
- Stage type: `candidate_screening`
- Stage order: 5
- Task: `T_P036_01` — predicting the experimental band gap values of HOIPs

## Goal

To reduce dimensionality and redundancy by removing highly correlated features and selecting the top 7 most important physical features using Pearson correlation and GBRT feature importance.

## Input

- 27 new features

## Output

- 7 best physical features (e.g., χB−X, μ, EAB−X, IRB, IRA−X, IRA+X, dX)

## Datasets used

- 610-data-point HOIP dataset — training: used to perform correlation filtering and GBRT-based feature importance ranking for subfeature selection

## Evidence

- P036, PDF page 3, METHODS: "Those features with a Pearson correlation coefficient greater than 0.95 are considered as highly correlated ones and are thus classified into one group; only one of the features was retained for each group. This is chosen according to the strength of its physical association with the band gap. ... After that, 11 groups of highly correlated features were identified, and 11 features are retained as listed in Table 1. ... To further remove the redundant feature to avoid dimensional disasters, we then used the GBRT algorithm to evaluate the accuracy of the model using different subfeatures, the subfeatures selected each time are in a decreasing order of feature importance, and the RMSEs of training and test sets are used as the evaluation metric ... we chose the top 7 features in ranked feature importance as input variables ... and the final GBRT-P model with an RMSE of 0.059 eV for the test set."
