# Stage: predicting flow strength from DFT-computed predictors

- Stage ID: `S_P014_09`
- Stage type: `computational_validation`
- Stage order: 9
- Task: `T_P014_01` — predicting plastic flow strength from small-scale indicator properties

## Goal

Apply the trained regression model to first-principles (DFT) computed predictor values for seven FCC metals to obtain predicted plastic flow strength with error bounds.

## Input

- DFT-computed {111} surface energy, lattice constant, vacancy migration energy for Ag, Al, Au, Cu, Ni, Pd, Pt

## Output

- predicted plastic flow strength values for seven FCC metals
- comparison to MD strength quartiles

## Datasets used

- DFT-Computed Predictor Values for Seven FCC Metals — computational_validation: Providing DFT-computed predictor values ({111} surface energy, lattice constant, vacancy migration energy) for seven FCC metals to predict plastic flow strength using the trained regression model.
