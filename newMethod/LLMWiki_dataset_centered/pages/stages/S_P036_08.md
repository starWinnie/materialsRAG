# Stage: subfeature ablation analysis

- Stage ID: `S_P036_08`
- Stage type: `ablation_study`
- Stage order: 8
- Task: `T_P036_01` — predicting the experimental band gap values of HOIPs

## Goal

To quantify the impact of feature count on model accuracy by evaluating RMSE across increasing numbers of top-ranked features.

## Input

- GBRT-P model
- subsets of top-k features

## Output

- RMSE curve showing diminishing returns beyond 7 features

## Datasets used

- None stated

## Evidence

- P036, PDF page 5, METHODS: "Figure 3b shows the variation of GBRT-P accuracy with the number of subfeatures; the model accuracy is not significantly improved when the number of subfeatures is greater than 7, so we chose the top 7 features in ranked feature importance as input variables to reduce the complexity of the model without sacrificing the accuracy too much"
