# Task: structure-based out-of-distribution (OOD) materials property prediction

- Task ID: `T_P029_01`
- Canonical name: `structure_based_ood_materials_property_prediction`
- Paper: `P029`

## Objective

To evaluate and benchmark graph neural network models for predicting materials properties on test samples that are out-of-distribution—i.e., whose crystal structures or property values deviate significantly from the training set distribution.

## Material scope

- inorganic crystalline materials

## Target properties

- refractive index
- shear modulus
- formation energy

## Constraints

- test sets must be out-of-distribution relative to training sets
- evaluation must reflect real-world discovery of novel outlier materials

## Input requirements

- crystal structure representations (e.g., crystal graphs, OFM features)

## Output goal

- predicted scalar property value (e.g., MAE in eV/unit cell, log10(GPa), unitless)

## Research stages

1. selection of three benchmark datasets from MatBench (`data_acquisition`)
2. generation of five OOD test set splits per dataset (`data_preparation`)
3. training of eight GNN models on each OOD fold (`model_training`)
4. evaluation of model performance using mean absolute error (MAE) (`model_evaluation`)
5. comparison of OOD performance against MatBench i.i.d. baselines (`ablation_study`)
6. analysis of latent physical spaces via t-SNE (`computational_validation`)
