# Task: crystal tensor property prediction

- Task ID: `T_P020_01`
- Canonical name: `crystal_tensor_property_prediction`
- Paper: `P020`

## Objective

predicting the Tensor properties of crystals, such as the dielectric tensor ε ∈R3×3, piezoelectric tensor e ∈R3×3×3, and elastic tensor C ∈R3×3×3×3

## Material scope

- crystalline materials

## Target properties

- dielectric tensor
- piezoelectric tensor
- elastic tensor

## Constraints

- O(3) equivariance
- invariance to crystal space groups
- symmetry constraints from Neumann's Principle

## Input requirements

- crystal structure M = (A, P, L)

## Output goal

- tensor matrix forms of dielectric, piezoelectric, and elastic tensors that fully respect intrinsic crystal symmetries

## Research stages

1. curating a dataset encompassing dielectric, piezoelectric, and elastic tensors (`data_acquisition`)
2. crystal graph construction (`data_preparation`)
3. crystal-level equivariant feature extraction (`model_training`)
4. equivariant tensor property prediction (`model_training`)
5. crystal symmetry enforcement (`model_training`)
6. evaluation using tailored metrics (`model_evaluation`)
7. ablation studies on component importance (`ablation_study`)

## Dataset uses

- curating a dataset encompassing dielectric, piezoelectric, and elastic tensors: Curated Crystal Tensor Property Dataset (training, DU_curated_crystal_tensor_property_dataset)
- curating a dataset encompassing dielectric, piezoelectric, and elastic tensors: JARVIS-DFT (source, DU_jarvis_dft)
