# Task: predicting plastic flow strength from small-scale indicator properties

- Task ID: `T_P014_01`
- Canonical name: `predict_plastic_flow_strength_from_small_scale_indicators`
- Paper: `P014`

## Objective

Predict large-scale plastic flow strength using regression on small-scale indicator properties computed with the same interatomic potential.

## Material scope

- FCC metals

## Target properties

- plastic flow strength

## Constraints

- statistical pool of interatomic potentials
- same IP used for both large- and small-scale computations
- FP calculations limited to ≤10² atoms

## Input requirements

- small-scale indicator properties (e.g., elastic constants, surface energies, vacancy formation/migration energies) computed with same IP

## Output goal

- predicted plastic flow strength with quantified statistical error bounds

## Research stages

1. collecting MD strength data and small-scale indicator properties from OpenKIM (`data_acquisition`)
2. excluding IPs with numerical instabilities or anomalous crystal response (`candidate_screening`)
3. excluding unreliable or missing small-scale indicator properties (`candidate_screening`)
4. imputing missing or unreasonable small-scale property values (`data_preparation`)
5. developing new vacancy-related indicator properties (`candidate_generation`)
6. selecting top-performing predictor combinations via k-fold cross-validation (`candidate_screening`)
7. fitting multi-linear regression model on selected predictors (`model_training`)
8. estimating prediction error using leave-one-out cross-validation (`model_evaluation`)
9. predicting flow strength from DFT-computed predictors (`computational_validation`)

## Evidence

- P014, PDF page 1: "Here we explore covariance between predictions of metal plasticity, from 178 large-scale (~108 atoms) molecular dynamics (MD) simulations, and a variety of indicator properties computed at small-scales (≤102 atoms). All simulations use the same 178 IPs. In a manner similar to statistical studies in public health, we analyze correlations of strength with indicators, identify the best predictor properties, and build a cross-scale “strength-on-predictors” regression model."
