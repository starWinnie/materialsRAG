# Task: Dielectric tensor prediction for inorganic materials

- Task ID: `T_P019_01`
- Canonical name: `dielectric_tensor_prediction`
- Paper: `P019`

## Objective

Predict the three types of dielectric tensors, ε∞ij, ε0ij and εij, for inorganic materials across 72 supported elements with the equivariance to the input structure.

## Material scope

- inorganic materials

## Target properties

- dielectric tensor
- electronic dielectric tensor
- ionic dielectric tensor
- total dielectric tensor

## Constraints

- O(3) equivariance
- thermodynamic stability (for screening)

## Input requirements

- crystal structure graph representation
- atomic numbers and positions
- 72 supported elements

## Output goal

- 3 × 3 dielectric tensor preserving rotational/reflective equivariance

## Research stages

1. Data acquisition from Materials Project (`data_acquisition`)
2. Dataset cleaning and filtering (`data_preparation`)
3. Training DTNet with transfer learning from PFP (`model_training`)
4. Benchmarking DTNet against state-of-the-art models (`model_evaluation`)
5. Preparation of candidate structures for virtual screening (`candidate_generation`)
6. Iterative active learning virtual screening (`candidate_screening`)
7. DFPT validation of screened candidates (`computational_validation`)

## Dataset uses

- Benchmarking DTNet against state-of-the-art models: Matbench dielectric task dataset (benchmark, DU_matbench_dielectric_task_dataset)
- Preparation of candidate structures for virtual screening: Materials Project candidate set for virtual screening (candidate_pool, DU_materials_project_candidate_set_for_virtual_screening)
- DFPT validation of screened candidates: Materials Project candidate set for virtual screening (computational_validation, DU_materials_project_candidate_set_for_virtual_screening)
- Dataset cleaning and filtering: Materials Project cleaned dielectric subset (training, DU_materials_project_cleaned_dielectric_subset)
- Benchmarking DTNet against state-of-the-art models: Materials Project cleaned dielectric subset (benchmark, DU_materials_project_cleaned_dielectric_subset)
- Data acquisition from Materials Project: Materials Project v2023.11.1 dielectric dataset (source, DU_materials_project_v2023_11_1_dielectric_dataset)
