# Task: benchmarking of materials design methods

- Task ID: `T_P028_01`
- Canonical name: `materials_design_method_benchmarking`
- Paper: `P028`

## Objective

to provide a comprehensive framework for systematic, reproducible, transparent, and unbiased scientific development through large-scale benchmarking of materials design methods

## Material scope

- materials

## Target properties

- formation energy
- bandgap
- bulk modulus
- forces
- Voigt bulk modulus
- exfoliation energy
- CO2 adsorption
- heat capacity
- solar cell efficiencies
- superconducting transition temperatures
- dielectric functions
- electron bandstructures
- phonon spectra
- strain-stress
- magnetometry
- XRD
- vibroscopy
- scanning electron microscopy
- transition electron microscopy

## Constraints

- benchmarks must have digital object identifier (DOI) from peer-reviewed article
- contributions must include run script, metadata file, and be reproducible
- experimental data used as reference where available
- high-fidelity computational methods used as reference when experimental data unavailable

## Input requirements

- well-characterized/well-known samples/tasks with DOI/peer-reviewed article links
- scripts/metadata easily available to reproduce results
- reference datasets in json.zip format
- contributions in csv.zip format with matching test identifiers

## Output goal

- leaderboard rankings by performance metric (e.g., MAE)
- comparative analysis across methods and categories
- interactive plots and tools for method comparison
- identification of material space requiring high-fidelity methods
- error estimation and validation of electronic structure methods

## Research stages

1. populating reference benchmark datasets (`data_acquisition`)
2. generating benchmark datasets with defined data splits (`data_preparation`)
3. user submission of methods and models (`candidate_generation`)
4. computing performance metrics against reference benchmarks (`model_evaluation`)
5. reproducing contributions via automated scripts and infrastructure (`computational_validation`)
6. inter-laboratory round-robin experimental benchmarking (`experimental_validation`)
