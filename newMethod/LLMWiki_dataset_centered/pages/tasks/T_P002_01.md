# Task: developing a single machine learning architecture that is capable of adapting its weights automatically to enforce invariance to any input space group

- Task ID: `T_P002_01`
- Canonical name: `space_group_invariant_architecture_development`
- Paper: `P002`

## Objective

To develop a single, adaptive neural architecture that enforces exact invariance to any of the 230 crystallographic space groups by automatically adapting its weights based on the input group.

## Material scope

- crystalline solids
- crystals

## Target properties

- material property prediction
- orbit distance
- zero-shot generalization to unseen space groups

## Constraints

- exact invariance to any space group
- weight sharing across all 230 space groups
- overcoming data sparsity for rare groups

## Input requirements

- atomic positions
- lattice vectors
- space group identifier (1-230)

## Output goal

- G-invariant positional encodings
- G-invariant material property predictions
- zero-shot generalization capability

## Research stages

1. using data from the Materials Project (`data_acquisition`)
2. constructing synthetic dataset for orbit distance validation (`data_preparation`)
3. deriving analytical constraints on Fourier coefficients (`candidate_generation`)
4. constructing symmetry-adapted Fourier basis via dual graph representation (`candidate_generation`)
5. pretraining the G-invariant positional encoding module (`model_training`)
6. training the full Crystal Fourier Transformer (CFT) for material property prediction (`model_training`)
7. evaluating CFT's performance on material property prediction benchmarks (`model_evaluation`)
8. comparing CFT with and without pretraining of positional encodings (`ablation_study`)
9. performing zero-shot generalization to unseen space groups (`experimental_validation`)
