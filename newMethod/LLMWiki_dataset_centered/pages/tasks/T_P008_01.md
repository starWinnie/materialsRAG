# Task: identifying semiconductors with ultralow lattice thermal conductivity

- Task ID: `T_P008_01`
- Canonical name: `identify_semiconductors_with_ultralow_lattice_thermal_conductivity`
- Paper: `P008`

## Objective

Identify semiconductors exhibiting ultralow lattice thermal conductivity (κL) for potential thermoelectric applications.

## Material scope

- semiconductors

## Target properties

- ultralow lattice thermal conductivity (κL)

## Constraints

- thermodynamic stability (Ehull ≤ 0.05 eV/atom)
- band gap 0.1–2 eV
- unit cell atoms < 20
- elements < 4
- exclude H, lanthanides, actinides

## Input requirements

- chemical composition
- crystal structure
- thermodynamic stability data
- band gap data

## Output goal

- list of candidate semiconductors with ultralow κL
- discovery of new factor governing structural anharmonicity

## Research stages

1. obtaining material dataset from Materials Project database (`data_acquisition`)
2. preliminary high-throughput screening (`data_preparation`)
3. unsupervised learning for clustering materials with similar κL (`candidate_generation`)
4. high-throughput calculation of κPET values for second-level dataset (`label_generation`)
5. statistical analysis and candidate selection from labeled local database (`candidate_screening`)
6. first-principles validation of selected candidates (`computational_validation`)
7. training interpretable supervised classification model (`model_training`)
8. evaluation of classification model performance (`model_evaluation`)
9. interpretable analysis using SHAP to discover governing descriptors (`ablation_study`)
