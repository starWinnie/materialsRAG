# Task: ML-guided materials discovery

- Task ID: `T_P004_01`
- Canonical name: `ml_guided_materials_discovery`
- Paper: `P004`

## Objective

Accelerate high-throughput computational search for thermodynamically stable inorganic crystals using machine learning as pre-filters for DFT calculations.

## Material scope

- inorganic crystals

## Target properties

- thermodynamic stability
- distance to convex hull phase diagram

## Constraints

- prospective benchmarking
- use of unrelaxed structures as input
- avoid circular dependency with DFT relaxation

## Input requirements

- unrelaxed crystal structures

## Output goal

- classification of stability (on or below convex hull) and ranking of candidates by predicted hull distance

## Research stages

1. Acquisition of training data from Materials Project database (`data_acquisition`)
2. Cleaning and protostructure-based filtering of WBM test set (`data_preparation`)
3. Training of ML models on MP data (`model_training`)
4. Evaluation of models on WBM test set using classification and regression metrics (`model_evaluation`)
5. Ranking and screening of hypothetical materials by predicted hull distance (`candidate_screening`)

## Dataset uses

- Acquisition of training data from Materials Project database: Materials Project (source, DU_materials_project)
- Training of ML models on MP data: Materials Project (training, DU_materials_project)
- Training of ML models on MP data: MP-crystals-2022.10.28 (training, DU_mp_crystals_2022_10_28)
- Training of ML models on MP data: MPF.2021.2.8 dataset (training, DU_mpf_2021_2_8_dataset)
- Training of ML models on MP data: MPtrj dataset (training, DU_mptrj_dataset)
- Cleaning and protostructure-based filtering of WBM test set: Wang-Botti-Marques (WBM) dataset (source, DU_wang_botti_marques_wbm_dataset)
- Evaluation of models on WBM test set using classification and regression metrics: WBM unique prototype test set (test, DU_wbm_unique_prototype_test_set)
- Ranking and screening of hypothetical materials by predicted hull distance: WBM unique prototype test set (candidate_pool, DU_wbm_unique_prototype_test_set)
