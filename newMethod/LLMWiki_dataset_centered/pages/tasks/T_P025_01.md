# Task: charge density prediction

- Task ID: `T_P025_01`
- Canonical name: `charge_density_prediction`
- Paper: `P025`

## Objective

Predict electron charge density in atomic systems to accelerate and improve density functional theory (DFT) calculations

## Material scope

- molecules
- inorganic materials
- battery cathode materials
- crystals
- zeolites
- surfaces

## Target properties

- electron charge density

## Constraints

- must be E(3)-equivariant (rotation, translation, reflection invariant)
- must scale linearly with system size
- must generalize across the periodic table

## Input requirements

- atomic species
- atomic positions
- probe point locations
- optional periodic boundary cell

## Output goal

- predicted charge density value at each probe point

## Research stages

1. collecting DFT-computed charge density data (`data_acquisition`)
2. constructing atom-probe graphs (`data_preparation`)
3. training ChargE3Net with higher-order equivariant features (`model_training`)
4. evaluating charge density prediction accuracy (`model_evaluation`)
5. using predicted charge densities to accelerate DFT calculations (`computational_validation`)
6. analyzing impact of higher-order equivariant representations (`ablation_study`)

## Dataset uses

- collecting DFT-computed charge density data: GNoME (computational_validation, DU_gnome)
- collecting DFT-computed charge density data: Materials Project (training, DU_materials_project)
- collecting DFT-computed charge density data: NMC (training, DU_nmc)
- collecting DFT-computed charge density data: QM9 (training, DU_qm9)
