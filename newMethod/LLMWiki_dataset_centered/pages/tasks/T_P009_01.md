# Task: predicting the properties of crystalline materials

- Task ID: `T_P009_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P009`

## Objective

predicting physical and electronic properties of crystalline materials from their text descriptions

## Material scope

- crystalline materials

## Target properties

- band gap
- formation energy per atom
- energy above hull
- unit cell volume
- energy per atom
- whether the band gap is direct or indirect

## Constraints

- None stated

## Input requirements

- crystal text descriptions

## Output goal

- predicted numerical values for regression tasks (e.g., band gap in eV, volume in A³/cell) and class labels for classification tasks (e.g., direct/indirect band gap)

## Research stages

1. collecting crystal structure-description pairs from Materials Project (`data_acquisition`)
2. generating crystal text descriptions using Robocrystallographer (`data_preparation`)
3. preprocessing text descriptions (stopword removal, token replacement, [CLS] prepending) (`data_preparation`)
4. obtaining property labels from Materials Project database (`label_generation`)
5. fine-tuning T5 encoder on preprocessed text and property labels (`model_training`)
6. evaluating prediction performance on test set using MAE and AUC (`model_evaluation`)
7. assessing contribution of each preprocessing and architectural choice (`ablation_study`)

## Dataset uses

- collecting crystal structure-description pairs from Materials Project: Materials Project (source, DU_materials_project)
- generating crystal text descriptions using Robocrystallographer: Materials Project (source, DU_materials_project)
- obtaining property labels from Materials Project database: Materials Project (label_source, DU_materials_project)
- fine-tuning T5 encoder on preprocessed text and property labels: TextEdge (training, DU_textedge)
- evaluating prediction performance on test set using MAE and AUC: TextEdge (test, DU_textedge)
