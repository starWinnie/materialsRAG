# Task: Predicting thermodynamic stability of inorganic compounds

- Task ID: `T_P005_01`
- Canonical name: `predict_thermodynamic_stability_of_inorganic_compounds`
- Paper: `P005`

## Objective

Accurately predict whether an inorganic compound is thermodynamically stable (i.e., has negative decomposition energy ΔHd)

## Material scope

- inorganic compounds
- perovskite halides
- Li-containing oxides
- transition metal oxides
- two-dimensional materials
- double perovskite oxides

## Target properties

- thermodynamic stability
- decomposition energy (ΔHd)

## Constraints

- compounds must be inorganic crystalline solids
- stability defined as ΔHd < 0 meV/atom

## Input requirements

- chemical formula (elemental composition)
- electron configuration of constituent elements
- atomic properties (e.g., atomic number, radius, electronegativity)
- interatomic interaction features

## Output goal

- binary classification: stable vs. unstable
- regression output: ΔHd value

## Research stages

1. Collecting DFT-computed stability data from public materials databases (`data_acquisition`)
2. Preprocessing compositional and electronic-structure representations (`data_preparation`)
3. Deriving stability labels from decomposition energy (ΔHd) via convex hull analysis (`label_generation`)
4. Training base-level models (ECCNN, Magpie, Roost) and meta-level model (MLR) via stacked generalization (`model_training`)
5. Benchmarking ECSG against state-of-the-art models using multiple metrics (`model_evaluation`)
6. Ablation study to quantify contribution of each base model and stacking strategy (`ablation_study`)
7. Screening candidate materials in unexplored composition space (e.g., perovskites, 2D materials) (`candidate_screening`)
8. Validating predictions via first-principles DFT calculations (`computational_validation`)
