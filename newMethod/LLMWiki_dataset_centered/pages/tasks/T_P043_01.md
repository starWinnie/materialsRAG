# Task: correcting DFT-calculated formation enthalpy errors

- Task ID: `T_P043_01`
- Canonical name: `correct_dft_formation_enthalpy_errors`
- Paper: `P043`

## Objective

To systematically correct intrinsic energy resolution errors in DFT-calculated formation enthalpies to improve reliability of phase stability predictions, especially for ternary systems.

## Material scope

- binary alloys
- ternary alloys
- intermetallic compounds
- Al–Ni–Pd system
- Al–Ni–Ti system

## Target properties

- formation enthalpy
- phase stability

## Constraints

- limited training dataset
- physically meaningful feature set
- avoid overfitting
- maintain interpretability

## Input requirements

- DFT-calculated formation enthalpies
- experimental formation enthalpies
- elemental concentrations
- atomic numbers
- interaction terms

## Output goal

- corrected formation enthalpy (Hpred = HDFT − Hcorr)
- reduced RMSE vs experimental values

## Research stages

1. acquiring experimental formation enthalpy data (`data_acquisition`)
2. preparing structured feature set (`data_preparation`)
3. calculating enthalpy correction labels (Hcorr) (`label_generation`)
4. training neural network regressor (`model_training`)
5. evaluating model performance with cross-validation (`model_evaluation`)
6. comparing linear vs. neural network correction models (`candidate_screening`)

## Dataset uses

- calculating enthalpy correction labels (Hcorr): DFT-calculated formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (source, DU_dft_calculated_formation_enthalpy_dataset_for_alnipd_and_alniti_ternary_systems)
- training neural network regressor: DFT-calculated formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (training, DU_dft_calculated_formation_enthalpy_dataset_for_alnipd_and_alniti_ternary_systems)
- evaluating model performance with cross-validation: DFT-calculated formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (test, DU_dft_calculated_formation_enthalpy_dataset_for_alnipd_and_alniti_ternary_systems)
- acquiring experimental formation enthalpy data: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (label_source, DU_experimental_formation_enthalpy_dataset_for_alnipd_and_alniti_ternary_systems)
- calculating enthalpy correction labels (Hcorr): Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (label_source, DU_experimental_formation_enthalpy_dataset_for_alnipd_and_alniti_ternary_systems)
- training neural network regressor: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (training, DU_experimental_formation_enthalpy_dataset_for_alnipd_and_alniti_ternary_systems)
- evaluating model performance with cross-validation: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (test, DU_experimental_formation_enthalpy_dataset_for_alnipd_and_alniti_ternary_systems)
