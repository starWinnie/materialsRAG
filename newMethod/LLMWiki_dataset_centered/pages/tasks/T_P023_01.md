# Task: crystal property prediction

- Task ID: `T_P023_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P023`

## Objective

Predict a target property value y ∈ R based on the crystal’s 3D structure (A, F, L)

## Material scope

- crystalline materials

## Target properties

- formation energy
- bandgap (OPT)
- total energy
- Ehull
- bandgap (MBJ)
- bulk modulus (Kv)
- shear modulus (Gv)
- SLME (%)
- spillage

## Constraints

- limited labeled data due to expensive physical simulations or lab experiments
- must satisfy O(3) invariance and periodic translation invariance

## Input requirements

- 3D crystal structure represented as atom features A, fractional coordinates F, lattice matrix L

## Output goal

- predicted target property value y

## Research stages

1. collecting unlabeled crystal structure data for pre-training (`data_acquisition`)
2. collecting labeled crystal property data for fine-tuning and evaluation (`data_acquisition`)
3. pre-training via crystal structure reconstruction (`model_training`)
4. fine-tuning for crystal property prediction (`model_training`)
5. downstream task evaluation on JARVIS-DFT (`model_evaluation`)
6. ablation study on key design components (`ablation_study`)

## Dataset uses

- collecting labeled crystal property data for fine-tuning and evaluation: JARVIS-DFT (training, DU_jarvis_dft)
- downstream task evaluation on JARVIS-DFT: JARVIS-DFT (test, DU_jarvis_dft)
- ablation study on key design components: JARVIS-DFT (benchmark, DU_jarvis_dft)
- collecting unlabeled crystal structure data for pre-training: Materials Project (source, DU_materials_project)
- collecting unlabeled crystal structure data for pre-training: Open Quantum Materials Database (OQMD) (source, DU_oqmd)
- collecting labeled crystal property data for fine-tuning and evaluation: OQMD-EXP (training, DU_oqmd_exp)
