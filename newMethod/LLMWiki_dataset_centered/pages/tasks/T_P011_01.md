# Task: crystal property prediction

- Task ID: `T_P011_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P011`

## Objective

Predicting the property of a given crystal structure C = {A, P, L} by learning a function f to predict its corresponding property.

## Material scope

- crystal structures

## Target properties

- formation energy
- band gap
- total energy
- energy above hull
- bulk moduli
- shear moduli

## Constraints

- labeled data is notably scarce and varies across different properties
- target properties lack comparability

## Input requirements

- crystal structure C = {B, L} characterized by basis B and Bravais lattice L
- basis B = {A, P} comprises atom types A and their respective positions P

## Output goal

- predicted property values (e.g., formation energy in eV/atom, band gap in eV)

## Research stages

1. acquiring unlabeled crystal structures (`data_acquisition`)
2. perturbing crystal representations (`data_preparation`)
3. pre-training denoising model (`model_training`)
4. fine-tuning on downstream property prediction (`model_training`)
5. evaluating property prediction accuracy (`model_evaluation`)

## Dataset uses

- acquiring unlabeled crystal structures: DPF Unlabeled Crystal Structures (pretraining, DU_dpf_unlabeled_crystal_structures)
- fine-tuning on downstream property prediction: JARVIS-DFT (training, DU_jarvis_dft)
- evaluating property prediction accuracy: JARVIS-DFT (test, DU_jarvis_dft)
- fine-tuning on downstream property prediction: Materials Project (training, DU_materials_project)
- evaluating property prediction accuracy: Materials Project (test, DU_materials_project)
