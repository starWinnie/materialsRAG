# Task: crystal material property prediction

- Task ID: `T_P021_01`
- Canonical name: `crystal_material_property_prediction`
- Paper: `P021`

## Objective

predict the target property value y, where y ∈R for regression tasks or y ∈{1, 2, · · · , C} for classification tasks with C classes by using crystal structure (A, P, L) as input.

## Material scope

- crystalline materials

## Target properties

- formation energy
- bandgap
- total energy
- Ehull
- bulk moduli
- shear moduli

## Constraints

- geometric completeness
- crystal passive symmetries (unit cell SE(3) invariance, unit cell SO(3) equivariance, periodic invariance)

## Input requirements

- crystal structure (A, P, L)

## Output goal

- target property value y

## Research stages

1. using three widely-used crystal benchmarks (`data_acquisition`)
2. constructing SE(3) invariant and SO(3) equivariant crystal graphs (`data_preparation`)
3. training iComFormer and eComFormer models (`model_training`)
4. evaluating predictive accuracy on crystal benchmarks (`model_evaluation`)
5. ablation studies on geometric completeness and model components (`ablation_study`)

## Dataset uses

- using three widely-used crystal benchmarks: JARVIS-DFT (source, DU_jarvis_dft)
- evaluating predictive accuracy on crystal benchmarks: JARVIS-DFT (benchmark, DU_jarvis_dft)
- ablation studies on geometric completeness and model components: JARVIS-DFT (screening, DU_jarvis_dft)
- using three widely-used crystal benchmarks: Matbench (source, DU_matbench)
- evaluating predictive accuracy on crystal benchmarks: Matbench (benchmark, DU_matbench)
- using three widely-used crystal benchmarks: Materials Project (source, DU_materials_project)
- evaluating predictive accuracy on crystal benchmarks: Materials Project (benchmark, DU_materials_project)
