# Task: dataset redundancy control for material property prediction

- Task ID: `T_P026_01`
- Canonical name: `dataset_redundancy_control`
- Paper: `P026`

## Objective

Reduce sample redundancy in material datasets to enable objective, realistic evaluation of ML models’ true predictive capability—particularly extrapolation and out-of-distribution performance—by preventing information leakage between training and test sets.

## Material scope

- inorganic crystalline materials
- perovskites (e.g., SrTiO3)
- Materials Project database entries
- Open Quantum Materials Database (OQMD) entries

## Target properties

- formation energy
- band gap

## Constraints

- avoid overestimation of ML model performance
- preserve coverage of composition/structure space
- enable fair comparison across models and properties
- support both composition-based and structure-based inputs

## Input requirements

- material compositions (e.g., chemical formulas)
- crystal structures (e.g., CIF files)
- distance metrics (e.g., Mendeleev, MatScholar, XRD, OFM)

## Output goal

- non-redundant training/validation/test splits
- datasets where no pair of samples exceeds a user-defined similarity threshold

## Research stages

1. MD-HIT-composition redundancy reduction (`data_preparation`)
2. MD-HIT-structure redundancy reduction (`data_preparation`)
3. download and curate Materials Project datasets (`data_acquisition`)
4. evaluate ML model performance on redundancy-controlled splits (`model_evaluation`)
5. validate OOD generalization improvement (`computational_validation`)
