# Task: materials property prediction

- Task ID: `T_P024_01`
- Canonical name: `materials_property_prediction`
- Paper: `P024`

## Objective

To accurately predict materials properties using crystal structure information, especially when training data is sparse.

## Material scope

- 3D materials
- 2D materials
- inorganic materials
- organic materials
- computational materials
- experimental materials

## Target properties

- formation energy
- band gap
- dielectric constant
- piezoelectric tensor
- exfoliation energy
- elastic tensor components
- Poisson ratio
- shear modulus
- bulk modulus
- electron effective mass
- optical properties
- magnetic properties
- vibrational properties
- electronic properties

## Constraints

- small dataset size
- cross-property transfer
- cross-materials class transfer (e.g., crystalline to molecular)
- extrapolation capability

## Input requirements

- crystal structure files (e.g., POSCAR)
- atomic positions
- lattice geometry
- composition

## Output goal

- numerical prediction of target property value (e.g., eV, GPa, Å, μB)

## Research stages

1. acquisition of diverse materials datasets (`data_acquisition`)
2. preprocessing of structure files for GNN input (`data_preparation`)
3. training of source model (ALIGNN) on large dataset (`model_training`)
4. generation of transfer learning models (fine-tuning and feature extraction) (`candidate_generation`)
5. evaluation of TL and scratch models on holdout test sets (`model_evaluation`)
6. analysis of feature type impact and dataset-size dependency (`ablation_study`)
