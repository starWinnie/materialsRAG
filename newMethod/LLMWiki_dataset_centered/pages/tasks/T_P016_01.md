# Task: probing out-of-distribution generalization in machine learning for materials

- Task ID: `T_P016_01`
- Canonical name: `probing_out_of_distribution_generalization`
- Paper: `P016`

## Objective

To systematically examine the performance of various ML methods across over 700 OOD tasks within large materials datasets and identify whether heuristic OOD definitions reflect true extrapolation or merely interpolation.

## Material scope

- crystalline solids

## Target properties

- formation energy
- band gap
- bulk modulus

## Constraints

- OOD tasks must have at least 200 test samples
- test sets must differ statistically from training sets in one or more attributes (e.g., element, period, group, space group, point group, crystal system)

## Input requirements

- ab initio-derived materials databases (JARVIS, Materials Project, OQMD)
- materials representations (embeddings or descriptors)
- OOD splitting criteria based on chemistry or structural symmetry

## Output goal

- quantified OOD generalization performance (MAE, R2) per task
- identification of representationally ID vs. OOD test data
- characterization of scaling behavior (training time/size effects) for different OOD regimes

## Research stages

1. selection of ab initio-derived materials databases (`data_acquisition`)
2. definition of OOD tasks using six criteria (`candidate_generation`)
3. training of representative ML models on each OOD task (`model_training`)
4. evaluation of OOD performance using MAE and R2 metrics (`model_evaluation`)
5. UMAP-based representational domain identification (`computational_validation`)
6. analysis of scaling effects (training time and size) on OOD performance (`ablation_study`)
7. SHAP-based bias source identification for leave-one-element-out tasks (`candidate_screening`)

## Dataset uses

- selection of ab initio-derived materials databases: JARVIS-DFT (source, DU_jarvis_dft)
- selection of ab initio-derived materials databases: Materials Project (source, DU_materials_project)
- selection of ab initio-derived materials databases: Open Quantum Materials Database (OQMD) (source, DU_oqmd)
