## Research summary

The paper proposes CrysDiff, a diffusion-based pretrain-finetune framework to address data scarcity in crystal property prediction. It pre-trains on abundant unlabeled 3D crystal structures via self-supervised crystal structure reconstruction (diffusing and denoising lattice L and fractional coordinates F), then fine-tunes on sparse labeled data to predict target properties (e.g., formation energy, bandgap). The method enforces crystal symmetries (O(3) invariance, periodic translation invariance) using an EGNN-based denoising model throughout both phases.
