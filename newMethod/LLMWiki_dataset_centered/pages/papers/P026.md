# Paper: MD-HIT: Machine learning for material property prediction with dataset redundancy control

## Research summary

This paper addresses the problem of overestimated machine learning model performance in materials science due to dataset redundancy—i.e., highly similar materials in training and test sets causing information leakage. It proposes MD-HIT, a redundancy reduction algorithm inspired by bioinformatics' CD-HIT, with two variants: MD-HIT-composition (using composition-based distance metrics like Mendeleev and MatScholar) and MD-HIT-structure (using structure-based metrics like XRD and OFM features). The authors apply MD-HIT to Materials Project datasets for formation energy and band gap prediction, demonstrating that redundancy-controlled splits yield lower but more realistic and generalizable (especially out-of-distribution) ML performance compared to standard random splits.
