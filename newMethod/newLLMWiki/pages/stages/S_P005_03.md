# Stage: Assigning stability labels based on decomposition energy thresholds

- Stage ID: `S_P005_03`
- Stage type: `label_generation`
- Stage order: 3
- Task: `T_P005_01` — Predicting thermodynamic stability of inorganic compounds

## Goal

Generate binary stability labels from DFT-derived ΔHd values

## Input

- decomposition energy (ΔHd) values from MP/OQMD/JARVIS

## Output

- binary labels: stable (ΔHd < 0 meV/atom) or unstable

## Datasets used

- Materials Project — label_source: Assigning stability labels based on decomposition energy thresholds
- Perovskite Halides Dataset — label_source: Assigning stability labels based on decomposition energy thresholds
- Li-containing Oxides Dataset — label_source: Assigning stability labels based on decomposition energy thresholds
- Transition Metal Oxides Dataset — label_source: Assigning stability labels based on decomposition energy thresholds

## Evidence

- P005, PDF page 11, Methods: "Compounds with a ΔHd below 0 meV/atom were considered stable and are labeled accordingly."
- P005, PDF page 4: "we slightly relax the threshold restriction when classifying materials stability. Consequently, we utilize thresholds of 25 meV/atom and 40 meV/atom to assign stability labels in the data set."
