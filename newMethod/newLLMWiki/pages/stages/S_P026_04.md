# Stage: evaluate ML model performance on redundancy-controlled datasets

- Stage ID: `S_P026_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P026_01` — dataset redundancy control for material property prediction

## Goal

Assess how redundancy control affects prediction performance (R2, MAE) of ML models on random-split and OOD test sets

## Input

- non-redundant datasets
- ML models (Roost, CrabNet, ALIGNN, DeeperGATGNN)
- evaluation metrics (MAE, R2)

## Output

- performance scores showing degradation with increasing redundancy control
- OOD performance comparison (e.g., Roostnr vs Roostred)

## Datasets used

- Mendeleev-nr — test: Evaluate ML model performance on redundancy-controlled datasets
- Matscholar-nr — test: Evaluate ML model performance on redundancy-controlled datasets
- XRD-nr — test: Evaluate ML model performance on redundancy-controlled datasets
- OFM-nr — test: Evaluate ML model performance on redundancy-controlled datasets

## Evidence

- P026, PDF page 1: "Applying MD-HIT to composition- and structure-based formation energy and band gap prediction problems, we demonstrate that with redundancy control, the prediction performances of the ML models on test sets tend to have relatively lower performance compared to the model with high redundancy, but better reflect models’ true prediction capability."
