# Stage: transfer learning via fine-tuning on target datasets

- Stage ID: `S_P024_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P024_01` — materials property prediction

## Goal

To adapt the pre-trained ALIGNN source model to each target dataset by initializing weights from the source model and refining them on target data.

## Input

- pre-trained ALIGNN source model
- target dataset (e.g., JARVIS-3D property)
- target structure files
- target property labels

## Output

- fine-tuned target model

## Datasets used

- JARVIS-DFT 3D — training: transfer learning via fine-tuning on target datasets
- JARVIS-DFT 2D — training: transfer learning via fine-tuning on target datasets
- Flla — training: transfer learning via fine-tuning on target datasets
- Dielectric Constant — training: transfer learning via fine-tuning on target datasets
- Piezoelectric Tensor — training: transfer learning via fine-tuning on target datasets
- Experimental Formation Energy — training: transfer learning via fine-tuning on target datasets
- Kingsbury Experimental Formation Energy — training: transfer learning via fine-tuning on target datasets
- Kingsbury Experimental Bandgap — training: transfer learning via fine-tuning on target datasets
- Harvard Organic Photovoltaic Dataset — training: transfer learning via fine-tuning on target datasets
