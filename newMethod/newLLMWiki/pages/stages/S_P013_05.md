# Stage: benchmarking against state-of-the-art models on 8 property datasets

- Stage ID: `S_P013_05`
- Stage type: `model_evaluation`
- Stage order: 5
- Task: `T_P013_01` — materials property prediction

## Goal

evaluate predictive performance using mean absolute error (MAE) across 8 property regression tasks

## Input

- CrysCo and CrysCoT predictions
- ground truth DFT values

## Output

- MAE and MSD metrics for each property

## Datasets used

- MP21 Formation Energy Dataset — benchmark: benchmark CrysCo's performance on formation energy prediction
- MP21 Band Gap Dataset — benchmark: benchmark CrysCo's performance on band gap prediction
- MP21 Phonon Frequency Dataset — benchmark: benchmark CrysCo's performance on phonon frequency prediction
- MP21 Dielectric (Refractive Index) Dataset — benchmark: benchmark CrysCo's performance on refractive index prediction
- MP21 Elasticity log10(Shear Modulus) Dataset — benchmark: benchmark CrysCo's performance on log10 of shear modulus prediction
- MP21 Elasticity log10(Bulk Modulus) Dataset — benchmark: benchmark CrysCo's performance on log10 of bulk modulus prediction
- MP21 Energy Above Convex Hull Dataset — benchmark: benchmark CrysCo's performance on energy above convex hull prediction
- MP21 Fermi Energy Dataset — benchmark: benchmark CrysCo's performance on Fermi energy prediction

## Evidence

- P013, PDF page 4: "To benchmark CrysCo’s performance, we used 8 properties datasets (Table 1) that include material compositions, crystal structures, and tabulated physical and chemical descriptors as inputs. All properties are further described in the Supplementary Information (SI). We trained the CrysGNN and CoTAN networks separately, in order to assess the predictive capabilities of these individual components as well. We utilized nested 5-fold cross-validation to generate results, which were then compared with previously published state-of-the-art models, such as structure-based ALIGNN21, MEGNet17, CGCNN18, SchNet20, Matformer29, and DeeperGATGNN37."
