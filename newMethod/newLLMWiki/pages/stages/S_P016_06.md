# Stage: SHAP-based bias source identification for leave-one-element-out tasks

- Stage ID: `S_P016_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P016_01` — Probing out-of-distribution generalization in machine learning for materials

## Goal

To identify whether poor OOD performance stems from compositional or structural biases by analyzing feature contributions to prediction corrections.

## Input

- Prediction errors from first model
- Compositional and structural features

## Output

- SHAP contribution violin plots
- Quantification of compositional vs. structural bias magnitude

## Datasets used

- None stated

## Evidence

- P016, PDF page 2, Results: "We propose a SHAP-based (SHapley Additive exPlanations) method to identify the sources of biases. This involves training a second model to correct the model for each leave-one-element-out task and evaluating the contributions from compositional and structural features to the corrections."
- P016, PDF page 8, Methods: "The following procedure is proposed to identify the sources of biases in the models trained for the leave-one-element-out tasks. For each task, we use the model trained without element X to make predictions on the whole dataset. Then, we train a second model on the prediction errors of the first model on the whole dataset."
