# Stage: statistical analysis and candidate screening from local database

- Stage ID: `S_P008_05`
- Stage type: `candidate_screening`
- Stage order: 5
- Task: `T_P008_01` — identifying semiconductors with ultralow lattice thermal conductivity

## Goal

Analyze κPET distribution to recommend TE candidates and select specific materials for in-depth mechanism analysis.

## Input

- local database of 661 materials with κPET

## Output

- list of candidate materials with κPET ≤ 2 W/mK (Table S2)
- Cs2SnSe3 and Cs2GeSe3 selected for first-principles validation

## Datasets used

- local database — screening: Statistical analysis and candidate screening to identify materials with κPET ≤ 2 W/mK.
