# Stage: Validating symmetry invariance and embedding stability

- Stage ID: `S_P006_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P006_01` — Generating universal atomic embeddings (UAEs) for crystal property prediction

## Goal

Verify that ct-UAEs are invariant under rotation/translation and stable across augmentations via cosine similarity and Euclidean distance metrics.

## Input

- augmented crystal samples (rotated/translated)
- MT@3p model

## Output

- average cosine similarity (0.998)
- average Euclidean distance (0.275)

## Datasets used

- Materials Project — computational_validation: Validating symmetry invariance and embedding stability via data augmentation

## Evidence

- P006, PDF page 9, Crystal-symmetry restrictions and data augmentation: "To validate this assertion, firstly we used a stronger data augmentation method to train the MT@3p model on the MP* dataset. Then a group of crystals are randomly selected, and subjected to random augmentations through rotations and translations. The consistency of the output vectors from these augmented samples was assessed using pairwise cosine similarity and Euclidean distance. The trained MT@3p model achieved an average cosine similarity of 0.998 and an average Euclidean distance of 0.275, indicating that the output vectors were nearly identical across augmentations."
