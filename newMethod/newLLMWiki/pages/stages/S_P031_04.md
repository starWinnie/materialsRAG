# Stage: training DiffCSP-SC for inverse design

- Stage ID: `S_P031_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P031_01` — designing novel superconducting candidates

## Goal

Train a transformer-based equivariant diffusion model to generate crystal structures conditioned on high Tc

## Input

- SuperCon3D dataset (structures + Tc)
- pre-training dataset (1.14M crystals from Materials Project, OQMD, ICSD, Matgen)

## Output

- trained DiffCSP-SC model

## Datasets used

- SuperCon3D — training: Training DiffCSP-SC for inverse design, using SuperCon3D as the target dataset for fine-tuning after pre-training
- Materials Project, OQMD, Matgen, and ICSD pre-training pool — pretraining: Pre-training DiffCSP-SC on large-scale crystal structures to address limited diversity in SuperCon3D
