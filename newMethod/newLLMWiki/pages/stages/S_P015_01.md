# Stage: acquisition of polymer and perovskite datasets

- Stage ID: `S_P015_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To obtain computational material property datasets for training and evaluation.

## Input

- None stated

## Output

- 69,480 amorphous polymers with Cp and refractive index
- 1345 hybrid organic–inorganic perovskites with bandgaps

## Datasets used

- RadonPy polymer dataset — source: To acquire computational material property datasets for training and evaluation of polymer properties (Cp and refractive index).
- HOIP dataset — source: To acquire computational material property dataset for training and evaluation of perovskite bandgaps.

## Evidence

- P015, PDF page 8, Methods: "In the polymer-property prediction experiments, 69,480 samples of Cp and 68,700 samples of the refractive index were used for the amorphous homopolymers. The data were generated using RadonPy36, which is a Python tool to construct a workﬂow for fully automated calculations of various polymeric properties using all-atom MD simulations."
- P015, PDF page 10, Methods: "The HOIP dataset40,41 contains 1345 perovskite compounds and their properties, including bandgaps, dielectric constants, and relative energies, calculated using the density functional theory."
