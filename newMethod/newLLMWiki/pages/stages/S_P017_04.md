- Stage ID: `S_P017_04`
- Stage type: `candidate_screening`
- Stage order: 4
- Task: `T_P017_01` — Out-of-Distribution Property Prediction

## Goal

Identify top-performing candidates by selecting the top 30% of test samples with highest predicted property values and evaluating extrapolative precision and recall.

## Input

- OOD test set
- trained model predictions

## Output

- top OOD candidates
- extrapolative precision score
- OOD recall
