# Stage: feature extraction from pre-trained ALIGNN for target compounds

- Stage ID: `S_P024_05`
- Stage type: `candidate_generation`
- Stage order: 5
- Task: `T_P024_01` — materials property prediction

## Goal

To generate fixed-dimensional, structure-aware feature vectors (atom-bond-angle features) from the pre-trained ALIGNN model for each compound in the target dataset.

## Input

- pre-trained ALIGNN source model
- target structure files

## Output

- 256-dimensional atom-based feature vector per compound
- 256-dimensional bond-based feature vector per compound
- 256-dimensional angle-based feature vector per compound
- 768-dimensional concatenated atom-bond-angle feature vector per compound

## Datasets used

- JARVIS-DFT 3D — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- JARVIS-DFT 2D — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- Flla — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- Dielectric Constant — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- Piezoelectric Tensor — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- Experimental Formation Energy — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- Kingsbury Experimental Formation Energy — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- Kingsbury Experimental Bandgap — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
- Harvard Organic Photovoltaic Dataset — candidate_pool: feature extraction from pre-trained ALIGNN for target compounds
