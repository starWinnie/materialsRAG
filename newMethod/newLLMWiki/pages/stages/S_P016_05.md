# Stage: Representation space analysis using UMAP and kernel density estimation

- Stage ID: `S_P016_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P016_01` — Probing out-of-distribution generalization in machine learning for materials

## Goal

To distinguish statistically OOD tasks from representationally OOD tasks by projecting materials into embedding/descriptor space and estimating training data density.

## Input

- Model embeddings (ALIGNN, GMP)
- Tree ensemble descriptors (XGB)
- UMAP parameters

## Output

- UMAP projections
- Kernel density estimates for test points
- Classification of test data as representationally ID or OOD

## Datasets used

- None stated

## Evidence

- P016, PDF page 5: "Uniform Manifold Approximation and Projection (UMAP) is used to project the high-dimensional materials representations to a two-dimensional plane... For deep learning models, materials representations (embeddings) are automatically learned during the training; embeddings of new materials can then be derived by using the trained models."
- P016, PDF page 5: "For each OOD task, we apply a Gaussian kernel to the training data and evaluate the kernel density estimate of the training data for every test data point in the UMAP embedding space. Test data points with high/low density estimates are considered as representationally ID/OOD data."
