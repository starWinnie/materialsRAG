# Stage: Training Bilinear Transduction model on ID data with analogical loss

- Stage ID: `S_P017_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P017_01` — Out-of-Distribution Property Prediction

## Goal

Train a bilinear transductive predictor hθ(Δx, x) = fθ(Δx)gθ(x) to predict property values y_i from anchor x_j and difference Δx_ij = x_i − x_j, where y_j < y_i.

## Input

- training set with (x, y) pairs
- descriptor-based representations

## Output

- trained Bilinear Transduction model

## Datasets used

- None stated

- P017, PDF page 6, Methods: "During training, rather than predicting hθ : X → Y, predictor hθ : ΔX × X → Y predicts value y2 ∈ Dtr_Y for data point x2 ∈ Dtr_X given anchor point x1 ∈ Dtr_X and the difference between them Δx21 = x2 − x1 ∈ Dtr_ΔX."
- P017, PDF page 6, Algorithm 1: "Train: Train θ on loss L(θ) = Σn_i=1 Σj:yj < yi ℓ(hθ(xi − xj, xj), yi)"
