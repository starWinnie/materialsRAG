# Stage: Learning curve analysis for training time and training set size scaling

- Stage ID: `S_P016_07`
- Stage type: `model_evaluation`
- Stage order: 7
- Task: `T_P016_01` — Probing out-of-distribution generalization in machine learning for materials

## Goal

To empirically test neural scaling laws on representationally OOD vs. ID tasks by measuring how MAE changes with increasing training time or dataset size.

## Input

- Trained models
- OOD test sets
- Varying training durations and dataset sizes

## Output

- Learning curves (MAE vs. training time/size)
- Identification of adverse/marginal scaling effects on representationally OOD tasks

## Datasets used

- None stated

## Evidence

- P016, PDF page 5: "Here we perform an extensive examination on various OOD tasks and, intriguingly, ﬁnd distinct scaling effects among the OOD tasks. Speciﬁcally, neural scaling laws are found to be valid only for representationally ID generalization, while the scaling effects are marginally beneﬁcial or even adverse for representationally OOD generalization."
