# Stage: validating regression predictions against DFT-computed predictors

- Stage ID: `S_P014_08`
- Stage type: `computational_validation`
- Stage order: 8
- Task: `T_P014_01` — predicting plastic flow strength from small-scale indicator properties

## Goal

Apply the trained regression model to first-principles (DFT) computed small-scale predictors to estimate plastic flow strength and assess predictive capability.

## Input

- Trained 3-variable regression model
- DFT-computed {111} surface energy, lattice constant, and vacancy migration energy for seven FCC metals

## Output

- Predicted plastic flow strength values for Ag, Al, Au, Cu, Ni, Pd, Pt
- Prediction error bounds

## Datasets used

- DFT-computed predictors for seven FCC metals — computational_validation: Validate regression model predictions against first-principles computed small-scale predictors

Figure 5 shows the ﬂow strength of seven FCC metals Ag, Al, Au, Cu, Ni, Pd, and Pt, predicted by substituting into the regression model the three predictors computed for each metal using DFT (see the “Methods” section for the details of the DFT calculations and the SI for a table of DFT results). Assuming that the 153 IPs and the seven DFT models belong to the same statistical pool (see explanation above), these values represent what seven hypothetical MD simulations with DFT forces would have predicted if indeed they could be performed under the same simulation conditions as those performed with the IPs."
