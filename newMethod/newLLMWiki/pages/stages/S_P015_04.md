# Stage: meta-training of matching neural networks via extrapolative episodic training (E2T)

- Stage ID: `S_P015_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To train attention-based MNNs to learn the mapping y = f(x, S) across diverse extrapolative episodes.

## Input

- episodes (xi, yi, Si)
- embedding function ϕ
- kernel ridge regressor head

## Output

- trained meta-learner MNN

## Datasets used

- RadonPy polymer dataset — training: To train matching neural networks via extrapolative episodic training (E2T) using episodes with (x,y) sampled from one polymer class and support set S from the other 19.
- HOIP dataset — training: To train matching neural networks via extrapolative episodic training (E2T) using episodes with (x,y) sampled from one anion–cation combination and support set S from the remaining ten.
