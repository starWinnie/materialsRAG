# Stage: descriptor generation for materials

- Stage ID: `S_P015_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To encode material structures into fixed-dimensional numerical representations suitable for model input.

## Input

- chemical structure of polymer repeating unit
- crystal structure of perovskite

## Output

- 2048-dimensional Morgan fingerprint descriptor
- 32-dimensional latent vector from MPNN

## Datasets used

- RadonPy polymer dataset — source: To generate Morgan fingerprint descriptors for polymer repeating units.
- HOIP dataset — source: To generate MPNN-encoded latent vectors for crystal structures.

## Evidence

- P015, PDF page 3, Experimental results: "The chemical structure of a polymer repeating unit was encoded through Morgan ﬁngerprinting38,39 into a 2048-dimensionaldescriptor vector, which served as the input for a three-layer fullyconnected neural network (FCNN) employed as the embedding function ϕ of MNN."
- P015, PDF page 9, Methods: "The count-based Morgan ﬁngerprint38, a type of extended connectivity ﬁngerprint (ECFP)39, was utilized as a descriptor for the repeating unit of a homopolymer. The descriptor was calculated using RDKit55, with a radius of 3 and bit length of 2048."
- P015, PDF page 10, Methods: "The MPNN44 was employed as the encoder for the crystal structures in all models. The MPNN architecture was designed in a manner similar to that proposed by Na and Park42, with an embedding size of 32."
