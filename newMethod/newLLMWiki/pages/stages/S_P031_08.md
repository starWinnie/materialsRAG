# Stage: wet lab synthesis and Tc characterization

- Stage ID: `S_P031_08`
- Stage type: `experimental_validation`
- Stage order: 8
- Task: `T_P031_01` — designing novel superconducting candidates

## Goal

Synthesize top candidates experimentally and measure their actual Tc to close the R&D loop

## Input

- DFT-validated candidate structures

## Output

- experimentally measured Tc values added to SuperCon3D

## Datasets used

- None stated

## Evidence

- P031, PDF page 27, F Pipeline for Designing Real-world Superconductors.: "Fig. 8 presents a pipeline for designing SC., validating our dataset and models for real-world scenarios. We initially generate potential, ordered superconducting structures using the DiffCSP-SC model trained on the SuperCon3D database. Candidate materials are selected based on Tc values predicted by SODNet, followed by DFT verification to confirm the presence of superconducting electronic structures, such as VHS. Subsequently, selected candidates undergo wet lab synthesis, with Tc values characterized and recorded in the SuperCon3D database."
