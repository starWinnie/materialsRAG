# Stage: Preprocessing representations and splitting datasets into ID/OOD sets

- Stage ID: `S_P017_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P017_01` — Out-of-Distribution Property Prediction

## Goal

Prepare fixed descriptor-based representations (Oliynyk descriptors for solids, RDKit descriptors for molecules) and split data into training, ID validation, and OOD test sets where OOD samples are the top 5% highest property values.

## Input

- material compositions
- SMILES representations

## Output

- stoichiometry-based descriptors
- RDKit descriptor vectors
- training set
- ID validation set
- OOD test set

## Datasets used

- AFLOW — training: Train predictor models using stoichiometry-based representations for solids
- Matbench — training: Train predictor models using stoichiometry-based representations for solids
- Materials Project — training: Train predictor models using stoichiometry-based representations for solids
- MoleculeNet — training: Train predictor models using RDKit descriptors for molecules
- ESOL — training: Train predictor models using RDKit descriptors for molecules
- FreeSolv — training: Train predictor models using RDKit descriptors for molecules
- Lipophilicity — training: Train predictor models using RDKit descriptors for molecules
- BACE — training: Train predictor models using RDKit descriptors for molecules

## Evidence

- P017, PDF page 6, Methods: "Let X ⊂ Rn denote a representation space of data points, such as RDKit descriptors derived from Simplified Molecular Input Line Entry System (SMILES) for molecules, and the composition-based descriptors Oliynyk27 derived from elemental properties for solids."
- P017, PDF page 6, Methods: "We split the data into training, validation and test sets such that OOD test samples Dte_Y ⊂ Y are 5% of the data with the highest property values, an ID validation set is a random sample of 5% of the remaining data, and the training set Dtr = {(x, y)}n ⊂ X × Y is the rest."
