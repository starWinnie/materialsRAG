## Datasets used

- AFLOW — benchmark: Evaluate extrapolation capability on solid materials property prediction tasks
- Matbench — benchmark: Evaluate extrapolation capability on solid materials property prediction tasks
- Materials Project — benchmark: Evaluate extrapolation capability on solid materials property prediction tasks
- MoleculeNet — benchmark: Evaluate extrapolation capability on molecular graph-to-property prediction tasks
- ESOL — benchmark: Evaluate extrapolation capability on aqueous solubility prediction task

- Lipophilicity — benchmark: Evaluate extrapolation capability on lipophilicity prediction task
- BACE — benchmark: Evaluate extrapolation capability on binding affinity prediction task
