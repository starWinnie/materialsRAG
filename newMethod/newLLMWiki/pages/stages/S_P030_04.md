# Stage: benchmarking against baseline models on multiple datasets

- Stage ID: `S_P030_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P030_01` — charge density prediction

## Goal

Quantitatively evaluate prediction accuracy (NMAE) and computational efficiency (mol/min) on QM9, MD, and Cubic benchmarks.

## Input

- trained model
- test set charge densities
- hardware configuration

## Output

- NMAE scores
- efficiency metrics
- Pareto-optimal trade-off curves

## Datasets used

- QM9 charge density dataset — test: Benchmarking prediction accuracy (NMAE) and computational efficiency (mol/min) on the test split.
- MD charge density dataset — benchmark: Benchmarking prediction accuracy (NMAE) on molecular systems.
- Cubic charge density dataset — benchmark: Benchmarking prediction accuracy (NMAE) on crystalline materials.

## Evidence

- P030, PDF page 8, 4 Experiments: "We benchmark the prediction accuracy with the normalized mean absolute error... We benchmark the efficiency of different methods by the number of molecules predicted per minute (Mol. per min.) on a single NVIDIA A100-80GB-PCIe GPU for the QM9 test split."
- P030, PDF page 8, 4 Experiments: "The metrics for all methods are presented in Table 1... Our best-performing model... achieves an NMAE of 0.178 on the QM9 charge density test set... significantly outperforms ChargE3Net [15] — a probe-based method."
