# Stage: training ML models on MP data

- Stage ID: `S_P004_05`
- Stage type: `model_training`
- Stage order: 5
- Task: `T_P004_01` — ML-guided materials discovery

## Goal

Train diverse ML models—including universal interatomic potentials and energy-only predictors—on MP-derived data to predict relaxed energies from unrelaxed inputs.

## Input

- MP training set (energies, forces, stresses, magnetic moments)
- model architectures (e.g., EquiformerV2, MACE, CGCNN)

## Output

- trained ML models for IS2RE prediction

## Datasets used

- None stated

## Evidence

- P004, PDF page 6, Methods: "We propose an evaluation framework that places no constraints on the type of data a model is trained on as long as it would be available to a practitioner conducting a real materials discovery campaign... any subset of the energies, forces, stresses or any other properties that can be routinely extracted from DFT calculations... are valid training targets."
- P004, PDF page 7, Article: "Models may train on the complete set of relaxation frames, or any subset thereof such as the final relaxed structures. Any subsets of the energies, forces and stresses are valid training targets."
