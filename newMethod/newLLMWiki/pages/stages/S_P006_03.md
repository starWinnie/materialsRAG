# Stage: Generating ct-UAE tensors for downstream models

- Stage ID: `S_P006_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P006_01` — Generating universal atomic embeddings (UAEs) for crystal property prediction

## Goal

Extract atomic embedding tensors (ct-UAEs) from the pretrained CrystalTransformer and prepare them for integration into various back-end GNN models.

## Input

- pretrained CrystalTransformer model
- crystal inputs (atom types + coordinates)

## Output

- ct-UAE tensors (89 × 128 dimensional)
- frozen or fine-tuned embeddings

## Datasets used

- None stated

## Evidence

- P006, PDF page 2: "The obtained embeddings are then transferred to different DL models."
- P006, PDF page 3: "Subsequently, the extracted atomic embeddings are integrated into a CGCNN back-end model and trained on the original MP dataset, which results in CT-CGCNN, CG-CGCNN, ALI-CGCNN, and so on."
- P006, PDF page 4: "CTfreeze-CGCNN, which employs frozen pre-trained embeddings from the CrystalTransformer or ct-UAEs, achieves an MAE of 0.073 eV/atom for formation energy Ef and 0.358 eV for bandgap Eg."
