# Stage: redundancy reduction using MD-HIT-composition

- Stage ID: `S_P026_01`
- Stage type: `data_preparation`
- Stage order: 1
- Task: `T_P026_01` — dataset redundancy control for material property prediction

## Goal

Generate non-redundant composition dataset by iteratively selecting representative materials based on composition distance metrics

## Input

- material compositions
- ElMD package (Mendeleev/MatScholar similarity)
- distance threshold

## Output

- non-redundant composition dataset (e.g., Mendeleev-nr, Matscholar-nr)

## Datasets used

- Mendeleev-nr — training: Generate non-redundant composition dataset by iteratively selecting representative materials based on composition distance metrics
- Matscholar-nr — training: Generate non-redundant composition dataset by iteratively selecting representative materials based on composition distance metrics

## Evidence

- P026, PDF page 3, Results: "Our MD-HIT-composition and MD-HIT-structure redundancy reduction algorithms are designed based on this idea, utilizing greedy incremental algorithms. In our case, MD-HIT starts the selection process with a seed material (default to H2O) and then sorts the remaining materials by the number of atoms instead of the formula lengths. Subsequently, it classifies each material as redundant or representative, depending on its similarity to the existing representatives already selected into the cluster."
