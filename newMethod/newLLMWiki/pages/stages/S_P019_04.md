# Stage: Benchmarking against state-of-the-art models

- Stage ID: `S_P019_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P019_01` — Dielectric tensor prediction for inorganic materials

## Goal

Evaluate DTNet performance using MAEten, MAEmean-diag, MAEdiag, and MAEoff-diag metrics on test set and Matbench.

## Input

- test subset (10% of 6648 structures)
- Matbench dielectric task dataset

## Output

- MAEten = 0.368 for ε∞, 1.677 for ε0, 1.911 for ε
- MAE = 0.2371 on Matbench

## Datasets used

- Materials Project cleaned subset (6648 structures) — test: Evaluate DTNet performance using MAEten, MAEmean-diag, MAEdiag, and MAEoff-diag metrics.
- Matbench dielectric task dataset — benchmark: Benchmark DTNet against state-of-the-art models on standardized dielectric task.
