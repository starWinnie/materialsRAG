# Stage: Generation of OOD test sets using five methods

- Stage ID: `S_P029_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P029_01` — Structure-based out-of-distribution (OOD) materials property prediction

## Goal

Systematically construct test sets that are out-of-distribution with respect to the training set, simulating real-world discovery of novel/exceptional materials.

## Input

- preprocessed structural and property data

## Output

- LOCO test sets
- SparseXsingle test sets
- SparseYsingle test sets
- SparseXcluster test sets
- SparseYcluster test sets

## Datasets used

- None stated
