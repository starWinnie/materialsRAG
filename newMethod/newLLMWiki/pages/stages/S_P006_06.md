# Stage: Clustering and interpreting ct-UAEs via UMAP/K-means

- Stage ID: `S_P006_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P006_01` — Generating universal atomic embeddings (UAEs) for crystal property prediction

## Goal

Use unsupervised clustering to categorize elements based on ct-UAEs and link clusters to physical/chemical properties.

## Input

- ct-UAE tensors (89 × 128)
- UMAP dimensionality reduction
- K-means clustering

## Output

- three-element classes (A/B/C)
- violin plots of formation energy/bandgap/magnetization per class

## Datasets used

- Materials Project — screening: Clustering and interpreting ct-UAEs via UMAP/K-means on oxide compounds
