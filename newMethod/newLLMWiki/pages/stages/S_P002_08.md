# Stage: evaluating zero-shot generalization to unseen space groups

- Stage ID: `S_P002_08`
- Stage type: `model_evaluation`
- Stage order: 8
- Task: `T_P002_01` — developing a single machine learning architecture that is capable of adapting its weights automatically to enforce invariance to any input space group

## Goal

Measure the performance degradation of CFT when predicting properties for materials from space groups it was never trained on.

## Input

- CFT model trained only on non-centrosymmetric groups
- test set of materials from Ginv

## Output

- group-wise MAE gaps (∆MAEG) and group-balanced absolute performance gap (GB-Gap)

## Datasets used

- Materials Project — test: Measure the performance degradation of CFT when predicting properties for materials from space groups it was never trained on.
