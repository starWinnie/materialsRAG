# Stage: fine-tuning for downstream extrapolative domains

- Stage ID: `S_P015_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To adapt pretrained meta-learners to target domains with limited data, evaluating transferability and rapid adaptation.

## Input

- pretrained MNN
- small target-domain dataset

## Output

- fine-tuned predictor optimized for target domain

## Datasets used

- RadonPy polymer dataset — training: To fine-tune pretrained E2T models on target-domain polymer class data.
- HOIP dataset — training: To fine-tune pretrained E2T models on target-domain HOIP-GeF or HOIP-PbI data.

## Evidence

- P015, PDF page 6, Fine-tuning to extrapolative domains: "Fine-tuning was performed on the RadonPy dataset. In this experiment, a pretrained E2T model with a source data size of 38,000 was ﬁne-tuned on data from the target domain corresponding to a particular polymer class."
- P015, PDF page 11, Fine-tuning experiments: "An MNN pretrained by E2T with a source data size of 1248 (HOIP-GeF) or 1228 (HOIP-PbI) was ﬁne-tuned on data, including data from the target domain."
