# Stage: unsupervised learning for clustering materials with similar κL

- Stage ID: `S_P008_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P008_01` — identifying semiconductors with ultralow lattice thermal conductivity

## Goal

Group materials into clusters based on composition and structure descriptors to identify problem-specific clusters likely to contain ultralow κL materials.

## Input

- first-level dataset
- Magpie composition descriptors {E}
- Voronoi structure descriptors {S}
- PCA-reduced 83 principal components

## Output

- seven clusters (C1–C7)
- problem-specific clusters C1 and C2 (704 materials)

## Datasets used

- first-level dataset — source: Input for unsupervised learning to identify problem-specific clusters likely to contain ultralow κL materials.
- second-level dataset — candidate_pool: Problem-specific clusters selected for focused investigation based on similarity to known low-κL materials.
