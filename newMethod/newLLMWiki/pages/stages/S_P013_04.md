# Stage: transfer learning for data-scarce properties

- Stage ID: `S_P013_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P013_01` — materials property prediction

## Goal

fine-tune pre-trained model on data-scarce secondary properties using transfer learning

## Input

- pre-trained CrysCo model
- data-scarce property datasets (e.g., elastic moduli, phonons, dielectric)

## Output

- CrysCoT model (transfer-learned)

## Datasets used

- MP21 Formation Energy Dataset — pretraining: pre-train model on formation energy for transfer learning to data-scarce properties
- MP21 Energy Above Convex Hull Dataset — pretraining: pre-train model on energy above convex hull for transfer learning to data-scarce properties
