# Stage: Preprocessing composition and encoding electron configuration

- Stage ID: `S_P005_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P005_01` — Predicting thermodynamic stability of inorganic compounds

## Goal

Transform raw chemical formulas into structured inputs suitable for ML models

## Input

- chemical formulas
- elemental identities
- atomic counts

## Output

- encoded input matrices for ECCNN (118 × 168 × 8)
- statistical atomic features for Magpie
- graph representations for Roost

## Datasets used

- None stated
