# Stage: Evaluating ct-UAE transfer performance on property prediction

- Stage ID: `S_P006_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P006_01` — Generating universal atomic embeddings (UAEs) for crystal property prediction

## Goal

Quantify accuracy improvement (MAE, R²) when integrating ct-UAEs into various back-end models (CGCNN, ALIGNN, MEGNET) across multiple datasets and targets.

## Input

- ct-UAE tensors
- back-end models (CGCNN, ALIGNN, MEGNET)
- target property labels (Ef, Eg, E, magnetization)

## Output

- MAE scores
- R² values
- comparative tables (e.g., Table 1, Table 2, Table 3)

## Datasets used

- Materials Project — benchmark: Evaluating ct-UAE transfer performance on property prediction
- JARVIS-DFT — benchmark: Evaluating ct-UAE transfer performance on formation energy and bandgap prediction
- MC3D dataset — benchmark: Evaluating ct-UAE transfer performance on total energy prediction
- Hybrid Organic-Inorganic Perovskite (HOIP) dataset — benchmark: Evaluating ct-UAE transfer performance on formation energy prediction in hybrid perovskites

## Evidence

- P006, PDF page 1: "By performing experiments on widely-used materials database, our CrystalTransformer-based UAEs (ct-UAEs) are shown to accurately capture complex atomic features, leading to a 14% improvement in prediction accuracy on CGCNN and 18% on ALIGNN when using formation energies as the target, based on the Materials Project database."
- P006, PDF page 3: "Table 1 shows a comparative MAE analysis to evaluate the relative performance enhancements attributable to the front-end atomic embeddings, denoted as N-CGCNN in Table 1 (N means the front-end model described above)."
