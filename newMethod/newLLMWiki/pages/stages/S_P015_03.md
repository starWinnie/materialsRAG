# Stage: generation of extrapolative episodes

- Stage ID: `S_P015_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To construct training episodes where test instances (x, y) lie outside the support set S’s domain, enabling extrapolative learning.

## Input

- dataset D
- partitioning strategy by polymer class or cation/anion combinations

## Output

- episodes (xi, yi, Si) with extrapolative relationships

## Datasets used

- RadonPy polymer dataset — candidate_pool: To generate extrapolative episodes by partitioning across 20 polymer classes, sampling test instances from one class and support sets from the other 19.
- HOIP dataset — candidate_pool: To generate extrapolative episodes by partitioning into 12 anion–cation domains and sampling test instances from one domain and support sets from the remaining ten.

## Evidence

- P015, PDF page 2, Results: "Numerous episodes were generated from a given dataset D, each comprising a training set S and test set Q containing instances outside the training domain S."
- P015, PDF page 2, Results: "For a given dataset, we can generate a set of episodes for extrapolative learning with ﬂexible quantity and quality. This is considered a type of self-supervised learning."
- P015, PDF page 3, Experimental results: "In each step of E2T, a training instance on (x, y) was sampled from a randomly selected polymer class, whereas the support set S was entirely sampled from the 19 polymer classes, including interpolative and extrapolative episodes."
- P015, PDF page 10, Methods: "We classiﬁed the HOIP dataset into 12 categories (or domains) based on a combination of four inorganic anions and three cations. Data from 11 of the 12 categories were included in the training dataset D. To evaluate the model performance, 10% of the data in D were used for validation. In each step of E2T, a training instance at (x, y) was sampled from a randomly selected combination among the 11 anion–cation combinations, whereas the support set S with a size of m = 50 was sampled from the remaining ten combinations of anions and cations, resulting in the inclusion of only extrapolative episodes."
