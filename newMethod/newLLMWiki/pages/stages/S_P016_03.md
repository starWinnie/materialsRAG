# Stage: Training of representative ML models on each OOD task

- Stage ID: `S_P016_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P016_01` — Probing out-of-distribution generalization in machine learning for materials

## Goal

To train multiple ML architectures (tree ensembles, neural networks, GNNs, LLMs) on each OOD task using consistent hyperparameters.

## Input

- OOD tasks
- Matminer descriptors
- GMP features
- crystal graphs
- crystal text descriptions

## Output

- Trained RF, XGB, ALIGNN, GMP, LLM-Prop models for each OOD task

## Datasets used

- None stated

## Evidence

- P016, PDF page 2, Results: "OOD performance is evaluated by training a representative set of ML models, including (1) random forest (RF) and XGBoost (XGB) models with Matminer descriptors. (2) single neural network with Gaussian multipole (GMP) expansion on electron density (3) atomistic line graph neural network (ALIGNN), and (4) the large language model (LLM) based LLM-Prop with crystal text descriptions."
- P016, PDF page 8, Methods: "Performing hyperparameter tuning for each of over 700 OOD tasks for every model would be computationally impractical... Our strategy is to perform the hyperparameter tuning on an in-distribution validation set randomly sampled from the whole dataset; then we apply the same optimal hyperparameters to every OOD task."
