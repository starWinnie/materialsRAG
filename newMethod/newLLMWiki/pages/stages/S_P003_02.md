# Stage: spherical-harmonics decomposition of dielectric tensors

- Stage ID: `S_P003_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P003_01` — prediction of tensorial spectra

## Goal

Transform Cartesian dielectric tensors into spherical-harmonics basis to encode rotational symmetry

## Input

- Cartesian dielectric tensors
- spherical-harmonics basis

## Output

- frequency-dependent spherical-harmonic coefficients

## Datasets used

- Materials Project 1432-semiconductor dataset — label_source: Spherical-harmonics decomposition of Cartesian dielectric tensors to obtain frequency-dependent spherical-harmonic coefficients for training targets

- P003, PDF page 2, Results: "To predict the dielectric tensor using an equivariant neural network, we express it in the spherical-harmonics basis, which naturally encodes rotational symmetry."
