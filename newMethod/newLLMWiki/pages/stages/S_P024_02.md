## Goal

To convert raw crystal structure files (e.g., POSCAR) into structured graph representations suitable for ALIGNN input.

## Input

- structure file containing information on lattice geometry and the ionic positions of a compound

## Output

- atom-based features
- bond-based features
- angle-based features
