# Task: predicting plastic flow strength from small-scale indicator properties

- Task ID: `T_P014_01`
- Canonical name: `predict_plastic_flow_strength_from_small_scale_indicators`
- Paper: `P014`

## Objective

To predict large-scale plastic flow strength of FCC metals using statistical regression on computationally cheaper small-scale indicator properties that are covariant with the target property.

## Material scope

- FCC metals

## Target properties

- plastic flow strength

## Constraints

- Predictors must be computable at small scales (≤10² atoms) where FP calculations are feasible
- Regression model must generalize to first-principles (DFT) predictor values

## Input requirements

- Small-scale indicator properties computed with the same interatomic potential
- Large-scale MD-simulated flow strength values

## Output goal

- Predicted plastic flow strength value with quantified uncertainty bounds

## Research stages

1. collecting interatomic potential models and their precomputed properties (`data_acquisition`)
2. screening IP models for numerical and physical validity (`candidate_screening`)
3. cleaning and imputing missing or unreliable small-scale property data (`data_preparation`)
4. identifying and excluding SF-jammed IP models (`candidate_screening`)
5. developing new vacancy-related indicator properties (`candidate_generation`)
6. training multi-linear regression models on indicator properties (`model_training`)
7. evaluating regression model performance with cross-validation (`model_evaluation`)
8. validating regression predictions against DFT-computed predictors (`computational_validation`)
