# Task: predicting the properties of crystalline materials

- Task ID: `T_P009_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P009`

## Objective

Predict physical and electronic properties of crystalline materials from their text descriptions

## Material scope

- crystalline materials

## Target properties

- band gap
- formation energy per atom
- energy above hull
- unit cell volume
- energy per atom
- direct/indirect band gap indicator

## Constraints

- must use text descriptions as input
- must outperform GNN-based methods and MatBERT

## Input requirements

- crystal text descriptions generated by Robocrystallographer

## Output goal

- numerical values for regression tasks (e.g., band gap in eV, volume in A³/cell) and classification labels (e.g., direct/indirect band gap)

## Research stages

1. collecting dataset from Materials Project database (`data_acquisition`)
2. generating crystal text descriptions using Robocrystallographer (`data_preparation`)
3. preprocessing text descriptions (`data_preparation`)
4. extracting property labels from Materials Project (`label_generation`)
5. fine-tuning T5 encoder for property prediction (`model_training`)
6. evaluating performance against baselines (`model_evaluation`)

## Dataset uses

- collecting dataset from Materials Project database: Materials Project (source, DU_P009_001)
- generating crystal text descriptions using Robocrystallographer: TextEdge (source, DU_P009_002)
- extracting property labels from Materials Project: Materials Project (label_source, DU_P009_003)
- fine-tuning T5 encoder for property prediction: TextEdge (training, DU_P009_004)
- evaluating performance against baselines: TextEdge (test, DU_P009_005)
