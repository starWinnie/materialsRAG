# Task: Structure-based out-of-distribution (OOD) materials property prediction

- Task ID: `T_P029_01`
- Canonical name: `structure_based_ood_materials_property_prediction`
- Paper: `P029`

## Objective

To evaluate and benchmark graph neural network models for predicting materials properties on test samples that are out-of-distribution—i.e., whose crystal structures or property values deviate significantly from the training set distribution.

## Material scope

- inorganic materials
- crystalline solids
- perovskites
- dielectric materials
- elastic materials

## Target properties

- refractive index
- shear modulus
- formation energy

## Constraints

- test sets must be out-of-distribution relative to training set
- no labeled samples in target set
- evaluation must reflect real-world discovery of outlier/novel materials

## Input requirements

- crystal structure representations (e.g., crystal graphs, OFM features)
- property labels for training/validation sets

## Output goal

- predicted property value (scalar regression output) for each OOD test material

## Research stages

1. Selection and acquisition of three MatBench datasets (`data_acquisition`)
2. Preprocessing and representation of crystal structures (`data_preparation`)
3. Generation of OOD test sets using five methods (`candidate_generation`)
4. Training of eight GNN models on each train/validation split (`model_training`)
5. Evaluation of model performance on OOD test sets using MAE (`model_evaluation`)
6. Analysis of latent physical spaces via t-SNE (`computational_validation`)

## Dataset uses

- Selection and acquisition of three MatBench datasets: matbench_dielectric (source, DU_P029_001)
- Selection and acquisition of three MatBench datasets: matbench_log_gvrh (source, DU_P029_002)
- Selection and acquisition of three MatBench datasets: matbench_perovskites (source, DU_P029_003)
