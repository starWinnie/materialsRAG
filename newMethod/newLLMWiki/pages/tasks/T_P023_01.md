# Task: crystal property prediction

- Task ID: `T_P023_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P023`

## Objective

Predict a target property value y ∈ R based on its 3D crystal structure (A, F, L)

## Material scope

- crystalline materials

## Target properties

- formation energy
- bandgap
- total energy
- ehull
- bulk modulus
- shear modulus
- SLME
- spillage

## Constraints

- limited labeled data due to expensive physical simulations or lab experiments
- must respect O(3) invariance and periodic translation invariance

## Input requirements

- 3D crystal structure represented as atom features A, fractional coordinates F, and lattice matrix L

## Output goal

- predicted target property value y

## Research stages

1. collecting unlabeled crystal structure data (`data_acquisition`)
2. collecting labeled crystal property data (`data_acquisition`)
3. pre-training via crystal structure reconstruction (`model_training`)
4. fine-tuning for crystal property prediction (`model_training`)
5. downstream task evaluation (`model_evaluation`)

## Dataset uses

- collecting unlabeled crystal structure data: Materials Project (source, DU_P023_001)
- collecting unlabeled crystal structure data: Open Quantum Materials Database (OQMD) (source, DU_P023_002)
- collecting labeled crystal property data: JARVIS-DFT (training, DU_P023_003)
- collecting labeled crystal property data: OQMD-EXP (training, DU_P023_004)
- downstream task evaluation: JARVIS-DFT (test, DU_P023_005)
- downstream task evaluation: OQMD-EXP (test, DU_P023_006)
