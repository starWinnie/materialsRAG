# Task: ML-guided materials discovery

- Task ID: `T_P004_01`
- Canonical name: `ml_guided_materials_discovery`
- Paper: `P004`

## Objective

To accelerate high-throughput computational materials discovery by using machine learning models as efficient pre-filters for DFT calculations, specifically to identify thermodynamically stable inorganic crystals.

## Material scope

- inorganic crystals

## Target properties

- thermodynamic stability
- distance to convex hull phase diagram

## Constraints

- models must predict relaxed energy from unrelaxed structure input
- test set must simulate prospective discovery workflow with covariate shift
- benchmark must use convex hull distance—not formation energy—as primary stability indicator

## Input requirements

- unrelaxed crystal structures

## Output goal

- classification of whether material is on or below convex hull (i.e., thermodynamically stable)

## Research stages

1. acquiring training data from Materials Project database (`data_acquisition`)
2. acquiring test data from WBM dataset (`data_acquisition`)
3. cleaning and filtering WBM test set (`data_preparation`)
4. computing convex hull distance labels (`label_generation`)
5. training ML models on MP data (`model_training`)
6. ranking candidates by predicted hull distance (`candidate_generation`)
7. evaluating classification performance against convex hull (`model_evaluation`)

## Dataset uses

- acquiring training data from Materials Project database: Materials Project (training, DU_P004_001)
- acquiring test data from WBM dataset: Wang-Botti-Marques (WBM) dataset (test, DU_P004_002)
- cleaning and filtering WBM test set: WBM unique protostructure test set (test, DU_P004_003)
- computing convex hull distance labels: WBM unique protostructure test set (label_source, DU_P004_004)
- ranking candidates by predicted hull distance: WBM unique protostructure test set (candidate_pool, DU_P004_005)
