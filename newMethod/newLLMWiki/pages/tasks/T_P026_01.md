# Task: dataset redundancy control for material property prediction

- Task ID: `T_P026_01`
- Canonical name: `dataset_redundancy_control`
- Paper: `P026`

## Objective

Reduce dataset redundancy in material datasets to enable objective performance evaluation of ML models for material property prediction, especially for extrapolation/out-of-distribution generalization

## Material scope

- inorganic crystalline materials
- perovskites (e.g., SrTiO3)
- Materials Project database entries
- OQMD database entries

## Target properties

- formation energy
- band gap
- elastic moduli
- thermal conductivity
- total energy
- charge density
- magnetic moment
- bulk modulus
- shear modulus

## Constraints

- avoid information leakage between training and test sets
- preserve coverage of composition/structure space
- ensure minimum inter-sample distance threshold
- support both composition-based and structure-based inputs

## Input requirements

- material compositions or crystal structures
- distance metric (e.g., Mendeleev, MatScholar, XRD, OFM)
- similarity/distance threshold

## Output goal

- non-redundant dataset where no pair of samples exceeds defined similarity threshold

## Research stages

1. redundancy reduction using MD-HIT-composition (`data_preparation`)
2. redundancy reduction using MD-HIT-structure (`data_preparation`)
3. download and curate Materials Project dataset (`data_acquisition`)
4. evaluate ML model performance on redundancy-controlled datasets (`model_evaluation`)
5. construct OOD test sets (MatscholarOOD, EmbeddingOOD) (`candidate_screening`)
