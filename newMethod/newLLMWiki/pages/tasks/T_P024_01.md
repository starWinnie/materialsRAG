- Task ID: `T_P024_01`
- Canonical name: `materials_property_prediction`
- Paper: `P024`

## Constraints

- small dataset size
- diverse materials classes
- cross-property transfer
- cross-materials class transfer
- need for structure-aware input

## Input requirements

- crystal structure files (e.g., POSCAR)
- atomic positions
- lattice geometry
- atom, bond, and angle information

## Output goal

- predicted numerical value of a target materials property

## Research stages

1. acquisition of diverse materials datasets (`data_acquisition`)
2. preprocessing of structure files into atom/bond/angle features (`data_preparation`)
3. training of source model (ALIGNN on MP formation energy) (`model_training`)
4. transfer learning via fine-tuning on target datasets (`model_training`)
5. feature extraction from pre-trained ALIGNN for target compounds (`candidate_generation`)
6. training of target model on extracted features (`model_training`)
7. evaluation of predictive performance using MAE (`model_evaluation`)
