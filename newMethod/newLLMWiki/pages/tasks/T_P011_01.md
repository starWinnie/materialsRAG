# Task: crystal property prediction

- Task ID: `T_P011_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P011`

## Objective

Predict crystal properties (e.g., formation energy, band gap, bulk moduli, shear moduli, energy above hull, total energy) from crystal structure representations.

## Material scope

- crystal materials

## Target properties

- formation energy
- band gap
- bulk moduli
- shear moduli
- energy above hull
- total energy

## Constraints

- labeled data is scarce and varies across properties
- target properties lack comparability
- models must discern distinct patterns for each target property

## Input requirements

- crystal structure C = {B, L} characterized by basis B = {A, P} (atom types A and atom positions P) and Bravais lattice L (lattice constants)

## Output goal

- predicted numerical values for crystal properties

## Research stages

1. acquisition of unlabeled crystal structures (`data_acquisition`)
2. perturbation of crystal structure representations (`data_preparation`)
3. denoising pre-training (`model_training`)
4. fine-tuning on downstream property prediction tasks (`model_training`)
5. evaluation of property prediction performance (`model_evaluation`)

## Dataset uses

- acquisition of unlabeled crystal structures: 380,743 unlabeled crystal structures (pretraining, DU_P011_001)
- fine-tuning on downstream property prediction tasks: JARVIS-DFT (training, DU_P011_002)
- fine-tuning on downstream property prediction tasks: Materials Project (training, DU_P011_003)
- evaluation of property prediction performance: JARVIS-DFT (test, DU_P011_004)
- evaluation of property prediction performance: Materials Project (test, DU_P011_005)

## Evidence

- P011, PDF page 3, Preliminary and Notations: "The crystal property prediction problem involves predicting the property of a given crystal structure C = {A, P, L} by learning a function f to predict its corresponding property."
