# Task: Dielectric tensor prediction for inorganic materials

- Task ID: `T_P019_01`
- Canonical name: `dielectric_tensor_prediction`
- Paper: `P019`

## Objective

Predict the three types of dielectric tensors, ε∞ij, ε0ij and εij, for inorganic materials across 72 supported elements with the equivariance to the input structure.

## Material scope

- inorganic materials

## Target properties

- dielectric tensor
- electronic dielectric tensor
- ionic dielectric tensor
- total dielectric tensor

## Constraints

- O(3) equivariance
- thermodynamic stability (Ehull = 0) for virtual screening candidates

## Input requirements

- crystal structure graph representation
- atomic numbers and positions
- 72-element support (excluding noble gases He, Ne, Ar, Kr)

## Output goal

- 3 × 3 symmetric dielectric tensor
- scalar polycrystalline dielectric constant ε
- tensor eigenvalues λi
- anisotropic ratio αr = λmax/λmin

## Research stages

1. Data acquisition from Materials Project (`data_acquisition`)
2. Dataset cleaning and filtering (`data_preparation`)
3. Training DTNet with pretrained PFP encoder (`model_training`)
4. Benchmarking against state-of-the-art models (`model_evaluation`)
5. Preparation of candidate structures for virtual screening (`candidate_generation`)
6. Iterative active learning for virtual screening (`candidate_screening`)
7. DFPT validation of screened candidates (`computational_validation`)

## Dataset uses

- Data acquisition from Materials Project: Materials Project (source, DU_P019_001)
- Dataset cleaning and filtering: Materials Project cleaned subset (6648 structures) (training, DU_P019_002)
- Benchmarking against state-of-the-art models: Materials Project cleaned subset (6648 structures) (test, DU_P019_003)
- Benchmarking against state-of-the-art models: Matbench dielectric task dataset (benchmark, DU_P019_004)
- Preparation of candidate structures for virtual screening: Materials Project candidate set (14,375 non-metal stable materials) (candidate_pool, DU_P019_005)
