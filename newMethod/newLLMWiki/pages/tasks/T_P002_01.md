# Task: developing a single machine learning architecture that is capable of adapting its weights automatically to enforce invariance to any input space group

- Task ID: `T_P002_01`
- Canonical name: `space_group_invariant_architecture_development`
- Paper: `P002`

## Objective

To develop a single, adaptive neural architecture that enforces exact invariance to any crystallographic space group by leveraging symmetry-adapted Fourier bases and group-conditional routing.

## Material scope

- crystalline solids
- crystals

## Target properties

- material property prediction
- zero-shot generalization to unseen space groups
- orbit distance capture

## Constraints

- exact invariance to any of the 230 space groups
- parameter sharing across all space groups
- overcoming data sparsity for rare groups

## Input requirements

- atomic positions
- lattice vectors
- space group identifier (1-230)

## Output goal

- G-invariant positional encodings
- material property predictions (e.g., total energy, band gap)
- zero-shot predictions for unseen space groups

## Research stages

1. using data from the Materials Project (`data_acquisition`)
2. constructing synthetic dataset for orbit distance validation (`data_preparation`)
3. computing orbit distance as ground truth (`label_generation`)
4. pretraining the symmetry-adapted positional encoding module (`model_training`)
5. training the full CFT architecture for material property prediction (`model_training`)
6. evaluating CFT on material property prediction benchmarks (`model_evaluation`)
7. holding out inversion-symmetric space groups for zero-shot evaluation (`candidate_screening`)
8. evaluating zero-shot generalization to unseen space groups (`model_evaluation`)

## Dataset uses
