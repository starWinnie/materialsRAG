# Task: identifying semiconductors with ultralow lattice thermal conductivity

- Task ID: `T_P008_01`
- Canonical name: `identifying_semiconductors_with_ultralow_lattice_thermal_conductivity`
- Paper: `P008`

## Objective

Identify semiconductors with ultralow lattice thermal conductivity (κL) for potential thermoelectric applications.

## Material scope

- semiconductors

## Target properties

- lattice thermal conductivity (κL)

## Constraints

- ultralow κL (≤ 2 W/mK)
- thermodynamic stability (Ehull ≤ 0.05 eV/atom)
- band gap 0.1–2 eV
- Natoms < 20
- Nelements < 4
- no H, lanthanides, actinides

## Input requirements

- chemical composition
- crystal structure
- descriptors derived from Magpie and Voronoi tessellations

## Output goal

- list of candidate semiconductors with ultralow κL
- interpretable descriptors governing κL modulation

## Research stages

1. obtaining material dataset from Materials Project database (`data_acquisition`)
2. preliminary high-throughput screening (`data_preparation`)
3. unsupervised learning for clustering materials with similar κL (`candidate_generation`)
4. high-throughput calculation of κL using PET model (`label_generation`)
5. statistical analysis and candidate screening from local database (`candidate_screening`)
6. first-principles validation of κL for selected candidates (`computational_validation`)
7. training CatBoost classifier for ultralow κL prediction (`model_training`)
8. evaluating CatBoost classifier performance (`model_evaluation`)
9. interpretable analysis using SHAP to uncover κL modulation mechanisms (`other`)
