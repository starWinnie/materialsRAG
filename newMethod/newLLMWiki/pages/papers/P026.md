# Paper: MD-HIT: Machine learning for material property prediction with dataset redundancy control

- File: `26_MD_HIT.pdf`
- Extraction status: completed

## Research summary

This paper addresses the problem of overestimated machine learning model performance in materials science due to dataset redundancy—i.e., highly similar materials in training and test sets causing information leakage. It proposes MD-HIT, a redundancy reduction algorithm inspired by bioinformatics' CD-HIT, to generate non-redundant composition and structure datasets using distance metrics (e.g., Mendeleev, MatScholar, XRD, OFM). The authors apply MD-HIT to formation energy and band gap prediction tasks, demonstrating that models evaluated on redundancy-controlled datasets show lower (but more realistic) performance, especially for out-of-distribution samples, thus enabling objective evaluation of extrapolation capability.
