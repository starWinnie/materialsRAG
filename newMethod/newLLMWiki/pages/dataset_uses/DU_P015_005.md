# Dataset Use: RadonPy polymer dataset in generation of extrapolative episodes

- DatasetUse ID: `DU_P015_005`
- Paper: `P015`

## Research task

extrapolative prediction of material properties (`T_P015_01`)

## Research stage

generation of extrapolative episodes (`candidate_generation`, `S_P015_03`)

## Dataset

RadonPy polymer dataset (`D_P015_radonpy_polymer_dataset`)

## Usage role

candidate_pool

## Purpose

To generate extrapolative episodes by partitioning across 20 polymer classes, sampling test instances from one class and support sets from the other 19.

## Used fields

- chemical structure of polymer repeating unit
- Cp
- refractive index

## Construction method

Partitioned into 20 polymer classes (p01–p16 and p18–p21); episodes constructed by sampling (x,y) from one class and support set S from remaining 19 classes.

## Filter conditions

- 19 of 20 polymer classes used for training
- remaining class held out for testing

## Sample count

69480

## Evidence

- P015, PDF page 3, Experimental results: "The dataset included 69,480 amorphous polymers classiﬁed into 20 polymer classes, denoted by p01–p16 and p18–p21 where p17 is a missing class, such as polyimide, polyesters, and polystyrene, based on the chemical structures of their repeating units (Supplementary Table S1)."
- P015, PDF page 3, Experimental results: "To evaluate the prediction performance for an unseen polymer class, the following process was implemented: (1) a model was trained using randomly selected samples from 19 of the 20 polymer classes and (2) its generalizability was assessed using data from the remaining polymer class."
