# Generated LLM Wiki

This directory is populated by `../extract_llm_wiki.py`.

All formal nodes must be traceable to validated evidence in the corresponding
PDF page. Intermediate page text, model responses, and validation results are
kept under `raw/extractions/`.

Final audited corpus (30 papers):

- 30 Paper nodes
- 30 main Task nodes
- 178 Stage nodes
- 85 normalized Dataset nodes
- 277 DatasetUse events
- 1,502 edges

See `reports/validation_report.json` and `reports/independent_audit.json`.
