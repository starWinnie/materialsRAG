# Stage: constructing synthetic dataset for orbit distance validation

- Stage ID: `S_P002_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P002_01` — developing a single machine learning architecture that is capable of adapting its weights automatically to enforce invariance to any input space group

## Goal

Generate synthetic crystal data to validate the geometric fidelity of the G-invariant encoding module.

## Input

- Space group identifiers
- Random atomic positions
- Random lattice vectors

## Output

- Synthetic dataset of atomic position pairs with ground-truth orbit distances

## Datasets used

- synthetic orbit distance dataset — training: Validate the geometric fidelity of the G-invariant encoding module by training it to produce embeddings where Euclidean distance corresponds to orbit distance.

## Evidence

- P002, PDF page 8, 5.2 SYMMETRY-ADAPTED ENCODINGS CAPTURE ORBIT DISTANCE: "We construct a synthetic dataset containing 100,000 samples for each of the 230 space groups. Each sample consists of a pair of random atomic positions as fractional coordinates in [0, 1)3, a space group, and randomly generated lattice vectors that satisfy the constraints of the Bravais lattice for the group."
