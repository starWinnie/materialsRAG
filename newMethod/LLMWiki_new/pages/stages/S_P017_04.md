# Stage: Training Bilinear Transduction predictor

- Stage ID: `S_P017_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P017_01` — Out-of-Distribution Property Prediction

## Goal

Train a bilinear transductive predictor hθ(Δx, x) = fθ(Δx)gθ(x) to learn how property values change as a function of material differences.

## Input

- training set Dtr = {(x, y)}n ⊂ X × Y
- differences distribution ΔX = {xi − xj | xi, xj ∈ X}

## Output

- trained bilinear transductive predictor hθ

## Datasets used

- None stated

## Evidence

- P017, PDF page 6, Methods: "During training, rather than predicting hθ : X → Y, predictor hθ : ΔX × X → Y predicts value y2 ∈ Dtr_Y for data point x2 ∈ Dtr_X given anchor point x1 ∈ Dtr_X and the difference between them Δx21 = x2 − x1 ∈ Dtr_ΔX."
- P017, PDF page 6, Methods: "The predictor hθ(Δx, x) = fθ(Δx)gθ(x) is implemented as a bilinear function in non-linear embeddings of Δx and x."
