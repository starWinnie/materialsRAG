# Stage: Dataset cleaning and partitioning

- Stage ID: `S_P019_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P019_01` — Dielectric tensor prediction for inorganic materials

## Goal

Clean the dataset by restricting dielectric constants and filtering unsupported elements, then partition into training, validation, and test subsets.

## Input

- 7277 relaxed materials with calculated dielectric constants

## Output

- 6648 structures retained for model training
- training, validation, and test subsets in 0.8:0.1:0.1 ratio

## Datasets used

- Refined MP training set (6648 structures) — training: Training set after cleaning and filtering for model training. / Validation subset for model development. / Test subset for final model evaluation.
