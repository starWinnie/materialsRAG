# Stage: Evaluate LLM responses on MaScQA

- Stage ID: `S_P101_02`
- Stage type: `model_evaluation`
- Stage order: 2
- Task: `T_P101_01` — Evaluate LLMs' question-answering capabilities in materials science and metallurgical engineering

## Goal

Quantify each LLM's accuracy across four question types (MATCH, MCQ, MCQN, NUM) via automated scoring using GPT-4o as judge.

## Input

- 644 MaScQA questions
- responses from 15 LLMs (each submitted three times)

## Output

- per-model, per-category accuracy scores
- overall accuracy (%)
- standard deviations

## Datasets used

- MaScQA — test: Quantify each LLM's accuracy across four question types (MATCH, MCQ, MCQN, NUM) via automated scoring using GPT-4o as judge.
