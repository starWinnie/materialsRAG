# Stage: Screening for top OOD candidates using extrapolative precision

- Stage ID: `S_P017_05`
- Stage type: `candidate_screening`
- Stage order: 5
- Task: `T_P017_01` — Out-of-Distribution Property Prediction

## Goal

Identify high-performing OOD candidates by selecting top predicted property values and evaluating fraction of true top OOD candidates correctly identified.

## Input

- predicted property values
- ground truth property values
- OOD test set

## Output

- top 30% predicted OOD candidates
- extrapolative precision score

## Datasets used

- AFLOW — screening: Screening for top OOD candidates by identifying 30% of test samples with highest property values
- Matbench — screening: Screening for top OOD candidates by identifying 30% of test samples with highest property values
- Materials Project — screening: Screening for top OOD candidates by identifying 30% of test samples with highest property values
- MoleculeNet — screening: Screening for top OOD candidates by identifying 30% of test samples with highest property values

## Evidence

- P017, PDF page 2, Results: "In addition, we report model performance on a purely extrapolative task of discovering high-performance extremes: identifying the 30% of test samples with the highest property values, which we refer to as the top OOD candidates (Table 2). This is quantified by extrapolative precision, which measures the fraction of true top OOD candidates correctly identified among the model’s top predicted OOD candidates."
