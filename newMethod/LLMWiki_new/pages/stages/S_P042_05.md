# Stage: establishment of FAIR-compliant protocols and infrastructure

- Stage ID: `S_P042_05`
- Stage type: `other`
- Stage order: 5
- Task: `T_P042_01` — creation of an open-access database and analysis tool for perovskite solar cells

## Goal

to develop procedures, templates, and infrastructure ensuring long-term sustainability, trustworthiness, and community adoption

## Input

- FAIR data principles
- community input
- Helmholtz Organization support

## Output

- Excel template for data upload
- metadata ontology
- GitHub repository
- project website (www.perovskitedatabase.com)
- guarantee of operational maintenance for a decade

## Datasets used

- Perovskite Database — computational_validation: to establish FAIR-compliant protocols, infrastructure, and long-term maintenance

## Evidence

- P042, PDF page 2, Data: "The key goals of the project are to: collect all perovskite solar cell data ever published in one open-access database; develop free interactive web-based tools for simple and interactive exploration, analysis, filtering and visualization of the data; develop procedures and protocols to simplify dissemination and collection of new perovskite data according to the FAIR data principles; release an open-source code base that can be used as a blueprint for similar projects and give a few demonstrations of insights and analysis that can be easily done if all data are consistently formatted and found in one place."
- P042, PDF page 6, Future expansion of the database: "To ensure the project’s longevity, we have secured support from the Helmholtz Organization in Germany, which acts as a guarantor ensuring that the web resources, that is, database, webpage and the GitHub account, will be operational and maintained for the coming decade, with an option of possible prolongation."
