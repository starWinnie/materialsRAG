# Stage: manual data extraction and formatting

- Stage ID: `S_P042_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P042_01` — creation of an open-access database and analysis tool for perovskite solar cells

## Goal

to extract device-level data from papers and format consistently according to protocol

## Input

- peer-reviewed papers with original experimental device data

## Output

- over 42,400 devices extracted with up to 100 parameters per device, consistently formatted

## Datasets used

- Perovskite Database — training: to extract and format device-level data from papers using a 95-attribute protocol

## Evidence

- P042, PDF page 2, Data: "In total, we have manually extracted data for over 42,400 devices. While a few devices with extractable data will have slipped through our net, the devices in the database represent almost every device someone has thought is worth the effort to describe in detail in the peer-reviewed literature."
- P042, PDF page 3, Data: "Once extracted, the data have been consistently formatted according to the instruction in the supporting documentation and is now freely available in the Perovskite Database."
