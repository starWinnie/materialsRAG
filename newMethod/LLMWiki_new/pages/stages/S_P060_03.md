# Stage: Structure vectorization

- Stage ID: `S_P060_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P060_01` — deep fusion of experimental and theoretical data in condensed matter physics

## Goal

transform each standardized crystal structure into a fixed-length numerical vector (structural fingerprint) encoding chemical and structural features

## Input

- standardized, canonical data

## Output

- structural fingerprints (e.g., 122-dimensional SiteStatsFingerprint vectors)

## Datasets used

- Crystal Structure and Diffraction Database (COD-derived) — candidate_pool: providing standardized crystal structures for transformation into structural fingerprints using SiteStatsFingerprint featurizer
- MatElab Single-Crystal Growth Database — candidate_pool: providing standardized experimental records for transformation into structural fingerprints using SiteStatsFingerprint featurizer

## Evidence

- P060, PDF page 5, Core data fusion: Structure-based similarity linking: "First, in an offline pre-processing step, every standardized crystal structure is transformed into a fixed-length numerical vector, or structural fingerprint, using a representation learning algorithm. For this, we employ the SiteStatsFingerprint featurizer from the matminer library[47], which encodes rich information about local atomic environments into a high-dimensional vector."
