# Stage: creation of explicit training, validation and test splits

- Stage ID: `S_P053_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P053_01` — training Machine Learning Interatomic Potentials (MLIPs) for inorganic materials

## Goal

to ensure consistent training and evaluation by the community and prevent data leakage

## Input

- full OMat24 dataset

## Output

- training split (100M structures), validation split (5M structures), WBM Test split (5.3M structures), ID Test split (5.45M structures), OOD-Composition Test split (573K structures), OOD-Element Test split (619K structures)

## Datasets used

- Open Materials 2024 (OMat24) — training: to create explicit training, validation and test splits ensuring consistent training and evaluation by the community
- WBM Test split — test: to ensure that the training dataset does not overlap with the Matbench Discovery leaderboard created from the WBM dataset
- OOD-Composition Test split — test: to measure the accuracy of the models on in-domain training data and the ability of the models to generalize to out-of-distribution compositions
- OOD-Element Test split — test: to measure the accuracy of the models on in-domain training data and the ability of the models to generalize to out-of-distribution elemental compositions
- ID Test split — test: to measure the accuracy of the models on in-domain training data

Training and validation splits are released to allow for model development and iteration. The test set is divided into four different splits."
