# Stage: evaluate ML model performance on redundant vs. non-redundant datasets

- Stage ID: `S_P026_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P026_01` — dataset redundancy control for material property prediction

## Goal

Quantify how redundancy control affects predictive performance (R², MAE) of ML models on both in-distribution (random-split) and out-of-distribution (OOD) test sets.

## Input

- non-redundant datasets
- redundant baseline datasets
- ML models (Roost, CrabNet, ALIGNN, DeeperGATGNN)

## Output

- R² and MAE scores for formation energy and band gap prediction
- parity plots
- comparisons of ID vs. OOD performance

## Datasets used

- Mendeleev-nr — training: Training set for composition-based ML models (Roost, CrabNet) with redundancy control
- Matscholar-nr — training: Training set for composition-based ML models (Roost, CrabNet) with redundancy control
- XRD-nr — training: Training set for structure-based ML models (ALIGNN, DeeperGATGNN) with redundancy control
- OFM-nr — training: Training set for structure-based ML models (ALIGNN, DeeperGATGNN) with redundancy control
