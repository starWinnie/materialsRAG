# Stage: Compositional space partitioning via Design of Experiments (DoE)

- Stage ID: `S_P066_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P066_01` — AI-driven design of multiprincipal element alloys for optimal water splitting

## Goal

Generate a diverse, representative, and boundary-aware set of 119 alloy compositions for initial model training.

## Input

- seven elemental precursors (Mn, Fe, Co, Ni, Cu, Mo, Pd, Pt)
- compositional constraints (1/9 ≤ xi ≤ 4/9 for high-entropy region)
- simplex centroid design
- extreme vertices design

## Output

- 119 DoE-based compositions (e.g., (1,0,0,0,0,0), (1/2,1/2,0,0,0,0), (1/6,1/6,1/6,1/6,1/6,1/6), (4/9,1/9,1/9,1/9,1/9,1/9), etc.)

## Datasets used

- None stated

- P066, PDF page 3: "Using 119 samples from extreme vertices and simplex centroids, the GPR model was trained via DoE-based sampling that captures compositional complexity better than random sampling."
