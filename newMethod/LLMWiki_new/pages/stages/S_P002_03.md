# Stage: pretraining the G-invariant encoding module

- Stage ID: `S_P002_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P002_01` — developing a single machine learning architecture that is capable of adapting its weights automatically to enforce invariance to any input space group

## Goal

Train the positional encoding module to produce embeddings where Euclidean distance corresponds to orbit distance.

## Input

- Synthetic dataset of atomic position pairs
- Ground-truth orbit distances

## Output

- Pretrained G-invariant positional encoding module

## Datasets used

- synthetic orbit distance dataset — training: Train the positional encoding module to produce embeddings where Euclidean distance corresponds to orbit distance.

## Evidence

- P002, PDF page 8, 5.2 SYMMETRY-ADAPTED ENCODINGS CAPTURE ORBIT DISTANCE: "The goal is to train the encoder to produce positional encodings where the Euclidean distance between embeddings directly corresponds to the true orbit distance dG(x1, x2) between atoms."
- P002, PDF page 8, 5.2 SYMMETRY-ADAPTED ENCODINGS CAPTURE ORBIT DISTANCE: "The model is trained to minimize the Mean Squared Error (MSE) between the L2 distance of the output embeddings and the ground-truth orbit distance."
