# Stage: Impulse excitation versus ultrasonic measurements

- Stage ID: `S_P075_06`
- Stage type: `model_evaluation`
- Stage order: 6
- Task: `T_P075_01` — Measuring the onset of sintering using laser ultrasonics

## Goal

Compare measured Rayleigh wave speeds from laser ultrasonics against those predicted from impulse excitation to assess accuracy and sensitivity of the new method

## Input

- predicted Rayleigh wave speeds
- measured Rayleigh wave speeds

## Output

- % error between predicted and measured Rayleigh values
- confirmation of ultrasonic technique viability

## Datasets used

- None stated

## Evidence

- P075, PDF page 7, 3.4 Impulse excitation versus ultrasonic measurements: "The measured Rayleigh wave speeds from the laser acoustic technique are compared to the values predicted from the impulse excitation technique in Table 1 for each of the sintering temperatures."
- P075, PDF page 9, 3.4 Impulse excitation versus ultrasonic measurements: "This table shows that for unsintered samples and samples sintered to temperatures of up to 1300◦C, the predicted and measured Rayleigh wave speed using the two techniques are very similar, differing by −6.52% to 4.81%. The mean difference between the predicted and measured Rayleigh wave arrival times for all the samples that were measured was 0.12%. This confirms that the ultrasonic technique is a very promising method to measure the sintering state."
