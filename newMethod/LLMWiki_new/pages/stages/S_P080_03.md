# Stage: Parameter screening for Pt loading, annealing temperature, and TiO2 thickness

- Stage ID: `S_P080_03`
- Stage type: `candidate_screening`
- Stage order: 3
- Task: `T_P080_01` — Photocatalytic Hydrogen Generation

## Goal

To systematically vary and assess the effects of Pt precursor concentration, pre-annealing temperature, and TiO2 layer thickness on photocatalytic H2 generation performance.

## Input

- Pt precursor concentrations (0.0001–2 mm)
- annealing temperatures (250–800 °C)
- TiO2 thicknesses (100–800 nm)

## Output

- optimized Pt SA density (≈0.26 at.% Pt)
- optimal annealing temperature (450 °C)
- thickness-dependent H2 production rates

## Datasets used

- None stated
