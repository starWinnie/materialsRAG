- Stage ID: `S_P056_04`

## Goal

Apply unsupervised learning (HDBSCAN clustering) and supervised symbolic regression (SISSO) to identify patterns and low-dimensional predictive descriptors.

## Input

- feature-augmented dataframe
- candidate descriptors (for SISSO)
- target property labels (e.g., Z2 topological invariant)

## Output

- clusters of materials
- sparse analytical descriptor (e.g., D1, D2) and its functional form

## Datasets used

- NOMAD tetradymite subset (152 alloyed tetradymites, Z2 calculated) — training: Training dataset for SISSO regression to classify topological vs trivial insulators using Z2 invariant.
