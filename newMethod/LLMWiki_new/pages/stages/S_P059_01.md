## Goal

obtain initial atomic structures and ground-truth reference data for benchmarking

## Input

- JARVIS-DFT database
- InterMat package

- initial structures for bulk, surfaces, defects, interfaces, and amorphous systems
- reference property values (e.g., elastic tensor, phonon band structure, surface energy, vacancy formation energy, work of adhesion, radial distribution function)

## Datasets used

- JARVIS-DFT — source: acquire initial atomic structures and ground-truth reference data for benchmarking

- MLEARN — source: benchmark force-prediction accuracy across diverse elemental systems
