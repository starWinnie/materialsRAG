# Stage: Analyzing learning curves for training time and training set size

- Stage ID: `S_P016_06`
- Stage type: `computational_validation`
- Stage order: 6
- Task: `T_P016_01` — Probing out-of-distribution generalization in machine learning for materials

## Goal

To empirically test neural scaling laws on representationally ID vs. OOD tasks by varying training effort.

## Input

- Trained models
- OOD tasks
- varying training epochs
- varying training set sizes

## Output

- Learning curves (MAE vs. training time/size)
- identification of beneficial, marginal, or adverse scaling effects
