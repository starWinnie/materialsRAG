# Stage: training CatBoost classifier on labeled local database

- Stage ID: `S_P008_05`
- Stage type: `model_training`
- Stage order: 5
- Task: `T_P008_01` — identifying semiconductors with ultralow lattice thermal conductivity

## Goal

Train supervised classification model to predict ultralow κL (κPET ≤ 2 W/mK)

## Input

- 661 labeled materials with κPET values
- 273 descriptors (Magpie + Voronoi)

## Output

- robust CatBoost classification model

## Datasets used

- local database — training: Train supervised classification model to predict ultralow κL (κPET ≤ 2 W/mK)
