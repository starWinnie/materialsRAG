# Stage: Rietveld refinement and DFT calculations

- Stage ID: `S_P119_04`
- Stage type: `computational_validation`
- Stage order: 4
- Task: `T_P119_01` — Band gap narrowing in oxychlorosulfide photocatalysts through aliovalent Cl-to-S anion substitution

## Goal

Validate structural integrity and quantify electronic structure changes (VBM upshift, band gap narrowing) induced by substitution.

## Input

- SXRD patterns
- CIC-determined S/Cl occupancies
- ordered structural models for DFT

## Output

- refined lattice parameters
- DFT-calculated band gaps (2.10 → 1.65 eV)
- DOS showing enhanced S 3p contribution at VBM

## Datasets used

- La5Ti6–xTaxO15S3+xCl3–x (x = 0, 0.5, 0.75, 1) — computational_validation: Structural validation via Rietveld refinement and electronic structure analysis via DFT calculations to quantify band gap narrowing and VBM upshift.
