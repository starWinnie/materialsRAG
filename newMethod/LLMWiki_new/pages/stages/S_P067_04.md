# Stage: Fitting tunnelling spectra with Dynes model

- Stage ID: `S_P067_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P067_01` — Superconducting gap of H3S measured by tunnelling spectroscopy

## Goal

To extract quantitative superconducting gap parameters (Δ, Γ) and validate s-wave symmetry by fitting normalized tunnelling spectra.

## Input

- normalized tunnelling spectra
- Dynes model
- Brinkman–Dynes–Rowell (BDR) background model

## Output

- gap values (e.g., ΔH3S-S1 ≈ 29 meV)
- broadening parameter Γ
- confirmation of s-wave symmetry

## Datasets used

- None stated

## Evidence

- P067, PDF page 3: "To quantitatively clarify the temperature evolution of the superconducting gap, we fitted the tunnelling spectra, which are normalized through division by the parabolic background fitted with Brinkman–Dynes–Rowell (BDR) model24 (Extended Data Fig. 3), with a single s-wave Dynes model25 (Methods)."
- P067, PDF page 1: "The tunnelling spectra reveal that H3S and D3S both have a fully gapped structure, which could be well described by a single s-wave Dynes model, with gap values 2Δ of approximately 60 meV and 44 meV, respectively."
