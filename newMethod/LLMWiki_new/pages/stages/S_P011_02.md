# Stage: perturbation of crystal representations

- Stage ID: `S_P011_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P011_01` — crystal property prediction

## Goal

Generate perturbed versions of crystal structures by masking atom types, adding noise to atom positions, and perturbing lattice constants.

## Input

- unlabeled crystal structures

## Output

- perturbed crystal representations: masked atom types, perturbed atom positions, perturbed lattice constants

## Datasets used

- None stated
