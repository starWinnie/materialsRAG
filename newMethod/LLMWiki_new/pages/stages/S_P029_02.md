# Stage: Preprocessing crystal structures into OFM feature space and applying t-SNE

- Stage ID: `S_P029_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P029_01` — Structure-based out-of-distribution (OOD) materials property prediction

## Goal

Convert raw crystal structures into low-dimensional representations for clustering-based OOD test set generation

## Input

- crystal structures

## Output

- 1024-dimension OFM feature space
- 2D t-SNE embedding

## Datasets used

- matbench_dielectric — pretraining: Convert raw crystal structures into low-dimensional representations for clustering-based OOD test set generation
- matbench_log_gvrh — pretraining: Convert raw crystal structures into low-dimensional representations for clustering-based OOD test set generation
- matbench_perovskites — pretraining: Convert raw crystal structures into low-dimensional representations for clustering-based OOD test set generation

## Evidence

- P029, PDF page 4, OOD test set generation: "Initially, we apply the k-means algorithm61 based on the orbital-field matrix (OFM) features62 to cluster the whole dataset into 50 clusters. OFM captures the electronic structure of materials by considering the orbitals’ interactions, which are fundamental to understanding the material’s properties, and easily interpretable due to their physical basis63. The OFM features were calculated fast using the MatMiner23 package."
- P029, PDF page 4, OOD test set generation: "In this method, we begin by converting material structures into the 1024-dimension OFM feature space. Subsequently, we apply the t-distributed stochastic neighbor embedding (t-SNE)64 for dimension reduction converting the OFM feature space to a 2D space (x-value)."
