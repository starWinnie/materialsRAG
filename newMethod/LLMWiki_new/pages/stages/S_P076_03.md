## Goal

To transform measured absolute values into relative values normalized to dense-material baselines (Vtr = Vt/Vt0, Vlr = Vl/Vl0, Er = E/E0) using tabulated dense-material parameters.

## Input

- measured Vt, Vl, E
- dense-material parameters from Table 2 (ρ0, E0, ν0, Vt0, Vl0)

## Output

- relative sound velocities (Vtr, Vlr)
- relative Young’s modulus (Er)
