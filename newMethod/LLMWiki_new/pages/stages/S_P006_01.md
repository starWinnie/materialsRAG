# Stage: Acquire crystal structure datasets

- Stage ID: `S_P006_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P006_01` — Generate universal atomic embeddings (UAEs) for crystal property prediction

## Goal

Obtain large-scale, high-quality crystal structure and property datasets for training and evaluation.

## Input

- None stated

## Output

- MP dataset (2018.6.1 version, 69,239 materials)
- MP* dataset (2023.6.23 version, 134,243 materials)
- JARVIS dataset
- MC3D dataset
- hybrid perovskite (HOIP) datasets

## Datasets used

- Materials Project (2018.6.1) — source: Source dataset for acquiring crystal structure and property data for training and evaluation
- Materials Project (2023.6.23) — source: Source dataset for acquiring crystal structure and property data for training and evaluation
- JARVIS-DFT — source: Source dataset for acquiring crystal structure and property data for training and evaluation
- MC3D dataset — source: Source dataset for acquiring crystal structure and property data for training and evaluation
- Hybrid Organic-Inorganic Perovskite (HOIP) dataset — source: Source dataset for acquiring crystal structure and property data for training and evaluation of hybrid perovskites
