# Stage: Compute convex hull distance labels for WBM structures

- Stage ID: `S_P004_04`
- Stage type: `label_generation`
- Stage order: 4
- Task: `T_P004_01` — ML-guided materials discovery

## Goal

Derive thermodynamic stability labels by computing each WBM structure's distance to the convex hull of the MP training set.

## Input

- PBE formation energies of DFT-relaxed WBM structures
- MP training set convex hull

## Output

- convex hull distance labels (EMP hull dist ≤ 0 for stable)

## Datasets used

- WBM unique prototype test set — label_source: Compute convex hull distance labels for stability classification

## Evidence

- P004, PDF page 8, Article: "Throughout this work, we define stability as being on or below the convex hull of the MP training set (EMP hull dist ≤ 0). In total, 32,942 of 215,488 materials in the WBM unique prototype test set satisfy this criterion."
- P004, PDF page 6, Methods: "The convex hull distance of a relaxed structure is chosen as the measure of its thermodynamic stability, rather than the formation energy, as it informs the decision on whether to pursue a potential candidate crystal."
