# Stage: construct OOD test sets via density-based sampling

- Stage ID: `S_P026_05`
- Stage type: `candidate_screening`
- Stage order: 5
- Task: `T_P026_01` — dataset redundancy control for material property prediction

## Goal

Identify truly out-of-distribution samples by measuring sparsity in either feature space (Matscholar) or latent representation space (Roost encoder).

## Input

- Matscholar features
- pretrained Roost encoder outputs

## Output

- MatscholarOOD test set
- EmbeddingOOD test set

## Datasets used

- MatscholarOOD test set — test: Out-of-distribution test set for evaluating extrapolative capability
- EmbeddingOOD test set — test: Out-of-distribution test set for evaluating extrapolative capability in latent space

## Evidence

- P026, PDF page 8: "We first selected 1000 OOD test samples to create the MatscholarOOD test set, based on the densities calculated using Matscholar features of compositions from the entire MP dataset..."
- P026, PDF page 8: "First, we used a pretrained Roost model as an encoder to obtain the latent representations for all samples in the entire dataset (86,740 samples). We then calculated the pairwise distances of all samples using their latent representations and selected 1000 OOD samples that are furthest away on average from their three nearest neighbors, forming our EmbeddingOOD test set."
