# Stage: Perform SCC testing with cathodic polarization

- Stage ID: `S_P093_03`
- Stage type: `experimental_validation`
- Stage order: 3
- Task: `T_P093_01` — Study the susceptibility to SCC of 7050 aluminum alloy

## Goal

Measure crack propagation under controlled electrochemical conditions to quantify SCC susceptibility

## Input

- pre-cracked DCB specimens
- 3.5 wt % NaCl solution
- −1100 mV cathodic polarization potential
- saturated calomel electrode
- platinum electrode

## Output

- crack length measurements every ten days
- da/dt–KI curves
- KISCC values
- plateau velocity

## Datasets used

- None stated
