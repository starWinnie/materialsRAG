# Stage: Historical validation of precursor recommendation success rate

- Stage ID: `S_P044_07`
- Stage type: `model_evaluation`
- Stage order: 7
- Task: `T_P044_01` — Precursor recommendation for inorganic synthesis

## Goal

Evaluate the pipeline by measuring the fraction of test targets for which at least one recommended precursor set appears in prior experimental records.

## Input

- 2,654 test target materials
- five proposed precursor sets per target
- historical synthesis records

## Output

- 82% success rate within five attempts

## Datasets used

- None stated

Using the knowledge base of 24,034 materials reported by the year 2014, we predict precursors for 2,654 test target materials newly reported from 2017 to 2020."
