# Stage: generation of molecular structures and consistency validation

- Stage ID: `S_P073_04`
- Stage type: `candidate_generation`
- Stage order: 4
- Task: `T_P073_01` — generation of lignin structures

## Goal

To convert molecular graphs into canonical SMILES representations and validate structural correctness and consistency with input constraints.

## Input

- topological matrices
- molecular graph representations

## Output

- canonical SMILES representations
- validated molecular structures

## Datasets used

- None stated

## Evidence

- P073, PDF page 5, Methods: "Generation of molecular structures and consistency validation. The molecular structure of a lignin is represented using the canonical SMILES (Simplified Molecular Input Line Entry System) notation which represents the molecular structure in a string format47. Directed graphs are converted to canonical SMILES by generating the monomer molecular graph and mapping the respective linkages using the Chemistry Development Toolkit (CDK)48, a widely used open-source cheminformatics toolkit."
- P073, PDF page 5, Methods: "Finally, generated structures are checked for the acceptance criteria that include structures with unique and valid SMILES representation; and number of nodes matching the requested degree of polymerization."
