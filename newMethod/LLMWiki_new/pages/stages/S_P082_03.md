# Stage: In situ SEM-based fiber push-out and push-back experiments

- Stage ID: `S_P082_03`
- Stage type: `experimental_validation`
- Stage order: 3
- Task: `T_P082_01` — Understanding the fiber–matrix interface properties governing the fiber-direction compressive strength improvement of the hybrid HM CFRPs

## Goal

To quantitatively measure interface shear strength (IFSS) and interface friction strength for IM and HM fibers in the hybrid CFRP.

## Input

- Hybrid CFRP thin membrane specimen (23 μm thick)
- Micromechanical load frame integrated with SEM
- Flat-end diamond indenter tip

## Output

- Load–displacement curves
- Calculated IFSS values
- Calculated interface friction strength values

## Datasets used

- None stated

## Evidence

- P082, PDF page 5, 3. In Situ SEM-Based Experiments: "In this work, in situ SEM-based fiber push-out and push-back tests are utilized for a hybrid CFRP to measure HM and IM carbon-fiber–polymer-matrix interface shear strength and interface friction strength, respectively."
- P082, PDF page 6, 5. Test Procedure: "The force applied on the fiber leads to fiber–matrix interface debonding until the fiber completely loses its load-carrying capacity and protrudes from the opposite sample surface."
- P082, PDF page 7, 5. Test Procedure: "By measuring the maximum applied load Pmax during the push-back test, the thickness of the specimen h, and the fiber radius r, the fiber–matrix interface friction strength can be calculated using Equation (1)."
