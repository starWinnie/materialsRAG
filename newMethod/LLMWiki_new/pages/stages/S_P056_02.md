# Stage: Enriching retrieved data with atomic features

- Stage ID: `S_P056_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P056_01` — AI-based analysis of materials-science data

## Goal

Augment the queried dataset with standardized atomic-level descriptors (e.g., electronegativity, ionic radius) to form machine-readable feature vectors.

## Input

- retrieved materials data (composition, atomic density)
- atomic features library (e.g., atomic_collections, MATMINER)

## Output

- structured dataframe with atomic features added per material

## Datasets used

- NOMAD ternary oxide subset (VASP/GGA, converged) — label_source: Source of atomic density values used to enrich the dataframe with atomic features.
