# Stage: preprocessing text descriptions (stopword removal, [NUM]/[ANG] replacement, [CLS] prepending)

- Stage ID: `S_P009_03`
- Stage type: `data_preparation`
- Stage order: 3
- Task: `T_P009_01` — predicting the properties of crystalline materials using large language models

## Goal

Transform raw crystal text descriptions into LLM-ready input sequences.

## Input

- raw crystal text descriptions

## Output

- preprocessed text sequences with stopwords removed, bond distances/angles replaced by [NUM]/[ANG], and [CLS] token prepended

## Datasets used

- None stated

## Evidence

- P009, PDF page 3: "For the input preprocessing step we did the following: (1) We removed stopwords from the text descriptions as this preprocessing step has been shown to improve performance on predictive tasks34,35. We processed all publicly available English stopwords and excluded them from the crystal text descriptions, except for digits and certain signs that may carry important information for crystal representation such as bond distances and angles. (2) We Replaced bond distance with a [NUM] token and bond angle with an [ANG] token. (3) We removed bond distances and bond angles. (4) We prepended a [CLS] token to the input."
