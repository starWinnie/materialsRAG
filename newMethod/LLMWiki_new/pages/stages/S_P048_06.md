## Goal

Validate whether universal machine learning potentials (M3GNet, CHGNet) can serve as surrogates for AIMD to generate non-crystalline structures by comparing radial distribution functions (RDFs) and structure features.

## Input

- M3GNet-predicted structures
- AIMD-calculated structures

## Output

- RDF comparison R2 scores
- structure feature comparison R2 scores
- validation of M3GNet's ability to reproduce non-crystalline structures
