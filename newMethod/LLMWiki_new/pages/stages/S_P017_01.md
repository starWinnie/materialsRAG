# Stage: Curating benchmark datasets for solids and molecules

- Stage ID: `S_P017_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P017_01` — Out-of-Distribution Property Prediction

## Goal

Acquire diverse, high-throughput computational and experimental datasets covering solid-state materials and molecules.

## Input

- None stated

## Output

- AFLOW dataset
- Matbench dataset
- Materials Project (MP) dataset
- MoleculeNet datasets (ESOL, FreeSolv, Lipophilicity, BACE)

## Datasets used

- AFLOW — source: Benchmark for solid materials property prediction covering electronic, mechanical, thermal properties
- Matbench — source: Benchmark for solid materials property prediction covering electronic, mechanical, thermal properties
- Materials Project — source: Benchmark for solid materials property prediction covering electronic, mechanical, thermal properties
- MoleculeNet — source: Benchmark for molecular graph-to-property prediction tasks
- ESOL — source: Graph-to-property prediction task for aqueous solubility
- FreeSolv — source: Graph-to-property prediction task for hydration free energy
- Lipophilicity — source: Graph-to-property prediction task for lipophilicity
- BACE — source: Graph-to-property prediction task for binding affinity
