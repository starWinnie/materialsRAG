# Stage: Assigning stability labels based on DFT-derived decomposition energy thresholds

- Stage ID: `S_P005_03`
- Stage type: `label_generation`
- Stage order: 3
- Task: `T_P005_01` — Predicting thermodynamic stability of inorganic compounds

## Goal

Generate binary stability labels from computed ΔHd values

## Input

- DFT-calculated decomposition energies (ΔHd)

## Output

- binary labels: stable (ΔHd ≤ 0 meV/atom) or unstable

- Materials Project — label_source: Assign stability labels based on DFT-derived decomposition energy thresholds
- Open Quantum Materials Database (OQMD) — label_source: Assign stability labels based on DFT-derived decomposition energy thresholds
