# Stage: fine-tuning for downstream extrapolative domains

- Stage ID: `S_P015_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To adapt pretrained meta-learners to target domains using limited data from those domains.

## Input

- pretrained MNN
- small dataset from target domain (e.g., one polymer class, HOIP-GeF)

## Output

- fine-tuned predictor optimized for target domain

## Datasets used

- RadonPy polymer dataset — experimental_validation: Fine-tuning pretrained meta-learners to target polymer domains using limited data
- HOIP dataset — experimental_validation: Fine-tuning pretrained meta-learners to target perovskite domains (HOIP-GeF and HOIP-PbI) using limited data

## Evidence

- P015, PDF page 6, Fine-tuning to extrapolative domains: "Fine-tuning was performed on the RadonPy dataset. In this experiment, a pretrained E2T model with a source data size of 38,000 was fine-tuned on data from the target domain corresponding to a particular polymer class."
- P015, PDF page 11, Fine-tuning experiments: "An MNN pretrained by E2T with a source data size of 1248 (HOIP-GeF) or 1228 (HOIP-PbI) was fine-tuned on data, including data from the target domain."
