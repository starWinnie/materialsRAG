# Stage: Thermal stability assessment via calorimetry

- Stage ID: `S_P113_05`
- Stage type: `candidate_screening`
- Stage order: 5
- Task: `T_P113_01` — Solid Solution in BaS–La2S3 Ceramics Produced by Mechanosynthesis and Their Potential for Rare-Earth Doping

## Goal

Identify thermal events (e.g., decomposition, sulfur loss) and assess phase stability limits under controlled atmosphere.

## Input

- as-milled x BaS–(1−x) La2S3 powders (e.g., x = 33)
- DTA–TGA instrument

## Output

- thermograms showing thermal events (e.g., exothermic/endothermic peaks)
- mass loss profiles
- transition temperature (~920 K)

## Datasets used

- as-milled x BaS–(1−x) La2S3 powders (x = 0, 15, 33, 50, 67) — screening: Thermal stability assessment via DTA–TGA to identify sulfur loss events

## Evidence

- P113, PDF page 1, ABSTRACT: "Calorimetric analysis of the same samples indicates a thermal event near 920 K associated with a small mass loss."
- P113, PDF page 4, Phase Stability: "The thermogram and corresponding mass loss of sample x = 33 shown in Figure 6 reveals a systematic thermal event near 920 K, which was found to be highly reproducible in all samples from the solid solution domain, but that was not observed in pure γ-La2 S3 . This event is associated with a small but systematic mass loss, which is associated with sulfur evaporation."
