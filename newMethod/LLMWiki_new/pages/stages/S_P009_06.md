# Stage: evaluating performance on test set across six properties

- Stage ID: `S_P009_06`
- Stage type: `model_evaluation`
- Stage order: 6
- Task: `T_P009_01` — predicting the properties of crystalline materials using large language models

## Goal

Quantify predictive accuracy of LLM-Prop against baselines using MAE (regression) and AUC (classification).

## Input

- test set (9,888 samples)
- LLM-Prop predictions
- ground-truth labels

## Output

- MAE scores for band gap, volume, FEPA, EPA, Ehull; AUC for Is-gap-direct

## Datasets used

- TextEdge — test: Evaluate predictive accuracy of LLM-Prop against baselines using MAE (regression) and AUC (classification).

## Evidence

- P009, PDF page 4, Data collection and analysis: "The data originally contained 145,825 crystals structure-description pairs which we randomly split into 125,825 samples for the training set, 10,000 samples for the validation set and 10,000 samples for the test set. However, when parsing the CIF files to build the graphs that are used to fine-tune GNN’s baselines, some structure files failed to be incorporated, ending up with 125,098 training samples, 9,945 validation samples, and 9,888 samples for the test set..."
- P009, PDF page 11, LLM-Prop: "For regression tasks, we train both MatBERT and LLM-Prop with the mean absolute error (MAE) loss and evaluate them in terms of MAE error while the GNN-based models are trained with root mean square error (RMSE) loss and evaluated with the MAE error. For classification, we train them with binary cross entropy (BCE) loss and evaluate with the area under the ROC curve (AUC)."
