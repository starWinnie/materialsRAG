# Stage: validating models using internal and external metrics

- Stage ID: `S_P074_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P074_01` — predicting dielectric constants (ε) for polymers

## Goal

Assess model robustness and predictive ability using multiple validation protocols including training/test split, LOO cross-validation, y-scrambling, and Williams plot analysis.

## Input

- trained QSPR models
- experimental dielectric constant data

## Output

- validated models with R2, Q2, s, F, AD assessment

## Datasets used

- None stated

## Evidence

- P074, PDF page 4, MATERIALS AND METHODS: "For validation purposes, multiple methods were applied, including leave-one-out (LOO) cross validation, y-scrambling, as well as internal and external validation protocols. After validation techniques were applied, the best model was chosen based on multiple criteria: (1) high statistical performance of R2 and Q2 variables (including R2 −Q2 < 0.3);43 (2) a low number of variables in the model; (3) low cross-correlation between descriptors in the selected model; and (4) best performance of R2 for the external validation set (test set) to avoid model overfitting."
- P074, PDF page 5, RESULTS AND DISCUSSION: "The applicability domain (AD) check was performed by application of leverage approach, i.e., William’s plot evaluation for the final models."
