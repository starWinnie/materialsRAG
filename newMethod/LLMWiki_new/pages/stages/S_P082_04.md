# Stage: Comparison and statistical analysis of IFSS and interface friction strength

- Stage ID: `S_P082_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P082_01` — Understanding the fiber–matrix interface properties governing the fiber-direction compressive strength improvement of the hybrid HM CFRPs

## Goal

To quantify and statistically compare interface shear strength and interface friction strength between IM and HM fibers.

## Input

- IFSS measurements from push-out tests
- Interface friction strength measurements from push-back tests
- Six replicates per fiber type

## Output

- Average IFSS: 122 MPa (IM) vs. 93 MPa (HM)
- Average interface friction strength: 36.7 MPa (IM) vs. 18.9 MPa (HM)
- 48% higher interface friction for IM fibers

## Datasets used

- None stated

## Evidence

- P082, PDF page 8, 6. Results: "Figure 7a confirms that the average measured IFSS value in IM fibers (122 Mpa) is 30% higher than HM fibers (93 Mpa)."
- P082, PDF page 8, 6. Results: "According to the outcome of the fiber push-back tests, the average interfacial friction strength of HM fibers was estimated as 18.9 MPa while IM fibers in the same material system have an average interfacial friction strength of 36.7 MPa. The test results show an approximately 48% decrease in the average values of the fiber-to-matrix interface friction strength for the HM carbon fibers compared to their IM counterparts."
