# Stage: representing crystal structures in fractional coordinate system

- Stage ID: `S_P023_02`

- Stage order: 2

## Goal

Encode crystal structures using atom features A, fractional coordinates F, and lattice matrix L to reflect periodicity and enable symmetry-aware modeling

## Input

- raw crystal structure data

## Output

- C = (A, F, L) representation

## Datasets used

- None stated

## Evidence

- P023, PDF page 2, Preliminaries: "We resort to the fractional coordinate system in this work since it can easily reflect the periodic nature of crystal structures. The crystal is now denoted by a tuple C = (A, F, L) with F = [f 1, · · · , f N] ∈[0, 1)3×N containing the fractional coordinates of all atoms in the unit cell."
