# Stage: Data Standardization

- Stage ID: `S_P060_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P060_01` — deep fusion of experimental and theoretical data in condensed matter physics

## Goal

transform raw, heterogeneous inputs into a consistent, analysis-ready format by establishing canonical representations for crystal structures and enforcing standardized nomenclature and units for property data

## Input

- raw, heterogeneous multimodal data

## Output

- standardized, canonical data with consistent structural representations and metadata

## Datasets used

- Crystal Structure and Diffraction Database (COD-derived) — training: providing standardized crystal structures for canonical representation and symmetry resolution using pymatgen and spglib
- MatElab Single-Crystal Growth Database — training: providing standardized experimental records with full provenance for canonical representation and metadata enforcement

- P060, PDF page 4, Data Standardization: "A rigorous and automated data standardization pipeline is the bedrock of the MaterialsGalaxy platform, transforming raw, heterogeneous inputs into a consistent, analysis-ready format."
- P060, PDF page 4, Data Standardization: "The standardization process is centered on establishing a canonical representation for crystal structures, the universal anchors for data linking.
