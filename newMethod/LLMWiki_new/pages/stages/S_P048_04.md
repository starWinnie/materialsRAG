# Stage: train machine learning models (RF, XGBoost, SISSO) on diffusivity data

- Stage ID: `S_P048_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P048_01` — predict Li-ion diffusivity in non-crystalline materials

## Goal

Train ensemble learning models (Random Forest, XGBoost) and a descriptor-based model (SISSO) to learn the relationship between compositional/structural features and Li-ion diffusivity.

## Input

- compositional features
- structural features
- Li-ion diffusivity labels

## Output

- trained RF model
- trained XGBoost model
- trained SISSO model

## Datasets used

- multi-temperature non-crystalline database — training: Train machine learning models (RF, XGBoost, SISSO) to predict Li-ion diffusivity and activation energy. / Validate machine learning models during training using cross-validation.
