# Stage: evaluation of extrapolative prediction performance

- Stage ID: `S_P015_05`
- Stage type: `model_evaluation`
- Stage order: 5
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To assess generalization on unseen material domains (e.g., left-out polymer class or perovskite composition).

## Input

- trained MNN
- test data from extrapolative domain

## Output

- RMSE, R² scores for Cp, refractive index, bandgap

## Datasets used

- RadonPy polymer dataset — test: Evaluation of extrapolative prediction performance on unseen polymer classes
- HOIP dataset — test: Evaluation of extrapolative prediction performance on unseen perovskite compositions (HOIP-GeF and HOIP-PbI)

## Evidence

- P015, PDF page 3, Results: "To evaluate the prediction performance for an unseen polymer class, the following process was implemented: (1) a model was trained using randomly selected samples from 19 of the 20 polymer classes and (2) its generalizability was assessed using data from the remaining polymer class."
- P015, PDF page 5, Results: "We performed numerical experiments using the same setting as that employed by Na et al.42,43. The HOIP dataset was divided into 12 groups based on the combinations of four anions and three cations... During the inference phase, the entire training dataset D was assigned to S."
