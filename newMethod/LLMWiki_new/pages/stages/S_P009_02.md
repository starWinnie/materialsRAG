# Stage: generating crystal text descriptions using Robocrystallographer

- Stage ID: `S_P009_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P009_01` — predicting the properties of crystalline materials using large language models

## Goal

Convert crystal structures (CIF files) into natural language text descriptions.

## Input

- CIF files from Materials Project

## Output

- crystal text descriptions (e.g., 'NaCl is Tetraauricupride structured and crystallizes in the cubic Pm3m space group...')

## Datasets used

- Materials Project database (as of November 1, 2022) — source: Generate crystal text descriptions using Robocrystallographer.

## Evidence

- P009, PDF page 4, Data collection and analysis: "For each crystal, we collect its ID, structural information, structure text description, and the aforementioned six properties. We generated the crystal text descriptions using Robocrystallographer41, a tool that generates a deterministic human readable text description of a structure given its CIF file."
