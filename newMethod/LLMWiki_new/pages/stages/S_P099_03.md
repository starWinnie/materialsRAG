# Stage: Microstructure characterization and analysis

- Stage ID: `S_P099_03`
- Stage type: `model_evaluation`
- Stage order: 3
- Task: `T_P099_01` — Investigation of isothermal continuous hot deformation behavior

## Goal

To characterize and quantify microstructural features including grain size, grain boundary types, misorientation, texture, and segregated phase morphology.

## Input

- etched discs
- TEM foils
- EBSD and TEM equipment

## Output

- grain size measurements
- pole figures (PF), inverse pole figures (IPF)
- kernel average misorientation (KAM) maps
- grain orientation spread (GOS) maps
- TEM images of MC carbides and dislocation structures

## Datasets used

- as-cast alumina-forming austenitic (AFA) alloy — source: To characterize and quantify microstructural features including grain size, grain boundary types, misorientation, texture, and segregated phase morphology.

## Evidence

- P099, PDF page 2, Experimental procedure: "Electron back-scattered diffraction (EBSD) tests were carried out by a Zeiss Gemini SEM300 field emission scanning electron microscope (SEM). AztecCrystal software was used to process the EBSD data to determine the grain size, pole figure (PF), inverse pole figure (IPF), kernel average misorientation (KAM) maps, texture component (TC) map, and grain orientation spread (GOS) map."
- P099, PDF page 2, Experimental procedure: "TEM observation was carried out on a JEOL-2100 F transmission electron microscope with an operating voltage of 200 kV."
