## Evidence

- P057, PDF page 2, 2.1. Crystal Representation: "Crystal materials can be viewed as a 3D point cloud (Fig. 4(a)) of atoms arranged in an orderly repeating pattern. For a material with N atoms in its unit cell, the structure can be defined as M = (A, X, L). Atom Type Matrix: A = [a1, a2, ..., aN]T ∈RN×k, where each ai is a one-hot vector denoting the atomic type of the ith atom, and k is the maximum number of possible atom types. Coordinate Matrix: X = [x1, x2, ..., xN]T ∈RN×3, where xi ∈R3 represents the 3D coordinates of the ith atom in the unit cell. Lattice Matrix: L = [l1, l2, l3]T ∈R3×3, which specifies how the unit cell repeats itself in 3D space along directions l1, l2, and l3 to form the periodic crystal."
