# Stage: computing material properties and error metrics

- Stage ID: `S_P059_05`
- Stage type: `computational_validation`
- Stage order: 5
- Task: `T_P059_01` — benchmarking machine learning force fields (MLFFs)

## Goal

compute target properties (elastic tensor, phonons, surface energy, vacancy formation, work of adhesion, RDF) using uMLFFs and quantify errors against reference data

## Input

- converged relaxed structures
- uMLFF ASE calculators
- reference data

## Output

- computed property values
- mean absolute error (MAE)
- Pearson correlation coefficient
- parity plots
- computational timing per property

## Datasets used

- CHIPS-FF 104-material test set — benchmark: compute and evaluate target properties (elastic tensor, phonons, surface energy, vacancy formation, work of adhesion, RDF) using uMLFFs
- CHIPS-FF 84-material phonon subset — benchmark: compute and evaluate phonon band structure predictions
- CHIPS-FF 85-material surface subset — benchmark: compute and evaluate surface energy predictions
- CHIPS-FF 48-material defect subset — benchmark: compute and evaluate vacancy formation energy predictions

## Evidence

- P059, PDF page 3: "Once each uMLFF is loaded and run through the Atomic Simulation Environment (ASE) calculator, a variety of properties can be computed. As these calculations are carried out, detailed logging information is saved, including the computational timing for each stage of the calculation and whether or not each stage converged. Once these material properties are computed with each uMLFF, they are cross checked with entries in the JARVIS-DFT database and the mean absolute error (MAE) for each property is computed."
- P059, PDF page 3: "For each of the 104 structures, we performed structural relaxations, fitting of the energy vs volume curve (equation of state), calculation of the elastic tensor, calculation of the phonon band structure, relaxation of all nonpolar surfaces..., and relaxation of each type of point defect in the material."
