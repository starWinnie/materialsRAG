# Stage: Preparation of candidate structures for virtual screening

- Stage ID: `S_P019_05`
- Stage type: `candidate_generation`
- Stage order: 5
- Task: `T_P019_01` — Dielectric tensor prediction for inorganic materials

## Goal

Download and select thermodynamically stable non-metal materials from MP for virtual screening.

## Input

- Materials Project database

## Output

- 14,375 non-metal materials with energy above convex hull Ehull = 0

## Datasets used

- MP candidate set for virtual screening (14,375 non-metal materials) — candidate_pool: Candidate pool for virtual screening of thermodynamically stable non-metal materials.

## Evidence

- P019, PDF page 8, unknown: "Preparation of candidate structures. The DTNet model has been proven effective predicting dielectric tensors which account for the direction and magnitude of the electric ﬁeld. To prepare the candidate set for screening, we downloaded 14,375 non-metal materials from the MP database. These materials are speciﬁcally selected based on the energy above convex hull Ehull = 0 to estimate their thermodynamic stability, so that only stable materials are included in the candidate set."
