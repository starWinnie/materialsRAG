# Stage: Train classical ML models in delta-learning framework using fMLIP latent features

- Stage ID: `S_P035_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P035_01` — Correcting DFT formation energies towards experimental accuracy

## Goal

Learn empirical corrections to the zero-shot fMLIP formation energies using their latent features as input

## Input

- PET-OMATPES latent features
- delta target (δ∆HMLIP_f = PET-OMATPES r2SCAN formation energy − experimental formation enthalpy)

## Output

- trained KRR/GPR/RF models
- predicted residual corrections

## Datasets used

- Materials Cloud three-dimensional crystals database — source: Provide PET-OMATPES latent features extracted from PBEsol-relaxed geometries as input for delta-learning models
- expt formation enthalpy kingsbury dataset — label_source: Provide experimental formation enthalpy references to compute delta target (δ∆HMLIP_f = PET-OMATPES r2SCAN formation energy − experimental formation enthalpy)
- experimental references from Kirklin et al. — label_source: Provide additional experimental formation enthalpy references to compute delta target (δ∆HMLIP_f = PET-OMATPES r2SCAN formation energy − experimental formation enthalpy)
