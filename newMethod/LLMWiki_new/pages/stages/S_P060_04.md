# Stage: Vector database and similarity search

- Stage ID: `S_P060_04`
- Stage type: `candidate_screening`
- Stage order: 4
- Task: `T_P060_01` — deep fusion of experimental and theoretical data in condensed matter physics

## Goal

dynamically link disparate data records at query time by performing high-speed similarity searches over indexed structural fingerprints to retrieve direct data and structural analogs

## Input

- structural fingerprints

## Output

- linked multi-modal material profiles
- lists of structurally analogous materials (analogs)

## Datasets used

- Crystal Structure and Diffraction Database (COD-derived) — screening: enabling high-speed similarity searches to dynamically link disparate data records based on structural fingerprints
- MatElab Single-Crystal Growth Database — screening: enabling high-speed similarity searches to retrieve structural analogs for missing experimental synthesis records

## Evidence

- P060, PDF page 5, Core data fusion: Structure-based similarity linking: "Second, and most critically, data fusion occurs dynamically at query time through a high-performance vector search index. All structural fingerprints are indexed using Approximate Nearest Neighbor (ANN) algorithms (e.g., HNSW-based graphs[61]), enabling sub-second similarity searches."
- P060, PDF page 5, Core data fusion: Structure-based similarity linking: "When a user views a specific material entry, the platform performs multiple, context-aware searches to retrieve two classes of information for each property module: (1) direct data, which is any information directly linked to the queried material’s exact structure, and (2) analog data, which comprises the properties of structurally analogous materials."
