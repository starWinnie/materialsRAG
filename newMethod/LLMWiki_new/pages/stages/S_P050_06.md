# Stage: multi-modal Retrieval-Augmented Generation (RAG) inference with L2-similarity retrieval

- Stage ID: `S_P050_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P050_01` — material property prediction and human-AI interaction for materials science

## Goal

To improve robustness at inference time by retrieving two most similar materials from training set based on bridge-model embedding L2 similarity and aggregating predictions.

## Input

- query material structure
- training set embeddings

## Output

- aggregated final output (majority vote for classification, average for numerical)

## Datasets used

- None stated

## Evidence

- P050, PDF page 8, 2.3 MatterChat extracted embeddings contain structural and property information: "Given that the embeddings derived from bridge model preserve both material structure and property-relevant information, we implemented a multi-modal Retrieval-Augmented Generation (RAG) mechanism during inference... Instead of relying solely on a single output from MatterChat for each query-sample pair, we now retrieve additional information of two more samples from the material pool (training set). This retrieval is based on the L2 similarity between the embeddings of the sample material and those in the pool. After that, we aggregate all three results to get the final output by applying a majority-voting strategy for classification tasks and averaging for quantitative tasks."
