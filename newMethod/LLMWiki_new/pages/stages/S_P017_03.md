# Stage: Defining OOD labels via top/bottom percentile thresholds

- Stage ID: `S_P017_03`
- Stage type: `label_generation`
- Stage order: 3
- Task: `T_P017_01` — Out-of-Distribution Property Prediction

## Goal

Identify out-of-distribution (OOD) samples by selecting extreme property value ranges not present in training data.

## Input

- property values
- training distribution

## Output

- OOD test set (top 5% highest property values)
- ID validation set (random 5% of remaining data)

## Datasets used

- AFLOW — candidate_pool: Defining OOD labels via top 5% highest property values
- Matbench — candidate_pool: Defining OOD labels via top 5% highest property values
- Materials Project — candidate_pool: Defining OOD labels via top 5% highest property values
- MoleculeNet — candidate_pool: Defining OOD labels via top 5% highest property values

## Evidence

- P017, PDF page 6, Methods: "We split the data into training, validation and test sets such that OOD test samples Dte_Y ⊂ Y are 5% of the data with the highest property values, an ID validation set is a random sample of 5% of the remaining data, and the training set Dtr = {(x, y)}n ⊂ X × Y is the rest."
- P017, PDF page 6, Methods: "If, instead, the goal were to identify materials with exceptionally low property values, we could redefine OOD samples as the bottom 5% rather than the top 5%."
