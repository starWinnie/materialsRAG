# Stage: Generating five types of OOD test sets via clustering and density estimation

- Stage ID: `S_P029_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P029_01` — Structure-based out-of-distribution (OOD) materials property prediction

## Goal

Produce five distinct OOD test set configurations (LOCO, SparseXsingle, SparseXcluster, SparseYsingle, SparseYcluster) that deviate from training distribution

## Input

- OFM feature space
- property values (y-values)
- t-SNE 2D embedding

## Output

- 50-fold LOCO test sets
- 50-fold SparseXsingle test sets
- 50-fold SparseXcluster test sets
- 50-fold SparseYsingle test sets
- 50-fold SparseYcluster test sets

## Datasets used

- matbench_dielectric — candidate_pool: Generate five types of OOD test sets via clustering and density estimation
- matbench_log_gvrh — candidate_pool: Generate five types of OOD test sets via clustering and density estimation
- matbench_perovskites — candidate_pool: Generate five types of OOD test sets via clustering and density estimation
