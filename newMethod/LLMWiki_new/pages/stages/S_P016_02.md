# Stage: Preprocessing and splitting for OOD tasks

- Stage ID: `S_P016_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P016_01` — Probing out-of-distribution generalization in machine learning for materials

## Goal

To construct statistically OOD train-test splits based on predefined chemical or structural criteria.

## Input

- JARVIS, MP, OQMD datasets

## Output

- Over 700 OOD tasks (e.g., leave-one-element-out, leave-one-period-out, leave-one-space-group-out)

## Datasets used

- JARVIS-DFT — training: Constructing OOD tasks via leave-one-X-out splitting based on chemistry or structural symmetry criteria
- Materials Project — training: Constructing OOD tasks via leave-one-X-out splitting based on chemistry or structural symmetry criteria
- Open Quantum Materials Database (OQMD) — training: Constructing OOD tasks via leave-one-X-out splitting based on chemistry or structural symmetry criteria

## Evidence

- P016, PDF page 2, Evaluation setup: "We primarily consider six criteria for deﬁning OOD test data: (1) materials containing element X, (2) materials containing any element in the period X, (3) materials containing any element in the group X, (4) materials of space group X, (5) materials of point group X, (6) materials of crystal system X. We consider these leave-one-X-out tasks for all possible values of X but exclude those with fewer than 200 test samples."
