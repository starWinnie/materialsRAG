# Stage: Identification of MPB composition window

- Stage ID: `S_P109_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P109_01` — Enhanced Magnetoelectric Coupling and Thermal Stability in Nd-Doped BiFeO3 Ceramics Near the Morphotropic Phase Boundary

## Goal

To determine the compositional range (x) where R3c and Pbam phases coexist — the morphotropic phase boundary.

## Input

- XRD patterns
- Rietveld refinement outputs
- phase evolution trends

## Output

- MPB region identified as x = 0.10–0.18, centered at x = 0.16

## Datasets used

- Bi1-xNdxFeO3 ceramic composition series — source: Identification of MPB composition window via structural phase evolution analysis

## Evidence

- P109, PDF page 3, 3 Results and Discussion: "Based on these structural observations, an MPB region is identified roughly in the composition range of x = 0.10–0.18. At this boundary, the competition between the polar R3c phase and the Pbam phase, which exhibits an antipolar nature similar to PbZrO3, leads to an instability of the polarization state."
