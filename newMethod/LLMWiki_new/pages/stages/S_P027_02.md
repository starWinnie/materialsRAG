# Stage: preprocessing of crystal structures and phonon data

- Stage ID: `S_P027_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P027_01` — phonon spectra and bandstructure prediction

## Goal

Convert raw crystal structures and phonon data into machine-learnable representations suitable for GNN input

## Input

- crystal structures
- phonon dispersion data

## Output

- periodic crystal graphs
- normalized phonon frequency labels
- high-symmetry k-path definitions

## Datasets used

- DFPT computational database for phonon dispersion — training: training data for phonon prediction models / testing data for phonon prediction models
- Atsushi Togo's phonon database — test: testing data for phonon prediction models on complex materials

## Evidence

- P027, PDF page 12, I DATA PREPARATION: "The data set containing full phonon bands of 1521 semiconducting inorganic materials are calculated from density functional perturbation theory (DFPT)?, which is the main dataset for training (“Main Database” for short). The phonon energy values at Γ-points (for vector virtual nodes, VVN and matrix virtual nodes, MVN model), and other high symmetric points (k-MVN model) were extracted and randomly split for training (90%) and testing set (10%)."
- P027, PDF page 9, Methods: "We used seekpath11,33 module to get the highly symmetric path of each material. Then, we fed it alongside POSCAR, FORCE_SET, and phonopy.config files from the database to Phonopy32’s python command to calculate the phonon dispersion along such path."
- P027, PDF page 9, Methods: "To quality control the data, we selected materials whose lowest Γ-phonon band is higher than −0.07 cm−1. We also filtered the material to get only the ones with more than 40 atoms per unit cell."
