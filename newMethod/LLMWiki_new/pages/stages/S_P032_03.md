# Stage: supervised pretraining of MD-ET on QCML

- Stage ID: `S_P032_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P032_01` — molecular dynamics simulation using a neural network force field

## Goal

Train the MD-adapted edge transformer (MD-ET) to predict atomic forces directly (not via energy gradients) using mean absolute error loss on QCML.

## Input

- QCML train split
- augmented batches
- MD-ET architecture with MD-specific embedding layers

## Output

- pretrained MD-ET checkpoint

## Datasets used

- QCML — training: Supervised pretraining of MD-ET to predict atomic forces directly using mean absolute error loss.

## Evidence

- P032, PDF page 3, We examine the effects of forgoing almost all commonly: "We perform supervised pretraining on the new QCML dataset.45 [...] During training, we use two randomly rotated and mirrored copies of each sampled structure so that our model can learn approximate O(3)-equivariance. Instead of predicting a combined loss50 of energies and forces or calculating forces as the negative gradient of the predicted energy with respect to positions, we predict forces directly."
- P032, PDF page 5, Pretraining performance: "We train MD-ET for 880k steps on QCML using a batch size of 1024 (i.e., 512 before data augmentation), which takes ∼16 A100 GPU-days"
