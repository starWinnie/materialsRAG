# Stage: Querying the NOMAD Archive via RESTful API

- Stage ID: `S_P056_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P056_01` — AI-based analysis of materials-science data

## Goal

Retrieve FAIR materials-science data from the NOMAD Archive using structured queries based on the NOMAD Metainfo schema.

## Input

- query parameters (e.g., {'atoms': ['O']}, VASP/GGA calculations, converged geometry)

## Output

- retrieved dataset (e.g., ~8000 ternary oxide entries) with metadata and simulation results

## Datasets used

- NOMAD Archive — source: Source database queried via RESTful API to retrieve FAIR materials-science data.
- NOMAD ternary oxide subset (VASP/GGA, converged) — training: Training dataset for clustering analysis targeting atomic density.
