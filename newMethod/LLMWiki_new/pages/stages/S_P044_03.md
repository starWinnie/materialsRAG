# Stage: Temporal data split for historical validation

- Stage ID: `S_P044_03`
- Stage type: `data_preparation`
- Stage order: 3
- Task: `T_P044_01` — Precursor recommendation for inorganic synthesis

## Goal

Split the dataset into training (≤2014), validation (2015–2016), and test (2017–2020) sets to simulate generalization to newly reported materials.

## Input

- 49,924 expanded reactions

## Output

- training set: 44,736 reactions / 24,304 targets
- validation set: 2,254 reactions / 1,910 targets
- test set: 2,934 reactions / 2,654 targets

## Datasets used

- None stated

## Evidence

- P044, PDF page 29, Data preparation: "We split the data based on the year of publication, i.e., training set (or knowledge base) for reactions published by 2014, validation set for reactions in 2015 and 2016, and test set for reactions from 2017 to 2020."
- P044, PDF page 17, Recommendation of precursor materials: "Using the knowledge base of 24,034 materials reported by the year 2014, we predict precursors for 2,654 test target materials newly reported from 2017 to 2020."
