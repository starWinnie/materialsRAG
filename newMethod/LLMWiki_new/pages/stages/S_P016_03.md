# Stage: Training representative ML models on each OOD task

- Stage ID: `S_P016_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P016_01` — Probing out-of-distribution generalization in machine learning for materials

## Goal

To fit multiple ML architectures (tree ensembles, neural networks, GNNs, LLMs) on the training split of each OOD task using consistent hyperparameters.

## Input

- OOD training splits
- Matminer descriptors
- GMP features
- crystal graphs
- crystal text descriptions

## Output

- Trained RF, XGB, ALIGNN, GMP, LLM-Prop models per task

## Datasets used

- JARVIS-DFT — training: Training ML models (RF, XGB, ALIGNN, GMP, LLM-Prop) on OOD training splits
- Materials Project — training: Training ML models (RF, XGB, ALIGNN, GMP, LLM-Prop) on OOD training splits
- Open Quantum Materials Database (OQMD) — training: Training ML models (RF, XGB, ALIGNN, GMP, LLM-Prop) on OOD training splits

- P016, PDF page 2, Evaluation setup: "OOD performance is evaluated by training a representative set of ML models, including (1) random forest (RF)33 and XGBoost (XGB)34 models with Matminer descriptors35.
