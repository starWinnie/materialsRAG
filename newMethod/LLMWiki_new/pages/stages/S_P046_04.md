# Stage: Training ALIGNN models with MSE and NLL loss

- Stage ID: `S_P046_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P046_01` — Predicting solid-state material properties

## Goal

Optimize ALIGNN parameters using backpropagation on regression (MSE) and classification (negative log likelihood) objectives.

## Input

- atomistic and line graph representations
- property labels
- hyperparameters (300 epochs, AdamW, batch size 64, one-cycle LR)

## Output

- trained ALIGNN models for 44 properties

## Datasets used

- Materials Project — training: Train ALIGNN models using regression and classification objectives. / Validate ALIGNN models during training. / Evaluate final model performance on held-out test set.
- JARVIS-DFT — training: Train ALIGNN models using regression and classification objectives. / Validate ALIGNN models during training. / Evaluate final model performance on held-out test set.
