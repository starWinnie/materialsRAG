# Stage: compute classical force-field inspired descriptors (CFID)

- Stage ID: `S_P064_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P064_01` — fast screening and mapping energy landscape for multicomponent systems

## Goal

Generate fixed-length chemo-structural descriptors including radial, angular, dihedral, charge, and chemical features

## Input

- crystal structures (primitive/conventional/supercell)
- elemental properties
- pseudopotential library for atomic radial charge

## Output

- 1557-dimensional CFID descriptor vectors per material

- None stated
