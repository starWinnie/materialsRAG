# Stage: Using DFT-computed property values as labels

- Stage ID: `S_P046_03`
- Stage type: `label_generation`
- Stage order: 3
- Task: `T_P046_01` — Predicting solid-state material properties

## Goal

Assign ground-truth property values (from DFT calculations) as regression or classification targets.

## Input

- JARVIS-DFT and MP dataset property values

## Output

- regression labels (e.g., formation energy in eV/atom, bandgap in eV)
- classification labels (e.g., metal/non-metal based on 0.01 eV threshold)

## Datasets used

- Materials Project — label_source: Provide ground-truth property values (formation energy, band gap) as regression targets.
- JARVIS-DFT — label_source: Provide ground-truth property values (formation energy, band gaps, dielectric constants, moduli, magnetic moment, etc.) as regression or classification targets.
