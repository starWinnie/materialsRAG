- Stage ID: `S_P033_04`
- Stage type: `model_evaluation`
- Stage order: 4

## Goal

Evaluate performance of trained models using RMSE and Pearson correlation coefficient

## Input

- test dataset
- trained models

## Output

- RMSE and r values for each algorithm
- best-performing model (Xgboost)

## Datasets used

- Experimental ABX3-type perovskite bandgap dataset — test: Test input for evaluating model performance (RMSE, r)
- Experimental CBM and VBM dataset for ABX3-type perovskites — test: Test input for evaluating CBM and VBM model performance
