# Stage: classification and organization of alloy compositions into material classes

- Stage ID: `S_P069_03`
- Stage type: `data_preparation`
- Stage order: 3
- Task: `T_P069_01` — creation of a corrosion resistant alloys database with electrochemical metrics

## Goal

To assign each composition to a consistent 'Material class' based on elemental composition and source context.

## Input

- alloy compositions
- source literature descriptions

## Output

- categorized records: Fe-based alloys, Al-based alloys, high entropy alloys (HEAs), Ni-Cr-Mo ternary system, Other

## Datasets used

- Electrochemical Metrics for Corrosion Resistant Alloys Database — source: To assign each composition to a consistent 'Material class' based on elemental composition and source context.

## Evidence

- P069, PDF page 3, Methods: "Each composition was assigned a “Material class” based on the elements present and the source of the data. The Fe- and Al- based alloys are compositions that contain >35 wt. % Fe or Al, respectively. High entropy alloys are compositions that were reported as such in the source literature. The Ni-Cr-Mo ternary system contains alloys with all three elements present as well as some compositions containing just one or two of the three base elements. Alloy compositions which fall outside these bounds are classified as “Other”."
