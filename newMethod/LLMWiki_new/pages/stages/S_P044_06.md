# Stage: Recipe completion via masked precursor completion (MPC)

- Stage ID: `S_P044_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P044_01` — Precursor recommendation for inorganic synthesis

## Goal

For each candidate reference material, extract its precursors; if element coverage is incomplete, use MPC to predict missing precursors conditioned on the available ones.

## Input

- precursors from reference material
- novel target composition

## Output

- complete precursor set for novel target

## Datasets used

- None stated

## Evidence

- P044, PDF page 17, Recommendation of precursor materials: "When the precursors used in the synthesis of the reference material cannot cover all elements of the target, we use MPC in Fig. 3B to predict the missing precursors."
- P044, PDF page 17, Recommendation of precursor materials: "For example, for Y2FeSbO7 (Fig. 1B), the most similar material in the knowledge base is FeSbO4. It is reasonable to assume that the precursors Fe2O3 and Sb2O5 used in the synthesis of FeSbO4 (38) can also be used to synthesize Y2FeSbO7. Because the Y source is missing, MPC finds Y2O3 is likely to fit with Fe2O3 and Sb2O5 for the synthesis of Y2FeSbO7, ending up as a complete precursor set (Fe2O3, Sb2O5, and Y2O3) (39)."
