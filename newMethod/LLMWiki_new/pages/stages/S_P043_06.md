# Stage: Comparison of linear vs. neural network correction models

- Stage ID: `S_P043_06`
- Stage type: `candidate_screening`
- Stage order: 6
- Task: `T_P043_01` — ML-based correction of DFT formation enthalpy errors for improved phase stability prediction

## Goal

Screen and compare candidate correction approaches (linear regression vs. MLP) to identify the superior method for reducing DFT enthalpy error.

## Input

- linear model predictions
- neural network predictions
- experimental Hcorr

## Output

- quantitative comparison showing MLP superiority (e.g., RMSE reduction from 31.4 to 10.6 meV/atom)

## Datasets used

- Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems — screening: Compare linear vs. neural network correction models by evaluating RMSE on same experimental reference

## Evidence

- P043, PDF page 6: "While the linear model offers some level of correction, its predictive power is ultimately constrained by its functional form. Even with interaction terms such as xAxB and xAxBxC, it cannot fully account for the intricate relationships governing enthalpy corrections. The neural network, in contrast, demonstrates a much greater ability to capture these relationships, leading to a substantial improvement in predictive accuracy."
- P043, PDF page 6: "Figure 5 [...] highlights the difference between experimental data and the DFT corrected values of H, as obtained from the linear and neural network models. Nearly all points of the ML model exhibit a reduction in error compared to the linear model, confirming that the machine learning approach better captures the errors of the DFT calculations."
