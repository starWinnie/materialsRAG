# Stage: Validate ct-UAE physical interpretability via reverse prediction

- Stage ID: `S_P006_06`
- Stage type: `computational_validation`
- Stage order: 6
- Task: `T_P006_01` — Generate universal atomic embeddings (UAEs) for crystal property prediction

## Goal

Validate that ct-UAEs encode meaningful physical/chemical atomic properties by training a CatBoost model to predict elemental properties from embeddings.

## Input

- ct-UAE tensors
- elemental properties (atomic radius, boiling temperature, etc.)

## Output

- R2 scores for reverse prediction (e.g., >0.78 for all properties)
- SHAP importance analysis

## Datasets used

- Materials Project (2018.6.1) — label_source: Providing elemental properties (atomic radius, boiling temperature, etc.) for reverse prediction to validate physical interpretability of ct-UAEs
