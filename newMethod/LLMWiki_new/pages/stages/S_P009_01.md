# Stage: collecting dataset from Materials Project database

- Stage ID: `S_P009_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P009_01` — predicting the properties of crystalline materials using large language models

## Goal

Acquire crystal structure-description pairs and associated property labels.

## Input

- Materials Project database (as of November 1, 2022)

## Output

- 145,825 crystal structure-description pairs with six properties: band gap, formation energy per atom, energy above hull, crystal volume, energy per atom, and Is-gap-direct indicator

## Datasets used

- Materials Project database (as of November 1, 2022) — source: Acquire crystal structure-description pairs and associated property labels.

## Evidence

- P009, PDF page 4, Data collection and analysis: "We collected the dataset used in this work from the Materials Project database40 using the Materials Project free API as of November 1, 2022. We focus on six crystal properties that include both regression and classification tasks and are diverse enough to evaluate the capabilities of any property predictor. We collect the data of band gap, formation energy per atom (FEPA), energy above hull (Ehull), crystal volume, energy per atom (EPA), and an indicator of whether the band gap is direct or indirect (Is-gap-direct)."
