# Stage: fine-tuning T5 encoder with linear prediction head

- Stage ID: `S_P009_05`
- Stage type: `model_training`
- Stage order: 5
- Task: `T_P009_01` — predicting the properties of crystalline materials using large language models

## Goal

Train LLM-Prop by fine-tuning the encoder of T5-small on preprocessed text inputs to regress/classify crystal properties.

## Input

- preprocessed text descriptions
- normalized property labels (z-score, min-max, or log)

## Output

- fine-tuned LLM-Prop model (T5 encoder + linear layer)

## Datasets used

- TextEdge — training: Fine-tune T5 encoder with linear prediction head on preprocessed text inputs to regress/classify crystal properties.

## Evidence

- P009, PDF page 2, Results: "LLM-Prop leverages T5 by directly adding a linear layer on top of its encoder for regression tasks. This linear layer can be composed with a sigmoid or softmax activation for classification tasks. Relying only on the T5 encoder reduces the total number of parameters by half which allows us to train on longer sequences..."
