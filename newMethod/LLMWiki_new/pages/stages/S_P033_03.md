# Stage: training of bandgap prediction models

- Stage ID: `S_P033_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P033_01` — bandgap prediction of ABX3-type perovskites

## Goal

Train multiple ML models to predict bandgap of ABX3-type perovskites

## Input

- training dataset
- 8 chemical components as features

## Output

- trained bandgap prediction models (BPMs)

## Datasets used

- Experimental ABX3-type perovskite bandgap dataset — training: Training input for multiple ML models (LR, KNN, SVR, RF, MLP, Xgboost)
- Experimental CBM and VBM dataset for ABX3-type perovskites — training: Training input for CBM and VBM prediction models using Xgboost
