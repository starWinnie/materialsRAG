# Stage: analysis of compositional-microstructural-property relationships

- Stage ID: `S_P088_07`
- Stage type: `candidate_screening`
- Stage order: 7
- Task: `T_P088_01` — engineering optimisation of as-cast HCWCIs

## Goal

identify optimal compositional windows and mechanistic trade-offs by correlating Cr/C, CVF, and matrix Cr with property responses

## Input

- Cr/C ratios
- carbide volume fractions
- matrix chromium content
- hardness
- fracture toughness
- abrasion wear rates
- corrosion rates

## Output

- optimal compositional window (Cr/C = ~12; CVF = ~33%)
- abrasion-corrosion trade-off
- mechanistic understanding of chromium partitioning

## Datasets used

- None stated

## Evidence

- P088, PDF page 1, ABSTRACT: "Mechanical and tribological properties showed pronounced non-linearity, with an optimal compositional window (Cr/C = ~12; CVF = ~33%) maximising hardness, fracture toughness and three-body abrasion resistance."
- P088, PDF page 1, ABSTRACT: "Corrosion resistance correlates mainly with matrix chromium availability, revealing a trade-off between wear and electrochemical performance."
- P088, PDF page 16, Discussion: "The optimal compositional window for abrasion-dominated environments lies near the eutectic regime (Cr/C = ~12; CVF = ~33%), whereas corrosion resistance favours higher Cr/C ratios that maximise matrix chromium retention."
