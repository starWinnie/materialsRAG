# Stage: evaluation of model performance against benchmarks

- Stage ID: `S_P061_04`
- Stage type: `model_evaluation`
- Stage order: 4
- Task: `T_P061_01` — accurate property prediction in both molecules and crystals

## Goal

Quantitatively assess prediction accuracy of MEGNet models versus prior models (SchNet, CGCNN, MPNN)

## Input

- trained MEGNet models
- test sets

## Output

- mean absolute errors (MAEs) for 13 molecular properties
- MAEs for formation energy, band gap, bulk/shear moduli, classification accuracy

## Datasets used

- QM9 — test: Evaluation of MEGNet model performance against benchmarks for 13 molecular properties
- Materials Project — test: Evaluation of MEGNet model performance against benchmarks for formation energy, band gap, bulk/shear moduli, and metal/nonmetal classification
- MP-crystals-2018.6.1 band gap subset — test: Evaluation of MEGNet model performance for band gap regression
- MP-crystals-2018.6.1 elasticity subset — test: Evaluation of MEGNet model performance for elastic moduli prediction
