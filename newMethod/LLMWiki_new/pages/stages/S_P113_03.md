# Stage: X-ray diffraction analysis of as-milled and annealed powders

- Stage ID: `S_P113_03`
- Stage type: `model_evaluation`
- Stage order: 3
- Task: `T_P113_01` — Solid Solution in BaS–La2S3 Ceramics Produced by Mechanosynthesis and Their Potential for Rare-Earth Doping

## Goal

Confirm phase purity, identify solid solution formation, detect impurity phases, and quantify lattice parameter evolution.

## Input

- as-milled powders
- annealed powders (823 K, 48 h; 870 K, 48 h; 1070 K, 72 h)

## Output

- XRD patterns
- lattice parameters extracted via GSAS-II/Le Bail refinement
- phase identification (e.g., single-phase vs. two-phase domains)

## Datasets used

- as-milled x BaS–(1−x) La2S3 powders (x = 0, 15, 33, 50, 67) — test: X-ray diffraction analysis to confirm phase purity and identify solid solution formation
- annealed x BaS–(1−x) La2S3 powders (x = 0, 15, 33, 50) — test: X-ray diffraction analysis to extract lattice parameters and validate Vegard’s law via Le Bail refinement

## Evidence

- P113, PDF page 2, Experimental Procedures: "Powder x-ray diffraction patterns were collected on a PANalytical X’Pert Pro diffractometer... The XRD pattern of as-milled powders from the binary system x BaS—( 1 − x ) La2 S3 ( x = 15, 33, 50, 67) are shown in Figure 1... A single phase is observed in the x = 0–50 region of the phase diagram therefore suggesting a solid solution in this compositional range."
