train generator and discriminator using adversarial learning with physics-based constraints

## Input

- MIO training set
- random noise Z
- element properties E
- space group sgp
- affine matrix O
- physics-guided loss terms (atom distance, symmetry-compliant base/full coordinates)

## Output

- trained PGCGM generator f*θ(Z, E, sgp) producing (B0_fake, B1_fake, B2_fake, P*_fake)
