# Stage: microstructural characterization

- Stage ID: `S_P090_05`
- Stage type: `model_evaluation`
- Stage order: 5
- Task: `T_P090_01` — optimizing densification and mechanical performance of ZrB2–SiC ceramics via spark plasma sintering

## Goal

Characterize microstructure including grain size, porosity, and phase composition to link processing to structure.

## Input

- polished and thermally etched cross-sections
- XRD samples

## Output

- grain size (ZrB2 and SiC)
- surface porosity (%)
- phase identification (ZrB2, SiC, ZrO2, etc.)

## Datasets used

- None stated

## Evidence

- P090, PDF page 4, Microstructural Characterization: "Grain size measurements were performed on high-contrast SEM micrographs of the thermally etched surfaces. For statistical reliability, at least 200 grains per sample were analyzed using the linear intercept method (ASTM E112 [ 9 ]). To accurately highlight and quantify porosity, a systematic image processing approach was employed using ImageJ software [ 10 ]."
- P090, PDF page 4, Microstructural Characterization: "To support the optical observations, X-ray diffraction (XRD) analysis was performed using a Bruker D8 Advance diffractometer with Cu-K α radiation ( λ = 1.5406 Å) operated at 40 kV and 40 mA."
