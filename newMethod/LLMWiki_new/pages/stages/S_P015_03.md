# Stage: generation of extrapolative episodes

- Stage ID: `S_P015_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P015_01` — extrapolative prediction of material properties

## Goal

To construct training episodes where test instances (x, y) lie outside the support set S’s domain, enabling extrapolative learning.

## Input

- dataset D
- domain partitioning rules (e.g., polymer classes, cation/anion combinations)

## Output

- episodes (xi, yi, Si) with extrapolative relationships

## Datasets used

- RadonPy polymer dataset — candidate_pool: Generation of extrapolative episodes where test instances lie outside training domain (e.g., left-out polymer class)
- HOIP dataset — candidate_pool: Generation of extrapolative episodes where test instances lie outside training domain (e.g., perovskites containing Ge+F or Pb+I excluded from training)

## Evidence

- P015, PDF page 2, Results: "Numerous episodes were generated from a given dataset D, each comprising a training set S and test set Q containing instances outside the training domain S."
- P015, PDF page 2, Results: "For instance, (xi, yi) represents the physical property yi of a cellulose derivative xi, whereas Si represents a dataset from other polymer classes, such as conventional plastic resins. Alternatively, (xi, yi) can correspond to a compound containing element species that do not exist in the training compounds comprising Si."
