# Stage: Benchmarking OC25 models against AIMD references

- Stage ID: `S_P062_03`
- Stage type: `model_evaluation`
- Stage order: 3
- Task: `T_P062_01` — CO dimerization on copper surfaces

## Goal

Validate OC25-trained models against literature AIMD benchmarks for interfacial structure (e.g., oxygen density profiles) and reaction energetics (e.g., CO dimerization free-energy profiles).

## Input

- AIMD reference data for Rh(111)/water interface
- AIMD reference data for CO dimerization on 3×4 Cu(100)/water

## Output

- quantitative agreement in oxygen density profiles
- consistent reduction in dimerization barrier with increasing negative surface charge

## Datasets used

- Domínguez-Flores et al. AIMD reference for Rh(111)/water interface — benchmark: Validate OC25-trained models against literature AIMD benchmarks for interfacial structure (e.g., oxygen density profiles).
- Kristoffersen and Chan AIMD reference for CO dimerization on 3×4 Cu(100)/water — benchmark: Validate OC25-trained models against literature AIMD benchmarks for reaction energetics (e.g., CO dimerization free-energy profiles).
