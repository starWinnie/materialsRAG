# Stage: Train CrystalTransformer to generate ct-UAEs

- Stage ID: `S_P006_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P006_01` — Generate universal atomic embeddings (UAEs) for crystal property prediction

## Goal

Train the CrystalTransformer model on large crystal databases to learn universal atomic embeddings (ct-UAEs) for target properties.

## Input

- preprocessed crystal data
- target properties (formation energy, bandgap, total energy, total magnetization)

## Output

- pre-trained CrystalTransformer model
- ct-UAE tensors

## Datasets used

- Materials Project (2023.6.23) — training: Training the CrystalTransformer model on formation energy and bandgap prediction tasks
