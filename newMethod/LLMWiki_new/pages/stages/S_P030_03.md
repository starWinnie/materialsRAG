# Stage: end-to-end training of equivariant neural network with fine-tuning for scaling factors

- Stage ID: `S_P030_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P030_01` — charge density prediction

## Goal

Train the eSCN-based model to predict orbital coefficients and exponent scaling factors, first with fixed exponents (pretraining), then with learnable scaling factors (fine-tuning).

## Input

- atomic types A
- coordinates R of real and virtual nodes
- ground-truth charge density ρ(r)

## Output

- trained SCDP model with learned coefficients ci,j,m and scaling factors si,j

## Datasets used

- None stated

## Evidence

- P030, PDF page 6, 3.2 Prediction Model: "We train the model end-to-end with a mean-absolute error loss L over the charge density: L = Er∈Data [|ρ(r) −ˆρ(r)|]."
- P030, PDF page 7, 3.2 Prediction Model: "The scaling factors at the exponents lead to significant training instability when the network is trained from scratch. Therefore, we use a fine-tuning approach, where we first pre-train the model with fixed basis set exponents [...] and then fine-tune the prediction model with a small learning rate with the learning for scaling factors enabled."
