# Stage: mechanical properties testing

- Stage ID: `S_P090_06`
- Stage type: `model_evaluation`
- Stage order: 6
- Task: `T_P090_01` — optimizing densification and mechanical performance of ZrB2–SiC ceramics via spark plasma sintering

## Goal

Measure mechanical performance metrics (hardness, flexural strength, fracture toughness) to evaluate functional outcomes of sintering optimization.

## Input

- mirror-polished samples
- flexural bars
- Vickers indented samples

## Output

- Vickers hardness (HV) in GPa
- flexural strength (σf) in MPa
- fracture toughness (KIC) in MPa m1/2

## Datasets used

- None stated

## Evidence

- P090, PDF page 4, Mechanical Properties Testing: "The Vickers hardness ( HV ) of each sintered sample was measured using a DuraScan 20 microhardness tester (Struers) under a 1 kgf (9.81 N) load with a 15-s dwell time, in accordance with ASTM C1327-08 [ 13 ]."
- P090, PDF page 4, Mechanical Properties Testing: "σf was determined using a four-point bending test according to ASTM C1161-13 [ 14 ] standards."
- P090, PDF page 4, Mechanical Properties Testing: "KIC was estimated using the indentation fracture method with a 5 kgf (49.05 N) load and 15-s dwell time."
