# Stage: preparation of creep-rupture data for analysis

- Stage ID: `S_P086_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P086_01` — creep-limited lifetime prediction

## Goal

To prepare the raw experimental data for parametric modeling, including normalization of stress and interpolation of missing ultimate tensile strength values.

## Input

- raw creep-rupture data
- ultimate tensile strength values

## Output

- normalized stress data (σa/σ_T_S)
- interpolated UTS values

## Datasets used

- None stated

## Evidence

- P086, PDF page 8, Analytical Results: "First, the experimental applied stresses were normalized using the ultimate tensile strength values presented in Table III. The measured values represent averages from uniaxial tension tests of specimens from heats CLH4663, BLT2820, and Hv1220PS. Values at temperatures where there were no test data were determined by linear interpolation."
