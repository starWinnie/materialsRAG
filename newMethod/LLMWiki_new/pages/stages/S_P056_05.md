- Stage ID: `S_P056_05`
- Stage type: `model_evaluation`
- Stage order: 5
- Task: `T_P056_01` — AI-based analysis of materials-science data

## Goal

Evaluate model outputs via interactive, high-fidelity visualization (e.g., t-SNE embedding, property maps) and structural inspection.

## Input

- clustering results
- SISSO descriptor components (D1, D2)
- crystal structure data

## Output

- interactive 2D map with color-coded clusters or classifications
- hover/click-enabled tooltips and structure viewers

## Datasets used

- NOMAD tetradymite subset (152 alloyed tetradymites, Z2 calculated) — experimental_validation: Used for interactive visualization and structural inspection via Visualizer (hover/click crystal structure display).
