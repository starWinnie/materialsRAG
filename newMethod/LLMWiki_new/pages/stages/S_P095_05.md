# Stage: Fitting stress−strain data to swelling-modified eight-chain model

- Stage ID: `S_P095_05`
- Stage type: `model_evaluation`

## Goal

To quantify differences in strain stiffening behavior by extracting the fitted degree of polymerization (n) as a proxy for onset of strain stiffening.

## Input

- swelling-corrected stress−strain curves of double networks

## Output

- fitted n values
- fitted NkT values

- None stated
