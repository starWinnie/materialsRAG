# Stage: Ultrasonic measurements

- Stage ID: `S_P075_04`
- Stage type: `candidate_generation`

- Task: `T_P075_01` — Measuring the onset of sintering using laser ultrasonics

## Goal

Generate and detect Rayleigh surface waves on sintered pellets using laser ultrasonics to measure local Young’s modulus via wave speed

## Input

- same pellets characterized by impulse excitation
- laser ultrasonic system (Nd-YAG pulsed laser + fiber detection laser)

## Output

- measured Rayleigh wave speed (cR = d/t)
- time-of-flight (ToF) data
- voltage signals proportional to out-of-plane displacement

## Datasets used

- None stated

## Evidence

- P075, PDF page 4, 2.4 Ultrasonic measurements: "The same pellets that were characterized using the impulse excitation method were then placed into the ultrasonic laser system that is schematically illustrated in Figure 1."
- P075, PDF page 4, 2.4 Ultrasonic measurements: "The laser ultrasonic system (AIR-1550-TWM, Intelligent Optical Systems), shown in Figure 1A, consisted of two lasers; a high-energy, pulsed laser that was used to generate a short-duration, high-amplitude elastic wave traveling along the surface of the specimen surface and a continuous wave laser that was used to detect the ToF of the propagating wave, with the propagation paths shown in Figure 1B."
- P075, PDF page 4, 2.4 Ultrasonic measurements: "The Rayleigh wave speed from this measurement was estimated by dividing the distance between the generation and detection laser, d, by the time of the first arrival peak, t: cR = d/t."
