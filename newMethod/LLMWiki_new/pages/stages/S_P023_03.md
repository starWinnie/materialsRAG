# Stage: pre-training via crystal structure reconstruction

- Stage ID: `S_P023_03`
- Stage type: `model_training`
- Stage order: 3
- Task: `T_P023_01` — crystal property prediction

## Goal

Learn the latent marginal distribution of crystal structures p(F, L | A) using a joint denoising diffusion model on lattice L and fractional coordinates F given atom composition A

## Input

- unlabeled crystal structures (A, F0, L0)

## Output

- pre-trained diffusion model ϕθ

## Datasets used

- None stated

## Evidence

- P023, PDF page 3, Methodology: "In the pre-training phase, we perform the task of crystal structure reconstruction to model the distribution p(F, L | A) based on the diffusion model from a large amount of unlabeled data."
- P023, PDF page 2, Introduction: "In the pre-training phase, CrysDiff tries to reconstruct the original crystal structures via a joint denoising diffusion model given the atom compositions only, and thus is self-supervised without annotations of target properties."
