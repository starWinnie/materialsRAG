# Stage: Data cleaning and expansion of material formulas

- Stage ID: `S_P044_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P044_01` — Precursor recommendation for inorganic synthesis

## Goal

Standardize variable-containing material strings (e.g., Ba1−x Srx TiO3) by substituting variables with values from text to ensure one composition per reaction.

## Input

- 33,343 synthesis recipes with variable-containing formulas

## Output

- 49,924 expanded reactions
- 28,598 target materials

## Datasets used

- Text-mined dataset of inorganic materials synthesis recipes — source: Input for data cleaning and expansion of material formulas

## Evidence

- P044, PDF page 28, Data preparation: "Because some material strings (e.g., Ba1−x Srx TiO3) extracted from the literature contain variables corresponding to different amounts of elements, we substituted these variables with their values from the text to ensure that a material in any reaction only corresponds to one composition, resulting in 49,924 expanded reactions and 28,598 target materials."
