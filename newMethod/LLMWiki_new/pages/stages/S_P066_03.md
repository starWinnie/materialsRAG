# Stage: Bayesian optimization over 16.2 million candidates

- Stage ID: `S_P066_03`
- Stage type: `candidate_generation`
- Stage order: 3
- Task: `T_P066_01` — AI-driven design of multiprincipal element alloys for optimal water splitting

## Goal

Iteratively propose new candidate compositions for synthesis and testing based on the GPR model and entropy-informed acquisition function.

## Input

- GPR model trained on DoE data
- configuration entropy (Sconfig)
- uncertainty (σ(x))
- hyperparameter λ
- 16.2 million candidate compositions

## Output

- five new candidate compositions per iteration (e.g., Fe12Co28Ni33Mo17Pd5Pt5 identified as final optimal)

## Datasets used

- None stated
