# Stage: screening of LMP and Wilshire models for long-term extrapolation capability using short-time data

- Stage ID: `S_P086_05`
- Stage type: `candidate_screening`
- Stage order: 5
- Task: `T_P086_01` — creep-limited lifetime prediction

## Goal

To compare the ability of each model to extrapolate reliably from data with t_f < 5,000 h to predict lifetimes up to ~70,000 h, identifying issues like 'turnback'.

## Input

- fitted LMP model
- fitted Wilshire model
- short-time subset (t_f < 5,000 h) data

## Output

- R2 for short-time fits
- identification of turnback in LMP
- comparison of predictive accuracy for long-term extrapolation
