# Stage: constructing atom-probe graphs

- Stage ID: `S_P025_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P025_01` — electron density prediction

## Goal

Build graphs connecting atoms and probe points for neural network input

## Input

- atomic positions
- probe point locations
- cutoff distance (4 Å)

## Output

- graph with atoms and probe points as vertices
- edges formed via proximity

## Datasets used

- None stated

Edges connecting atoms are unidirectional and edges connecting atoms and probe points are directed pointing from atoms to probe points."
