# Stage: construction of atomic and virtual node representations

- Stage ID: `S_P030_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P030_01` — charge density prediction

## Goal

Transform raw atomic configurations into structured inputs including real atoms and SE(3)-equivariant virtual nodes placed at bond midpoints.

## Input

- atomic coordinates R
- atomic types A

## Output

- extended node set with real and virtual nodes
- bond-midpoint-based virtual coordinates

## Datasets used

- None stated

## Evidence

- P030, PDF page 4, 3.1 Charge Density Representation: "Due to the critical importance of chemical bonds in defining the overall electronic structure, we insert virtual nodes into the midpoint of all chemical bonds for a given molecule (illustrated in Figure 2 (a)). With this method, the coordinates to insert the virtual nodes are SE(3)-equivariant with regard to the input atom coordinates."
- P030, PDF page 15, Appendix: "For the molecules in the MD dataset, we use bond centers as coordinates for virtual nodes. For the materials in the Cubic dataset, we iteratively insert virtual nodes up to the number of atoms in the unit cell using an algorithm based on Voronoi diagrams [55]."
