# Stage: Supervised training of neural network regressor

- Stage ID: `S_P043_04`
- Stage type: `model_training`
- Stage order: 4
- Task: `T_P043_01` — ML-based correction of DFT formation enthalpy errors for improved phase stability prediction

## Goal

Train a multi-layer perceptron (MLP) regressor to predict Hcorr from the engineered feature set, using cross-validation and regularization to prevent overfitting.

## Input

- feature vector X
- Hcorr labels

## Output

- trained MLP model with optimized parameters θ

## Datasets used

- Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems — training: Train neural network to predict Hcorr using experimental ground truth
- DFT-calculated formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems — source: Provide DFT-calculated formation enthalpies (HDFT) to compute Hcorr labels and later generate Hpred = HDFT − Hcorr
