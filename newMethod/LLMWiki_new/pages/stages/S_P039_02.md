# Stage: training the foundation equivariant neural network potential with polarizable long-range interactions

- Stage ID: `S_P039_02`
- Stage type: `model_training`
- Stage order: 2
- Task: `T_P039_01` — developing a foundation machine learning interatomic potential with polarizable long-range interactions

## Goal

to train an equivariant graph neural network (NequIP) component (E0) and integrate it with a physically motivated polarizable charge equilibration (PQEq) scheme for electrostatics and DFT-D3 for dispersion

## Input

- MPtrj dataset
- PQEq parameters
- DFT-D3 dispersion correction
- NequIP architecture with six equivariant layers

## Output

- trained foundation model with integrated E0, EPQEq, and ED3 components

## Datasets used

- None stated

## Evidence

- P039, PDF page 9, Methods: "For equivariant neural network training, the NequIP12 model was utilized, incorporating six equivariant layers with node features set at 256 × 0e + 256 × 1e. Spherical harmonic basis functions were used to represent interatomic directions... Interatomic distances were described using eight Bessel basis functions, and a cut-off value of 5.0 Å was chosen..."
