# Stage: Ablation studies on (W/U)PDD contribution

- Stage ID: `S_P012_05`
- Stage type: `candidate_screening`
- Stage order: 5
- Task: `T_P012_01` — Crystal material property prediction

## Goal

Isolate and quantify the impact of WPDD/UPDD integration on model performance

## Input

- models with/without PDD message passing blocks
- models with/without (W/U)PDD information

## Output

- performance deltas (e.g., 17.4% improvement in Bulk Moduli)

## Datasets used

- Materials Project — benchmark: Isolate and quantify the impact of WPDD/UPDD integration on model performance via ablation studies
- JARVIS-DFT — benchmark: Isolate and quantify the impact of WPDD/UPDD integration on model performance via ablation studies
