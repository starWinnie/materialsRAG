# Stage: selection and curation of experimental input data

- Stage ID: `S_P073_01`
- Stage type: `data_acquisition`
- Stage order: 1
- Task: `T_P073_01` — generation of lignin structures

## Goal

To obtain and curate experimental characterization data on lignin structural features to bootstrap the structure generation workflow.

## Input

- analytical results from previous studies on softwood and hardwood lignin samples
- number average molecular weight (Mn)
- S/G ratio or monomer unit's proportion
- bond proportion

## Output

- curated set of experimental structural characteristics
