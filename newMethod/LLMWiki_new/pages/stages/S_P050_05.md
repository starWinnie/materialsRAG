# Stage: comprehensive evaluation across 9 material property tasks on test set

- Stage ID: `S_P050_05`
- Stage type: `model_evaluation`
- Stage order: 5
- Task: `T_P050_01` — material property prediction and human-AI interaction for materials science

## Goal

To quantitatively assess MatterChat’s performance against baselines (Vicuna, Mistral, SchNet, CHGNet) on classification (accuracy) and numerical (RMSE) property prediction tasks.

## Input

- test set (14290 samples)
- ground truth labels for 9 tasks

## Output

- accuracy scores for 6 classification tasks
- RMSE values for 3 numerical tasks
- comparative results vs. baselines

## Datasets used

- None stated
