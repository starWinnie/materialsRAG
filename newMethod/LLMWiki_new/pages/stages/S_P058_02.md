# Stage: imputation of missing attributes

- Stage ID: `S_P058_02`
- Stage type: `data_preparation`
- Stage order: 2
- Task: `T_P058_01` — graphene layer number classification

## Goal

Fill missing values in the sparse, heterogeneous dataset using statistical methods (KNN, MICE) and prompt-based LLM methods (GUIDE, MAP, CITE, etc.)

## Input

- raw CVD graphene dataset with missing values across nearly all attributes

## Output

- imputed dataset with no missing values

## Datasets used

- CVD graphene synthesis dataset — training: Imputation of missing attributes using statistical and LLM-based methods

- P058, PDF page 4, Imputation of missing attributes: "The first step in imputation is to assess the underlying reasons for missing entries in the collected data."
- P058, PDF page 4, Imputation of missing attributes: "Missing data for each attribute is imputed using three statistical methods (K nearest neighbors with uniform neighbor contribution (KNN-U), KNN with distance weights (KNN-D), and multivariate imputation via chained equations (MICE)), and six prompt-based LLM methods."
