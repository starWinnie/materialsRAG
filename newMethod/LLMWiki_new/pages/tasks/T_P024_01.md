# Task: materials property prediction

- Task ID: `T_P024_01`
- Canonical name: `materials_property_prediction`
- Paper: `P024`

## Objective

to accurately predict materials properties prior to synthesis to prioritize resources for simulations and experiments and accelerate materials discovery

## Material scope

- 3D materials
- 2D materials
- inorganic materials
- organic materials
- computational materials
- experimental materials

## Target properties

- formation energy
- band gap
- dielectric constant
- piezoelectric tensor
- exfoliation energy
- elastic tensor components
- Poisson ratio
- shear modulus
- bulk modulus
- electron effective mass
- optical properties
- magnetic properties
- vibrational properties
- electronic properties

## Constraints

- small dataset size
- cross-property transfer
- cross-materials class transfer
- extrapolation capability

## Input requirements

- crystal structure files (e.g., POSCAR)
- atomic positions
- lattice geometry
- composition

## Output goal

- predicted numerical value of a target materials property

## Research stages

1. acquisition of diverse materials datasets (`data_acquisition`)
2. preprocessing of structure files into graph representations (`data_preparation`)
3. training of source model (ALIGNN) on large dataset (`model_training`)
4. generation of transfer learning models via fine-tuning and feature extraction (`candidate_generation`)
5. evaluation of predictive performance using MAE (`model_evaluation`)
