# Task: predicting dielectric constants (ε) for polymers

- Task ID: `T_P074_01`
- Canonical name: `predict_dielectric_constant_of_polymers`
- Paper: `P074`

## Objective

To develop a reliable, mechanistically explainable predictive QSPR model for dielectric constant values of polymers based on molecular structure.

## Material scope

- polymers

## Target properties

- dielectric constant
- permittivity

## Constraints

- model must be mechanistically explainable
- model must be robust and validated externally

## Input requirements

- chemical structure of polymer monomer units

## Output goal

- numerical prediction of dielectric constant (ε)

## Research stages

1. collecting experimental dielectric constant data for polymers (`data_acquisition`)
2. generating and filtering molecular descriptors from monomer structures (`data_preparation`)
3. training QSPR models using GA-MLRA (`model_training`)
4. validating models using internal and external metrics (`model_evaluation`)

## Dataset uses

- collecting experimental dielectric constant data for polymers: Bicerano's polymer dielectric constant dataset (source, DU_P074_001)
- collecting experimental dielectric constant data for polymers: Ku and Liepins' polymer dielectric constant dataset (source, DU_P074_002)

## Evidence

- P074, PDF page 3, MATERIALS AND METHODS: "The purpose of this study was to develop a reliable predictive QSPR model that could effectively be used to predict dielectric constant values with mechanistically explainable descriptors for further design applications."
