# Task: benchmarking of materials design methods

- Task ID: `T_P028_01`
- Canonical name: `materials_design_method_benchmarking`
- Paper: `P028`

## Objective

to provide a comprehensive, reproducible, transparent, and unbiased framework for benchmarking materials design methods across multiple categories and data modalities

## Material scope

- materials of technological interest

## Target properties

- formation energy
- bandgap
- bulk modulus
- forces
- exfoliation energy
- CO2 adsorption
- elastic properties
- thermal properties
- optical properties
- electronic properties
- phonon spectra
- dielectric functions
- solar cell efficiencies
- superconducting transition temperatures
- strain-stress
- magnetometry
- vibroscopy
- XRD
- STEM
- STM

## Constraints

- must be based on well-characterized/well-known samples/tasks with digital object identifier/peer-reviewed article links
- must include run script to exactly reproduce results
- must include metadata file with team name, contact information, computational timing and software/hardware used

## Input requirements

- reference benchmark data (e.g., experimental data, DFT data, analytical results)
- user-submitted method outputs (e.g., predictions, measurements, simulations)

## Output goal

- performance rankings across methods for each benchmark
- reproducible, comparable, and interpretable evaluation metrics (e.g., MAE, accuracy, ROUGE)

## Research stages

1. populate reference dataset (`data_acquisition`)
2. apply method, train models, or run experiments (`candidate_generation`)
3. prepare contribution files (`data_preparation`)
4. compute performance metrics (`model_evaluation`)
5. local verification and automated testing (`computational_validation`)
6. administrator verification and benchmark curation (`experimental_validation`)
