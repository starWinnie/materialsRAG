# Task: benchmarking machine learning force fields (MLFFs)

- Task ID: `T_P059_01`
- Canonical name: `mlff_benchmarking`
- Paper: `P059`

## Objective

to evaluate universal machine learning force fields (MLFFs) for complex material properties beyond total energy, including elastic constants, phonon spectra, defect formation energies, surface energies, interfacial properties, and amorphous phase properties

## Material scope

- metals
- semiconductors
- insulators

## Target properties

- elastic constants
- phonon spectra
- defect formation energies
- surface energies
- interfacial properties
- amorphous phase properties
- forces
- lattice parameters
- bulk modulus
- work of adhesion
- radial distribution function

## Constraints

- accuracy with respect to DFT
- convergence
- computational cost

## Input requirements

- pretrained MLFF models
- initial structures from JARVIS-DFT database
- DFT reference data (e.g., JARVIS-DFT, InterMat, AIMD, experimental data)

## Output goal

- mean absolute error (MAE) for each property
- convergence rates
- computational timing
- parity plots
- JARVIS-Leaderboard entries

## Research stages

1. acquiring initial structures and reference data (`data_acquisition`)
2. generating supercell structures for surfaces and defects (`data_preparation`)
3. selecting and loading pretrained MLFF models (`candidate_generation`)
4. running structural relaxation and convergence analysis (`candidate_screening`)
5. computing material properties and error metrics (`computational_validation`)
6. aggregating and reporting benchmarking results (`model_evaluation`)

## Dataset uses

- acquiring initial structures and reference data: JARVIS-DFT (source, DU_P059_001)
- acquiring initial structures and reference data: InterMat (source, DU_P059_002)
- acquiring initial structures and reference data: MLEARN (source, DU_P059_003)
- generating supercell structures for surfaces and defects: CHIPS-FF 104-material test set (candidate_pool, DU_P059_006)
- computing material properties and error metrics: CHIPS-FF 104-material test set (benchmark, DU_P059_007)
- computing material properties and error metrics: CHIPS-FF 84-material phonon subset (benchmark, DU_P059_008)
- computing material properties and error metrics: CHIPS-FF 85-material surface subset (benchmark, DU_P059_009)
- computing material properties and error metrics: CHIPS-FF 48-material defect subset (benchmark, DU_P059_010)
