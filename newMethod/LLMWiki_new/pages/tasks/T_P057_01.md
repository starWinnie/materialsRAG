# Task: crystal property prediction

- Task ID: `T_P057_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P057`

## Objective

predict downstream target property value y given any material M = (A, X, L)

## Material scope

- crystal materials
- crystal structures

## Target properties

- formation energy
- bandgap
- total energy
- ehull
- bulk modulus
- shear modulus
- spillage
- SLME

## Constraints

- data scarcity
- low-data regimes
- DFT error bias

## Input requirements

- 3D crystal structure M = (A, X, L)

## Output goal

- predicted property value y

## Research stages

1. pretraining data acquisition (`data_acquisition`)
2. crystal structure representation (`data_preparation`)
3. VAE pretraining (`model_training`)
4. latent diffusion model training (`model_training`)
5. fine-tuning for property prediction (`model_training`)
6. downstream property prediction evaluation (`model_evaluation`)

## Dataset uses

- pretraining data acquisition: GNoME (pretraining, DU_P057_001)
- fine-tuning for property prediction: JARVIS-DFT (training, DU_P057_002)
- fine-tuning for property prediction: Materials Project (training, DU_P057_003)
- downstream property prediction evaluation: JARVIS-DFT (test, DU_P057_004)
- downstream property prediction evaluation: Materials Project (test, DU_P057_005)
- downstream property prediction evaluation: OQMD-EXP (experimental_validation, DU_P057_006)
