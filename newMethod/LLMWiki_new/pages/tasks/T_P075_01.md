# Task: Measuring the onset of sintering using laser ultrasonics

- Task ID: `T_P075_01`
- Canonical name: `measuring_onset_of_sintering`
- Paper: `P075`

## Objective

Determine the onset temperature and early-stage sintering state of ceramic powder compacts

## Material scope

- alumina

## Target properties

- onset temperature of sintering
- early-stage sintering state
- interparticle neck size
- Young's modulus
- Rayleigh wave speed

## Constraints

- noncontact
- near-surface measurement
- localized to selected regions
- suitable for in-line monitoring of additive manufacturing

## Input requirements

- partially sintered ceramic samples
- laser ultrasonic system (pulsed generation laser + continuous detection laser)

## Output goal

- detection of sintering onset at temperatures between 520°C and 650°C
- quantification of early-stage sintering via Rayleigh wave speed and Young's modulus

## Research stages

1. Sample preparation (`data_acquisition`)
2. Impulse excitation measurements (`model_evaluation`)
3. Predicted Rayleigh velocities (`computational_validation`)
4. Ultrasonic measurements (`candidate_generation`)
5. SEM analysis (`experimental_validation`)
6. Impulse excitation versus ultrasonic measurements (`model_evaluation`)

- None stated

- P075, PDF page 1, Abstract: "We demonstrate the ability to measure very small changes in interparticle neck size by measuring Rayleigh wave speeds."
