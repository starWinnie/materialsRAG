# Task: Construct materials maps reflecting the relation between the structural complexity and the experimental thermoelectric properties (zT values)

- Task ID: `T_P055_01`
- Canonical name: `construct_materials_maps_for_structural_complexity_and_zt_relationship`
- Paper: `P055`

## Objective

To construct interpretable materials maps that visualize the relationship between material structural complexity and experimental thermoelectric properties (zT values), supporting experimental researchers in synthesizing new materials.

## Material scope

- thermoelectric materials containing Sb, Te, Sn, Se, Bi, S

## Target properties

- structural complexity
- predicted experimental zT values

## Constraints

- maps must reflect real-world variability
- must support experimentalists in synthesizing feasible materials
- input limited to structural information

## Input requirements

- materials structures (atomic positions, lattice parameters)
- predicted experimental zT values

## Output goal

- 2D materials map visualizing structural relationships and zT trends

## Research stages

1. Use dataset extracted in previous study composed of predicted experimental zT values with corresponding materials structures (`data_acquisition`)
2. Preprocessing experimental data, training a machine learning model, and applying the trained model to predict experimental data for the compositions registered in the computational data (`data_preparation`)
3. Train graph-based machine learning model (MPNN) using material structures as input and predicted zT values as output (`model_training`)
4. Construct materials maps using t-SNE architecture with data extracted from the first dense layer (`candidate_generation`)
5. Evaluate structural organization of maps using distribution analysis of nearest neighbor distances (NND) via Kernel Density Estimation (KDE) (`model_evaluation`)
6. Interpret maps by making plots colored with various properties stored in a computational database (`candidate_screening`)

## Dataset uses

- Preprocessing experimental data, training a machine learning model, and applying the trained model to predict experimental data for the compositions registered in the computational data: Materials Project (candidate_pool, DU_P055_002)
