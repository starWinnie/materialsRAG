# Task: creation of an open-access database and analysis tool for perovskite solar cells

- Task ID: `T_P042_01`
- Canonical name: `create_open_access_perovskite_solar_cell_database_and_analysis_tool`
- Paper: `P042`

## Objective

to expand the normal research cycle by collecting all perovskite solar cell data, both past and future, in one place; to make all historical data accessible and provide means to upload new experimental data; to implement interactive graphical data visualization tools that enable simple and interactive exploration, analysis and filtering

## Material scope

- metal-halide perovskites
- perovskite solar cells

## Target properties

- power conversion efficiency (PCE)
- open-circuit voltage (Voc)
- bandgap (Eg)
- stability (T80)
- scalability (cell area)
- device stack composition

## Constraints

- FAIR data principles (findable, accessible, interoperable, reusable)
- consistently formatted data
- peer-reviewed literature only
- up to end of February 2020

## Input requirements

- peer-reviewed papers on metal-halide perovskite solar cells
- data extraction protocol with 95 attributes
- metadata ontology
- interactive web-based tools development

## Output goal

- open-access database containing >42,400 photovoltaic devices
- free interactive web-based tools for exploration, analysis, filtering and visualization
- open-source code base
- procedures and protocols for FAIR-compliant data dissemination

## Research stages

1. manual literature search and data collection (`data_acquisition`)
2. manual data extraction and formatting (`data_preparation`)
3. development of interactive analysis and visualization tools (`candidate_generation`)
4. demonstration of database utility through example analyses (`model_evaluation`)
5. establishment of FAIR-compliant protocols and infrastructure (`other`)

## Dataset uses

- manual literature search and data collection: Perovskite Database (source, DU_P042_001)
- manual data extraction and formatting: Perovskite Database (training, DU_P042_002)
- development of interactive analysis and visualization tools: Perovskite Database (computational_validation, DU_P042_003)
- demonstration of database utility through example analyses: Perovskite Database (benchmark, DU_P042_004)
- establishment of FAIR-compliant protocols and infrastructure: Perovskite Database (computational_validation, DU_P042_005)

## Evidence

- P042, PDF page 1: "Here we extract all the meaningful device data from peer-reviewed papers on metal-halide perovskite solar cells published so far and make them available in a database. We collect data from over 42,400 photovoltaic devices with up to 100 parameters per device. We then develop open-source and accessible procedures to analyse the data, providing examples of insights that can be gleaned from the analysis of a large dataset. The database, graphics and analysis tools are made available to the community and will continue to evolve as an open-source initiative."
