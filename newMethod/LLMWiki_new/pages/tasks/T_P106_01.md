# Task: Optimizing Cementitious Glasses for the Disposal of Radioactive Waste

- Task ID: `T_P106_01`
- Canonical name: `optimizing_cementitious_glasses_for_radioactive_waste_disposal`
- Paper: `P106`

## Objective

Create glasses that would react with aqueous simulated low-level radioactive waste (LLW) solutions upon contact and form solid phases over time.

## Material scope

- calcium-magnesium aluminosilicate (CMAS) glasses

## Target properties

- cementitious reactivity
- glass stability
- processability
- formation of solid phases upon contact with LLW
- no free-standing liquid

## Constraints

- compositional ranges bounded by OPC, BFS, and class F fly ash
- quaternary basicity (λ) ranges: 0.85 < λ < 0.95, 0.95 < λ < 1.10, 1.10 < λ < 1.25, 1.25 < λ < 1.40
- water-to-solids ratio (W/S) between 0.4 and 0.64

## Input requirements

- chemical and mineralogical properties of OPC, BFS, and class F fly ash
- simulated LLW solution

## Output goal

- ideal glass composition (IGC) optimized for both processing performance and cementitious reactivity

## Research stages

1. Design of Ideal Glass Compositions using DOE (`data_acquisition`)
2. Down-selection and Uniform Spacing of Glass Compositions (`candidate_generation`)
3. Raman Spectroscopy-Based Structural Quantification (`model_training`)
4. Correlation of Glass Structure with Cementitious Reactivity (`model_evaluation`)
5. Isothermal Calorimetry and Post-Reaction XRD Analysis (`experimental_validation`)
