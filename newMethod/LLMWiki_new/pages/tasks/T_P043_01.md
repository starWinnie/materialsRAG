# Task: ML-based correction of DFT formation enthalpy errors for improved phase stability prediction

- Task ID: `T_P043_01`
- Canonical name: `dft_formation_enthalpy_error_correction`
- Paper: `P043`

## Objective

To systematically correct intrinsic energy resolution errors in DFT-calculated formation enthalpies to improve the reliability of first-principles predictions of phase stability, particularly in ternary systems.

## Material scope

- binary alloys
- ternary alloys
- intermetallic compounds
- Al–Ni–Pd system
- Al–Ni–Ti system

## Target properties

- formation enthalpy (Hf)
- phase stability

## Constraints

- ambient-temperature (0 K) conditions
- metallic systems
- limited training dataset
- physically meaningful feature set

## Input requirements

- DFT-calculated formation enthalpies (HDFT)
- experimental formation enthalpies (Hexpt)
- elemental concentrations
- atomic numbers
- pairwise and triplet interaction terms

## Output goal

- corrected formation enthalpy (Hpred = HDFT − Hcorr)
- reduced RMSE in formation enthalpy prediction (from ~41 meV/atom to ~10 meV/atom)

## Research stages

1. Collection of experimental formation enthalpy data (`data_acquisition`)
2. Feature engineering and normalization (`data_preparation`)
3. Calculation of DFT-experiment discrepancy (Hcorr) (`label_generation`)
4. Supervised training of neural network regressor (`model_training`)
5. Performance evaluation using cross-validation (`model_evaluation`)
6. Comparison of linear vs. neural network correction models (`candidate_screening`)
7. Application of ML-corrected enthalpies to phase stability assessment (`computational_validation`)

## Dataset uses

- Collection of experimental formation enthalpy data: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (label_source, DU_P043_001)
- Calculation of DFT-experiment discrepancy (Hcorr): Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (label_source, DU_P043_002)
- Supervised training of neural network regressor: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (training, DU_P043_003)
- Supervised training of neural network regressor: DFT-calculated formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (source, DU_P043_004)
- Performance evaluation using cross-validation: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (test, DU_P043_005)
- Comparison of linear vs. neural network correction models: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (screening, DU_P043_006)
- Application of ML-corrected enthalpies to phase stability assessment: Experimental formation enthalpy dataset for Al–Ni–Pd and Al–Ni–Ti ternary systems (computational_validation, DU_P043_007)
