# Task: Predicting solid-state material properties

- Task ID: `T_P046_01`
- Canonical name: `predict_solid_state_material_properties`
- Paper: `P046`

## Objective

To improve prediction accuracy of solid-state material properties by explicitly incorporating bond angle information via a line graph neural network architecture.

## Material scope

- crystalline materials
- solid-state materials

## Target properties

- formation energy
- band gap (PBE, OPT, MBJ)
- dielectric constants
- bulk modulus
- shear modulus
- magnetic moment
- piezoelectric coefficients
- Seebeck coefficient
- power factor
- electric field gradient
- exfoliation energy
- topological spin-orbit spillage
- solar-cell efficiency (SLME)
- energy above convex hull
- effective masses
- total energy
- convex hull stability
- metal/non-metal classification
- magnetic/non-magnetic classification

## Constraints

- explicit incorporation of bond angles
- use of both bond distance and angle information
- applicability to periodic crystalline structures
- compatibility with JARVIS-DFT and Materials Project datasets

## Input requirements

- atomistic graph representation with node features (electronegativity, group number, covalent radius, valence electrons, first ionization energy, electron affinity, block, atomic volume)
- edge features (interatomic bond distances via RBF expansion)
- line graph representation with edge features (bond angle cosines via RBF expansion)

## Output goal

- regression predictions of continuous material property values
- classification predictions of binary material labels (e.g., metal/non-metal, stable/unstable)

## Research stages

1. Acquiring JARVIS-DFT and Materials Project datasets (`data_acquisition`)
2. Constructing atomistic and line graphs (`data_preparation`)
3. Using DFT-computed property values as labels (`label_generation`)
4. Training ALIGNN models with MSE and NLL loss (`model_training`)
5. Evaluating model performance using MAE and ROC AUC (`model_evaluation`)
