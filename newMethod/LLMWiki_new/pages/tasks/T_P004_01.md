# Task: ML-guided materials discovery

- Task ID: `T_P004_01`
- Canonical name: `ml_guided_materials_discovery`
- Paper: `P004`

## Objective

To accelerate high-throughput computational materials discovery by using ML models as efficient pre-filters for DFT calculations to identify thermodynamically stable inorganic crystals.

## Material scope

- inorganic crystals

## Target properties

- thermodynamic stability
- distance to convex hull phase diagram

## Constraints

- models must predict convex hull distance from unrelaxed structures only
- avoid circular dependency with DFT relaxation
- prospective benchmarking with realistic covariate shift

## Input requirements

- unrelaxed crystal structures

## Output goal

- classification of thermodynamic stability (on or below convex hull)

## Research stages

1. Acquire training data from Materials Project database (`data_acquisition`)
2. Acquire test data from WBM dataset (`data_acquisition`)
3. Clean and filter WBM test set by protostructure matching (`data_preparation`)
4. Compute convex hull distance labels for WBM structures (`label_generation`)
5. Train ML models on MP data to predict convex hull distance (`model_training`)
6. Evaluate models on WBM test set using classification metrics (`model_evaluation`)
7. Rank candidates by predicted hull distance for discovery campaigns (`candidate_screening`)

## Dataset uses

- Acquire training data from Materials Project database: Materials Project (training, DU_P004_001)
- Acquire test data from WBM dataset: Wang-Botti-Marques dataset (test, DU_P004_002)
- Clean and filter WBM test set by protostructure matching: WBM unique prototype test set (test, DU_P004_003)
- Compute convex hull distance labels for WBM structures: WBM unique prototype test set (label_source, DU_P004_004)
- Train ML models on MP data to predict convex hull distance: Materials Project (training, DU_P004_005)
- Evaluate models on WBM test set using classification metrics: WBM unique prototype test set (test, DU_P004_006)
- Rank candidates by predicted hull distance for discovery campaigns: WBM unique prototype test set (candidate_pool, DU_P004_007)
