# Task: developing a single machine learning architecture that is capable of adapting its weights automatically to enforce invariance to any input space group

- Task ID: `T_P002_01`
- Canonical name: `space_group_invariant_architecture_development`
- Paper: `P002`

## Objective

Develop a single, adaptive neural architecture capable of enforcing exact invariance to any of the 230 crystallographic space groups.

## Material scope

- crystalline solids

## Target properties

- G-invariance (exact invariance under any input space group)

## Constraints

- Must support all 230 space groups in 3D
- Must enable weight sharing across groups
- Must generalize to unseen groups (zero-shot)
- Must be computationally efficient

## Input requirements

- Atomic positions
- Space group identifier (1-230)
- Lattice vectors

## Output goal

- G-invariant representation of crystal structure for material property prediction

## Research stages

1. using data from the Materials Project (`data_acquisition`)
2. constructing synthetic dataset for orbit distance validation (`data_preparation`)
3. pretraining the G-invariant encoding module (`model_training`)
4. training the full CFT architecture (`model_training`)
5. evaluating CFT on material property prediction benchmarks (`model_evaluation`)
6. performing zero-shot generalization evaluation (`model_evaluation`)

## Dataset uses

- using data from the Materials Project: Materials Project (source, DU_P002_001)
- constructing synthetic dataset for orbit distance validation: synthetic orbit distance dataset (training, DU_P002_002)
- pretraining the G-invariant encoding module: synthetic orbit distance dataset (training, DU_P002_003)
- training the full CFT architecture: Materials Project (training, DU_P002_004)
- evaluating CFT on material property prediction benchmarks: Materials Project (test, DU_P002_005)
- performing zero-shot generalization evaluation: held-out inversion-symmetric space groups dataset (screening, DU_P002_006)
