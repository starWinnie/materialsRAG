# Task: Structure-based out-of-distribution (OOD) materials property prediction

- Task ID: `T_P029_01`
- Canonical name: `structure_based_ood_materials_property_prediction`
- Paper: `P029`

## Objective

To objectively evaluate ML model performances in property prediction of out-of-distribution (OOD) materials that are different from the training set

## Material scope

- inorganic materials
- crystalline solids
- perovskites
- dielectric materials
- elastic materials

## Target properties

- refractive index
- shear modulus
- formation energy

## Constraints

- test set comprises no labeled samples
- OOD test sets must deviate significantly from training/validation set in distribution
- evaluation must reflect real-world material discovery where outlier materials are of interest

## Input requirements

- crystal structures
- orbital-field matrix (OFM) features
- property values (y-values)

## Output goal

- predicted property values for OOD materials
- quantified generalization gap (e.g., MAE increase over i.i.d. baseline)

## Research stages

1. Selecting three benchmark datasets from MatBench (`data_acquisition`)
2. Preprocessing crystal structures into OFM feature space and applying t-SNE (`data_preparation`)
3. Generating five types of OOD test sets via clustering and density estimation (`candidate_generation`)
4. Training eight GNN models on each fold using OOD train/val splits (`model_training`)
5. Evaluating model performance using MAE on OOD test sets (`model_evaluation`)
6. Comparing OOD MAEs against MatBench i.i.d. baselines and analyzing latent spaces (`computational_validation`)
