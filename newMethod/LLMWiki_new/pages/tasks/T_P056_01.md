# Task: AI-based analysis of materials-science data

- Task ID: `T_P056_01`
- Canonical name: `ai_based_analysis_of_materials_science_data`
- Paper: `P056`

## Objective

To enable interactive, reproducible, and accessible AI-powered analysis of FAIR materials-science data for knowledge discovery and understanding.

## Material scope

- ternary oxides
- tetradymites (AB−LMN, A,B ∈ {As,Sb,Bi}, L,M,N ∈ {S,Se,Te})

## Target properties

- atomic density
- topological vs trivial insulator classification

## Constraints

- data must be FAIR-compliant
- analysis must be reproducible via shared notebooks
- software must be containerized and versioned

## Input requirements

- NOMAD Archive data accessed via RESTful API
- atomic features (e.g., atomic number, electronegativity, radii)
- primary features and operators for descriptor generation

## Output goal

- clusters of similar materials
- low-dimensional descriptors predicting target properties
- interactive visualizations (e.g., t-SNE maps, property maps)

## Research stages

1. Querying the NOMAD Archive via RESTful API (`data_acquisition`)
2. Enriching retrieved data with atomic features (`data_preparation`)
3. Generating candidate descriptors via SISSO (`candidate_generation`)
4. Training AI models (clustering and SISSO regression) (`model_training`)
5. Visualizing and interpreting AI results (`model_evaluation`)

## Dataset uses

- Querying the NOMAD Archive via RESTful API: NOMAD Archive (source, DU_P056_001)
- Querying the NOMAD Archive via RESTful API: NOMAD ternary oxide subset (VASP/GGA, converged) (training, DU_P056_002)
- Enriching retrieved data with atomic features: NOMAD ternary oxide subset (VASP/GGA, converged) (label_source, DU_P056_003)
- Generating candidate descriptors via SISSO: NOMAD ternary oxide subset (VASP/GGA, converged) (candidate_pool, DU_P056_004)
- Training AI models (clustering and SISSO regression): NOMAD tetradymite subset (152 alloyed tetradymites, Z2 calculated) (training, DU_P056_005)
- Visualizing and interpreting AI results: NOMAD tetradymite subset (152 alloyed tetradymites, Z2 calculated) (experimental_validation, DU_P056_006)
