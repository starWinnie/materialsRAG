# Task: dataset redundancy control for material property prediction

- Task ID: `T_P026_01`
- Canonical name: `dataset_redundancy_control`
- Paper: `P026`

## Objective

Reduce dataset redundancy in materials datasets to enable objective, realistic evaluation of ML model performance—particularly extrapolative (out-of-distribution) capability—by preventing information leakage between training and test sets caused by high similarity among samples.

## Material scope

- inorganic crystalline materials
- perovskites (e.g., SrTiO3)
- Materials Project database entries
- Open Quantum Materials Database (OQMD) entries

## Target properties

- formation energy
- band gap

## Constraints

- must preserve coverage of composition/structure space
- must avoid data bias (e.g., over-selection of near-zero band gap samples)
- thresholds must be tunable per distance metric

## Input requirements

- material compositions or crystal structures
- composition descriptors (e.g., MatScholar, Mendeleev features) or structure descriptors (e.g., XRD, OFM features)

## Output goal

- non-redundant dataset where no pair of samples exceeds a user-defined similarity threshold

## Research stages

1. redundancy reduction using MD-HIT-composition (`data_preparation`)
2. redundancy reduction using MD-HIT-structure (`data_preparation`)
3. download and curate raw materials datasets (`data_acquisition`)
4. evaluate ML model performance on redundant vs. non-redundant datasets (`model_evaluation`)
5. construct OOD test sets via density-based sampling (`candidate_screening`)
