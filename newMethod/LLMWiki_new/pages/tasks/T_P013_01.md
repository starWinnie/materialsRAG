# Task: materials property prediction

- Task ID: `T_P013_01`
- Canonical name: `materials_property_prediction`
- Paper: `P013`

## Objective

accurately predict energy-related properties (e.g., total energy, energy above the convex hull, energy band gap) and data-scarce mechanical properties (e.g., bulk and shear modulus)

## Material scope

- inorganic materials

## Target properties

- total energy
- energy above the convex hull
- energy band gap
- bulk modulus
- shear modulus
- phonon frequency
- refractive index
- Fermi energy

## Constraints

- data scarcity for specific properties
- capturing thermodynamic stability
- capturing global crystal structure and periodicity information

## Input requirements

- material compositions
- crystal structures
- tabulated physical and chemical descriptors

## Output goal

- property predictions for inorganic materials

## Research stages

1. using DFT-calculated solid-state properties from the MP21 database (`data_acquisition`)
2. graph representation of crystal structure using G8, L(G8), and L(G8d) (`data_preparation`)
3. training hybrid CrysCo model with EGAT and transformer architectures (`model_training`)
4. benchmarking CrysCo's performance against state-of-the-art models (`model_evaluation`)
5. applying CrysCo to predict Ef and EHull of novel structures (`candidate_screening`)
6. filling-in elastic data missing from the Materials Project database (`candidate_generation`)

## Dataset uses

- using DFT-calculated solid-state properties from the MP21 database: Materials Project (source, DU_P013_001)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Formation Energy Dataset (benchmark, DU_P013_002)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Band Gap Dataset (benchmark, DU_P013_003)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Phonon Frequency Dataset (benchmark, DU_P013_004)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Dielectric Dataset (benchmark, DU_P013_005)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Shear Modulus Dataset (benchmark, DU_P013_006)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Bulk Modulus Dataset (benchmark, DU_P013_007)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Energy Above Convex Hull Dataset (benchmark, DU_P013_008)
- benchmarking CrysCo's performance against state-of-the-art models: MP21 Fermi Energy Dataset (benchmark, DU_P013_009)
- applying CrysCo to predict Ef and EHull of novel structures: Novel Structures Dataset (screening, DU_P013_010)
- filling-in elastic data missing from the Materials Project database: Materials Project Elastic Data Gap (candidate_pool, DU_P013_011)
