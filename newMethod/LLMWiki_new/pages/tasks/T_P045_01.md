# Task: Constructing a dataset of solution-based inorganic materials synthesis recipes

- Task ID: `T_P045_01`
- Canonical name: `construct_solution_based_synthesis_dataset`
- Paper: `P045`

## Objective

To construct the first large-scale dataset of solution-based inorganic materials synthesis recipes extracted from scientific literature.

## Material scope

- inorganic materials
- solution-based synthesis

## Target properties

- None stated

## Constraints

- must contain precursors and target materials, their quantities, synthesis actions and attributes, and reaction formulas

## Input requirements

- scientific literature (over 4 million papers), HTML/XML full-text articles, metadata

## Output goal

- structured synthesis 'recipes' in JSON format, publicly available dataset

## Research stages

1. Content acquisition (`data_acquisition`)
2. Paragraph classification (`data_preparation`)
3. Synthesis recipe extraction (`candidate_generation`)
4. Building reaction formulas (`candidate_generation`)
5. Dataset generation (`data_preparation`)

## Dataset uses

- Dataset generation: Solution-based Inorganic Materials Synthesis Recipes Dataset (benchmark, DU_P045_005)
