# Task: Dielectric tensor prediction for inorganic materials

- Task ID: `T_P019_01`
- Canonical name: `dielectric_tensor_prediction`
- Paper: `P019`

## Objective

Predict the three types of dielectric tensors, ε∞ij, ε0ij and εij, for inorganic materials across 72 supported elements with the equivariance to the input structure.

## Material scope

- inorganic materials

## Target properties

- dielectric tensor
- electronic dielectric tensor
- ionic dielectric tensor
- total dielectric tensor

## Constraints

- O(3) equivariance
- thermodynamic stability

## Input requirements

- crystal structure
- atomic numbers and positions

## Output goal

- 3 × 3 dielectric tensor

## Research stages

1. Data acquisition from Materials Project (`data_acquisition`)
2. Dataset cleaning and partitioning (`data_preparation`)
3. Training DTNet with pretrained PFP as encoder (`model_training`)
4. Benchmarking DTNet against state-of-the-art algorithms (`model_evaluation`)
5. Preparation of candidate structures for virtual screening (`candidate_generation`)
6. Virtual screening for high-dielectric and highly anisotropic materials (`candidate_screening`)
7. DFPT validation of screened candidates (`computational_validation`)

## Dataset uses

- Data acquisition from Materials Project: Materials Project v2023.11.1 dielectric dataset (source, DU_P019_001)
- Dataset cleaning and partitioning: Refined MP training set (6648 structures) (training, DU_P019_002)
- Benchmarking DTNet against state-of-the-art algorithms: Materials Project v2023.11.1 dielectric dataset (benchmark, DU_P019_003)
- Benchmarking DTNet against state-of-the-art algorithms: Matbench dielectric dataset (benchmark, DU_P019_004)
- Preparation of candidate structures for virtual screening: MP candidate set for virtual screening (14,375 non-metal materials) (candidate_pool, DU_P019_005)
- DFPT validation of screened candidates: MP candidate set for virtual screening (14,375 non-metal materials) (computational_validation, DU_P019_006)
