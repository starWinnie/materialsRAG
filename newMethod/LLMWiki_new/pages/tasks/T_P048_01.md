# Task: predict Li-ion diffusivity in non-crystalline materials

- Task ID: `T_P048_01`
- Canonical name: `predict_li_ion_diffusivity_in_non_crystalline_materials`
- Paper: `P048`

## Objective

To rapidly and accurately predict Li-ion diffusivity in non-crystalline inorganic materials using machine learning models trained on computed data, providing a cost-effective alternative to expensive density functional theory (DFT) calculations.

## Material scope

- non-crystalline inorganic materials
- amorphous materials
- glass
- supercooled liquid
- liquid

## Target properties

- Li-ion diffusivity
- activation energy (Ea) for Li diffusion

## Constraints

- must cover broad chemical space of non-crystalline materials
- must be computationally efficient alternative to DFT
- must capture dynamics of liquids, supercooled liquids, and glasses

## Input requirements

- composition
- temperature
- structural features (e.g., packing fraction, neighbor counts, bond ionicity, cohesive energy)

## Output goal

- predicted Li-ion diffusivity (D_Li)
- predicted activation energy (Ea)

## Research stages

1. generate non-crystalline structure database via AIMD (`data_acquisition`)
2. construct multi-temperature non-crystalline database (`data_preparation`)
3. calculate Li-ion diffusivity and activation energy from AIMD trajectories (`label_generation`)
4. train machine learning models (RF, XGBoost, SISSO) on diffusivity data (`model_training`)
5. evaluate ML model performance using parity plots and error metrics (`model_evaluation`)
6. validate universal ML potentials (M3GNet) for structure generation (`computational_validation`)

## Dataset uses

- generate non-crystalline structure database via AIMD: 5000K non-crystalline database (source, DU_P048_001)
- construct multi-temperature non-crystalline database: 5000K non-crystalline database (source, DU_P048_002)
- calculate Li-ion diffusivity and activation energy from AIMD trajectories: multi-temperature non-crystalline database (label_source, DU_P048_003)
- train machine learning models (RF, XGBoost, SISSO) on diffusivity data: multi-temperature non-crystalline database (training, DU_P048_004)
- evaluate ML model performance using parity plots and error metrics: multi-temperature non-crystalline database (test, DU_P048_005)
- validate universal ML potentials (M3GNet) for structure generation: multi-temperature non-crystalline database (computational_validation, DU_P048_006)
