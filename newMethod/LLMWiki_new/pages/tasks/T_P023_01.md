# Task: crystal property prediction

- Task ID: `T_P023_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P023`

## Objective

Predict a target property value y ∈ R based on its 3D crystal structure (A, F, L)

## Material scope

- crystalline materials

## Target properties

- formation energy
- bandgap (OPT)
- total energy
- Ehull
- bandgap (MBJ)
- bulk modulus (Kv)
- shear modulus (Gv)
- SLME (%)
- spillage

## Constraints

- limited labeled data due to expensive physical simulations or lab experiments
- must satisfy O(3) invariance and periodic translation invariance

## Input requirements

- atom features A
- fractional coordinates F
- lattice matrix L

## Output goal

- predicted target property value y

## Research stages

1. collecting unlabeled crystal structure data (`data_acquisition`)
2. representing crystal structures in fractional coordinate system (`data_preparation`)
3. pre-training via crystal structure reconstruction (`model_training`)
4. fine-tuning for crystal property prediction (`model_training`)
5. evaluating downstream property prediction performance (`model_evaluation`)

## Dataset uses

- collecting unlabeled crystal structure data: Materials Project and OQMD (pretraining, DU_P023_001)
- evaluating downstream property prediction performance: JARVIS-DFT (test, DU_P023_002)
- evaluating downstream property prediction performance: OQMD-EXP (test, DU_P023_003)
