# Task: predicting the properties of crystalline materials using large language models

- Task ID: `T_P009_01`
- Canonical name: `predict_crystal_properties_from_text`
- Paper: `P009`

## Objective

Predict physical and electronic properties of crystalline materials from their natural language text descriptions.

## Material scope

- crystalline materials
- crystals

## Target properties

- band gap
- formation energy per atom
- energy above hull
- unit cell volume
- energy per atom
- whether the band gap is direct or indirect

## Constraints

- input must be crystal text descriptions (not graphs or CIF files)
- model must be based on fine-tuned LLM encoder (T5-small)

## Input requirements

- text descriptions of crystal structures generated by Robocrystallographer

## Output goal

- numerical predictions for regression tasks (e.g., band gap in eV, volume in Å³/cell)
- binary classification outputs (e.g., AUC for direct/indirect band gap)

## Research stages

1. collecting dataset from Materials Project database (`data_acquisition`)
2. generating crystal text descriptions using Robocrystallographer (`data_preparation`)
3. preprocessing text descriptions (stopword removal, [NUM]/[ANG] replacement, [CLS] prepending) (`data_preparation`)
4. obtaining property labels from Materials Project (`label_generation`)
5. fine-tuning T5 encoder with linear prediction head (`model_training`)
6. evaluating performance on test set across six properties (`model_evaluation`)

## Dataset uses

- collecting dataset from Materials Project database: Materials Project database (as of November 1, 2022) (source, DU_P009_001)
- generating crystal text descriptions using Robocrystallographer: Materials Project database (as of November 1, 2022) (source, DU_P009_002)
- obtaining property labels from Materials Project: Materials Project database (as of November 1, 2022) (label_source, DU_P009_003)
- fine-tuning T5 encoder with linear prediction head: TextEdge (training, DU_P009_004)
- evaluating performance on test set across six properties: TextEdge (test, DU_P009_005)
