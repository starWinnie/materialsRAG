# Task: designing novel superconducting candidates

- Task ID: `T_P031_01`
- Canonical name: `designing_novel_superconducting_candidates`
- Paper: `P031`

## Objective

design novel material structures that are potential superconducting candidates

## Material scope

- crystal structures
- superconductors

## Target properties

- superconducting transition temperature (Tc)

## Constraints

- high Tc value

## Input requirements

- crystal structure M

## Output goal

- novel material structures with high Tc

## Research stages

1. constructing SuperCon3D dataset (`data_acquisition`)
2. training SODNet for Tc prediction (`model_training`)
3. screening ICSD database using SODNet (`candidate_screening`)
4. training DiffCSP-SC for inverse design (`model_training`)
5. generating novel superconductor candidates with DiffCSP-SC (`candidate_generation`)
6. performing DFT calculations on candidates (`computational_validation`)

## Dataset uses

- constructing SuperCon3D dataset: SuperCon (source, DU_P031_001)
- constructing SuperCon3D dataset: ICSD (source, DU_P031_002)
- constructing SuperCon3D dataset: SuperCon3D (label_source, DU_P031_003)
- training SODNet for Tc prediction: SuperCon3D (training, DU_P031_004)
- screening ICSD database using SODNet: ICSD (candidate_pool, DU_P031_005)
- training DiffCSP-SC for inverse design: SuperCon3D (training, DU_P031_006)
- training DiffCSP-SC for inverse design: Pretraining Crystal Collection (pretraining, DU_P031_007)
