# Task: predicting the experimental band gap values of HOIPs

- Task ID: `T_P036_01`
- Canonical name: `predict_band_gap_of_hybrid_perovskites`
- Paper: `P036`

## Objective

to predict the experimental band gap values of hybrid organic−inorganic perovskites (HOIPs) using an interpretable ML strategy

## Material scope

- hybrid organic−inorganic perovskites (HOIPs)
- ABX3 (A = Cs, formamidinium (FA), or methylammonium (MA); B = Pb or Sn; X = Br, Cl, or I)

## Target properties

- band gap

## Constraints

- ideal band gap range (1.3−1.4 eV)
- wide band gap range (1.7−2.1 eV)
- exclude Cl-containing compositions

## Input requirements

- experimental band gap data
- physical features (e.g., electronegativity, ionic radius, Goldschmidt tolerance factor, octahedral factor, electron affinity, dipole polarizability, atomic radius, d/f orbital electrons)

## Output goal

- HOIP compositions with targeted band gaps (e.g., MA0.23FA0.02Cs0.75Pb0.59Sn0.41Br0.24I2.76 with 1.39 eV)
