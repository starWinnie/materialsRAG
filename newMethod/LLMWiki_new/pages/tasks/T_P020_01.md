# Task: prediction of general tensor properties of crystalline materials, including dielectric, piezoelectric, and elastic tensors

- Task ID: `T_P020_01`
- Canonical name: `crystal_tensor_property_prediction`
- Paper: `P020`

## Objective

Predict crystal tensor properties (dielectric, piezoelectric, elastic) in matrix forms that satisfy O(3) equivariance and crystal space group invariance

## Material scope

- crystalline materials

## Target properties

- dielectric tensor
- piezoelectric tensor
- elastic tensor

## Constraints

- O(3) equivariance
- crystal space group invariance
- tensor symmetry constraints (e.g., zero elements, mutually dependent elements)

## Input requirements

- crystal structure M = (A, P, L)

## Output goal

- tensor matrix forms (e.g., ε ∈ R³×³, e ∈ R³×³×³, C ∈ R³×³×³×³) fully consistent with intrinsic crystal symmetries

## Research stages

1. curated dataset construction from JARVIS-DFT database (`data_acquisition`)

3. crystal-level equivariant feature extraction (`model_training`)
4. equivariant tensor property prediction (`model_training`)
5. crystal symmetry enforcement (`model_training`)
6. evaluation using symmetry-aware metrics (`model_evaluation`)
