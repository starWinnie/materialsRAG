# Task: creation of a corrosion resistant alloys database with electrochemical metrics

- Task ID: `T_P069_01`
- Canonical name: `create_corrosion_resistant_alloys_database`
- Paper: `P069`

## Objective

To create a CRA database with electrochemical metrics that could be fed into machine learning (ML) based models to allow for exploration of the compositional space beyond what was used to create the current empirical models.

## Material scope

- Al-based alloys
- Fe-based alloys
- high entropy alloys (HEAs)
- Ni-Cr-Mo ternary system

## Target properties

- pitting potential (Epit)
- repassivation potential (Erp)
- crevice corrosion potential (Ecrev)
- pitting temperature (Tpit)
- crevice corrosion temperature (Tcrev)
- corrosion potential (Ecorr)
- corrosion current density (icorr)
- passivation current density (ipass)
- corrosion rate

## Constraints

- data must be experimentally measured electrochemical metrics relevant to localized corrosion
- must include metadata such as alloy composition, temperature, chloride ion concentration, pH, test solution, microstructure

## Input requirements

- experimental results from literature sources
- alloy composition data
- electrochemical testing conditions (temperature, pH, [Cl−], test solution, scan rate, etc.)

## Output goal

- a publicly available, structured database of electrochemical corrosion metrics for CRAs, formatted for ML model training

## Research stages

1. collection of experimental data from literature sources (`data_acquisition`)
2. extraction and digitization of data from figures and tables (`data_preparation`)
3. classification and organization of alloy compositions into material classes (`data_preparation`)
4. recording of experimental metadata (`data_preparation`)
5. statistical validation and outlier screening (`computational_validation`)
6. formatting and packaging for public release (`data_preparation`)
