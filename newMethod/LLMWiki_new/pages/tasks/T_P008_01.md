# Task: identifying semiconductors with ultralow lattice thermal conductivity

- Task ID: `T_P008_01`
- Canonical name: `identify_semiconductors_with_ultralow_lattice_thermal_conductivity`
- Paper: `P008`

## Objective

Identify semiconductors with ultralow lattice thermal conductivity (κL) for potential thermoelectric applications

## Material scope

- semiconductors

## Target properties

- ultralow lattice thermal conductivity (κL)

## Constraints

- thermodynamic stability (Ehull ≤ 0.05 eV/atom)
- band gap 0.1–2 eV
- unit cell atoms < 20
- elements per compound < 4
- exclusion of H, lanthanides, actinides

## Input requirements

- chemical composition
- crystal structure

## Output goal

- list of candidate semiconductors with ultralow κL
- discovery of new factor (Lmin) governing structural anharmonicity

## Research stages

1. obtaining material dataset from Materials Project database (`data_acquisition`)
2. preliminary high-throughput screening (`data_preparation`)
3. unsupervised learning for clustering materials with similar κL (`candidate_generation`)
4. high-throughput calculation (HTC) of κPET on problem-specific clusters (`computational_validation`)
5. training CatBoost classifier on labeled local database (`model_training`)
6. evaluating CatBoost classifier performance (`model_evaluation`)
7. screening candidates Cs2SnSe3 and Cs2GeSe3 for in-depth mechanism analysis (`candidate_screening`)
8. first-principles calculation of κL for Cs2SnSe3 and Cs2GeSe3 (`experimental_validation`)
9. assigning binary labels (ultralow/non-ultralow κL) based on κPET threshold (`label_generation`)
10. interpretable analysis using SHAP to discover Lmin as new factor governing structural anharmonicity (`other`)
