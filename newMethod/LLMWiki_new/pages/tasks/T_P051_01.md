# Task: generation of natural language-material narratives

- Task ID: `T_P051_01`
- Canonical name: `natural_language_material_narrative_generation`
- Paper: `P051`

## Objective

To generate balanced, plain-language textual narratives describing solid-state materials—covering composition, computed properties, and potential applications—to supplement biased 'common-core' corpora and enable less biased, domain-specialized LLM training.

## Material scope

- solid-state materials

## Target properties

- composition
- band gap
- formation energy per atom
- total energy per atom
- volume
- energy above hull
- density
- enthalpy per atom
- scintillation attenuation length
- space group symbol
- crystal system
- total magnetization
- oxide type
- stability

## Constraints

- narratives must include all numerical values with units
- must not omit any provided property
- must follow academic reporting convention: properties first, then applications

## Input requirements

- structured material data from ab initio databases
- computed physical/chemical properties
- chemical formula
- crystallographic identifiers

## Output goal

- natural language paragraphs pairing each material with a scientifically grounded, application-aware narrative

## Research stages

1. Dataset Collection (`data_acquisition`)
2. Preprocess Databases (`data_preparation`)
3. Training GNN model and Inference (`model_training`)
4. Generate narrative (`candidate_generation`)
5. Validation (`model_evaluation`)

## Dataset uses

- Dataset Collection: Open Quantum Materials Database (OQMD) (source, DU_P051_001)
- Dataset Collection: Materials Project (source, DU_P051_002)
- Dataset Collection: JARVIS-DFT (source, DU_P051_003)
- Dataset Collection: Crystallography Open Database (source, DU_P051_004)
- Dataset Collection: Automatic Flow for Materials Discovery (source, DU_P051_005)
