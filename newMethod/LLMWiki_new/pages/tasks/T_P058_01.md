# Task: graphene layer number classification

- Task ID: `T_P058_01`
- Canonical name: `graphene_layer_number_classification`
- Paper: `P058`

## Objective

Map synthesis conditions to graphene layer count during CVD growth

## Material scope

- graphene

## Target properties

- number of graphene layers

## Constraints

- scarce, heterogeneous, partially missing dataset

## Input requirements

- CVD synthesis parameters (pressure, temperature, growth time, substrate, precursor flow rates)

## Output goal

- classification of graphene layer count (binary: monolayer vs. multilayer; ternary: monolayer vs. bilayer vs. multilayer)

## Research stages

1. manual curation of CVD graphene literature data (`data_acquisition`)
2. imputation of missing attributes (`data_preparation`)
3. feature engineering of substrate attribute (`data_preparation`)
4. discretization of feature space (`data_preparation`)
5. training SVM classifier on processed data (`model_training`)
6. evaluation of classification performance (`model_evaluation`)

## Dataset uses

- manual curation of CVD graphene literature data: CVD graphene synthesis dataset (source, DU_P058_001)
- imputation of missing attributes: CVD graphene synthesis dataset (training, DU_P058_002)
- feature engineering of substrate attribute: CVD graphene synthesis dataset (training, DU_P058_003)
- discretization of feature space: CVD graphene synthesis dataset (training, DU_P058_004)
- training SVM classifier on processed data: CVD graphene synthesis dataset (training, DU_P058_005)
- evaluation of classification performance: CVD graphene synthesis dataset (test, DU_P058_006)
- manual curation of CVD graphene literature data: ML-HydPARK dataset (source, DU_P058_007)
