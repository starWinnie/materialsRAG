# Task: crystal property prediction

- Task ID: `T_P011_01`
- Canonical name: `crystal_property_prediction`
- Paper: `P011`

## Objective

Predicting the property of a given crystal structure C = {A, P, L} by learning a function f to predict its corresponding property.

## Material scope

- crystal structures

## Target properties

- formation energy
- band gap
- total energy
- energy above hull
- bulk moduli
- shear moduli

## Constraints

- labeled data is notably scarce and varies across different properties
- target properties lack comparability

## Input requirements

- crystal structure C = {B, L} characterized by basis B = {A, P} (atom types A and positions P) and Bravais lattice L

## Output goal

- predicted property value (e.g., in eV/atom, eV, log(GPa))

## Research stages

1. acquisition of unlabeled crystal structures (`data_acquisition`)
2. perturbation of crystal representations (`data_preparation`)
3. denoising pre-training (`model_training`)
4. fine-tuning for property prediction (`model_training`)
5. evaluation of property prediction accuracy (`model_evaluation`)

## Dataset uses

- acquisition of unlabeled crystal structures: Merchant et al. 2023 unlabeled crystal structures (pretraining, DU_P011_001)
- fine-tuning for property prediction: JARVIS-DFT (training, DU_P011_002)
- fine-tuning for property prediction: Materials Project (training, DU_P011_003)
- evaluation of property prediction accuracy: JARVIS-DFT (test, DU_P011_004)
- evaluation of property prediction accuracy: Materials Project (test, DU_P011_005)
