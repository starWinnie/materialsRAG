# Dataset Use: QCML in dataset splitting and augmentation

- DatasetUse ID: `DU_P032_002`
- Paper: `P032`

## Research task

molecular dynamics simulation using a neural network force field (`T_P032_01`)

## Research stage

dataset splitting and augmentation (`data_preparation`, `S_P032_02`)

## Dataset

QCML (`D_qcml`)

## Usage role

training

## Purpose

Partition QCML into train/validation/test splits while preserving conformational grouping, and apply random rotations and reflections to enable learning of approximate O(3)-equivariance.

## Used fields

- 3D atomic positions
- atomic numbers
- spin and charge states

## Construction method

90%/5%/5% split with grouped conformers; augmented batches with rotated/mirrored copies

## Filter conditions

- all conformations of a structure assigned to same split

## Sample count

Not stated.

## Availability

- Dataset: public
- Recommendable: true

## Confidence

1.0

## Evidence

- P032, PDF page 5, Pretraining performance: "We create an approximate 90%/5%/5% split from QCML. As QCML contains multiple conformations for each structure sampled along its normal modes, we ensure that all conformations of a structure are assigned to the same split."
- P032, PDF page 5, Pretraining performance: "To learn approximate equivariance, we use data augmentation: during pretraining, we duplicate each batch once and apply random rotations and reflections to both copies to form an augmented batch."
