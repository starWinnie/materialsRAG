## Purpose

training data for TSENN model consisting of frequency-dependent dielectric tensors computed via first-principles methods

## Used fields

## Construction method

ab initio DFT calculations using OpenMX; dielectric tensor computed within IPA using Kubo formula for photon energies 0–30 eV at 0.01 eV increments; structures symmetrized prior to calculation

## Filter conditions

- nonmagnetic
- semiconductors
- bandgap 0.3–3 eV
- energy-above-hull ≤ 0.02 eV/atom
- ≤3 elements
- ≤10 atoms per unit cell
- no f-electron elements
