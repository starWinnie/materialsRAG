## Dataset

RadonPy polymer dataset (`D_P015_radonpy_polymer_dataset`)

## Purpose

Generation of extrapolative episodes where test instances lie outside training domain (e.g., left-out polymer class)

## Used fields

- polymer class
- Cp
- refractive index

## Construction method

Episodes constructed by sampling (x,y) from one polymer class and support set S from other 19 classes

## Filter conditions

- 19 of 20 polymer classes used for support set S
- remaining class used for test set Q
