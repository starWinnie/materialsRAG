# Paper: Graph Networks as a Universal Machine Learning Framework for Molecules and Crystals

- Paper ID: `P061`
- Year: 2019
- DOI: 10.1021/acs.chemmater.9b01294
- File: `529_cm9b01294.pdf`
- Extraction status: completed

## Research summary

This paper develops universal MatErials Graph Network (MEGNet) models for accurate property prediction in both molecules and crystals, addressing limitations of prior ML models—including domain specificity (molecules vs. crystals), lack of global state handling (e.g., temperature), and data scarcity—through graph networks with global state attributes, unified free energy modeling, and transfer learning of elemental embeddings.
