## Research summary

This paper presents a structure-aware graph neural network (GNN) based deep transfer learning framework to improve predictive performance for materials properties using sparse data. It leverages the ALIGNN architecture trained on large source datasets (e.g., Materials Project formation energy) and applies transfer learning—via fine-tuning or feature extraction—to small target datasets across diverse materials classes (3D/2D, inorganic/organic, computational/experimental). The framework is evaluated on 115 dataset-property combinations, showing TL models outperform scratch-trained models in ≈90% of cases, especially for extrapolation and small-data regimes.
