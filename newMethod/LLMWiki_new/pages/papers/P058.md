## Research summary

This paper proposes LLM-based data imputation and feature engineering methods to enhance machine learning performance on scarce, heterogeneous datasets, demonstrated on graphene CVD synthesis data and the ML-HydPARK hydrogen storage dataset. GPT models perform data imputation via tailored prompting and semantic normalization of inconsistently reported features (e.g., CVD substrates). The methods markedly improve downstream performance: in graphene layer number classification using SVM, binary accuracy increases from 39% to 65% and ternary from 52% to 72%. Fine-tuning experiments show combining LLM-based data imputation and feature encoding with numerical ML predictors outperforms standalone fine-tuned LLM predictors in data-scarce settings.
