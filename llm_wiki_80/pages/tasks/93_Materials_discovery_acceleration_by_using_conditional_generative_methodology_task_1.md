# 93_Materials discovery acceleration by using conditional generative methodology - Task 1

## Task Description

Discovering novel topological insulators (TIs) and topological crystalline insulators (TCIs) by generating crystal structures conditioned on topological, nonmetallic, and nonmagnetic properties — specifically, designing new crystalline materials that satisfy multiple electronic property constraints simultaneously to accelerate targeted discovery of experimentally synthesizable TIs/TCIs.

## Supporting Datasets

### [Alexand20 dataset](../datasets/Alexand20_dataset.md)

- Usage page: [usage note](../dataset_uses/93_Materials_discovery_acceleration_by_using_conditional_generative_methodology_Alexand20_.md)
- Original title in paper: Alexand20 dataset
- Link: https://doi.org/10.1038/s41597-022-01164-2

A dataset of 175,000 stable and metastable materials calculated using PBEsol and SCAN functionals, used in this paper as the source for initializing the Markov Chain Monte Carlo (MCMC) sampling process in PODGen; it provides chemically plausible starting structures for conditional generation toward topological insulators.

### [Materiae and TQC databases](../datasets/Materiae_and_TQC_databases.md)

- Usage page: [usage note](../dataset_uses/93_Materials_discovery_acceleration_by_using_conditional_generative_methodology_Materiae_a.md)
- Original title in paper: Materiae and TQC databases
- Link: https://www.topologicalquantumchemistry.org/; https://materiae.iphy.ac.cn/

Combined topological materials databases containing known topological insulators and crystalline insulators (e.g., from Zhang et al. Nature 2019 and Vergniory et al. Science 2022); used in this paper for duplicate checking during structure generation and as a reference distribution to assess elemental composition bias in generated candidates.

### [Generated crystal dataset (PODGen output)](../datasets/Generated_crystal_dataset_PODGen_output.md)

- Usage page: [usage note](../dataset_uses/93_Materials_discovery_acceleration_by_using_conditional_generative_methodology_Generated_.md)
- Original title in paper: Generated crystal dataset (PODGen output)
- Link: https://materialsgalaxy.iphy.ac.cn/materials; https://in.iphy.ac.cn/eln/link.html#/113/G9f5

A curated set of 78,110 unique, MLFF-relaxed crystal structures generated by PODGen, including 19,324 classified as topological insulators or topological crystalline insulators; used to train and validate the topological classification model, screen for direct band gaps, and select candidates for first-principles validation and synthesizability assessment via SSW.
